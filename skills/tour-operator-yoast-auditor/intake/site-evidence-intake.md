Use this when direct evidence is needed before making findings.

## Evidence to request or inspect

- Site URL and staging/live context.
- Rendered HTML and source HTML for representative pages.
- Yoast metadata output: title, meta description, canonical, meta robots and social tags.
- Schema graph output for pages, tours, destinations, accommodation, articles and organisation details where available.
- XML sitemap index and relevant sitemap files.
- Robots.txt and llms.txt where present.
- Redirect evidence for rebuild or migration checks.
- Destination, travel-style and accommodation archive URLs.
- Tour URL samples and their linked destination or accommodation evidence.
- Enquiry page and thank-you page indexation evidence.

## Minimum evidence by scope

| Scope | Minimum evidence |
|---|---|
| Metadata audit | Page URLs plus rendered/source metadata output |
| Taxonomy/archive audit | Archive URLs, canonical output, meta robots and sitemap status |
| Tour relationship audit | Tour URLs, related destination/accommodation URLs and observed internal links |
| Schema QA | Schema output from representative URLs |
| Migration readiness | Old/new URL examples, redirect map, sitemap plan and canonical evidence |
| Launch QA | Staging/live URL, sitemap, robots, metadata, schema and redirect evidence |
