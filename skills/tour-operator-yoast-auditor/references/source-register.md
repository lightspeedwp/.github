# Source Register

Use this register as a reminder of preferred source types. Refresh dates and details when doing a live evidence-led audit.

## Preferred sources

| Source | Use for | Notes |
|---|---|---|
| Official Yoast documentation | Feature behaviour, settings, schema and metadata guidance | Confirm active plugin stack before applying capability claims to a site. |
| Yoast developer documentation | Filters, APIs and implementation boundaries | Use before recommending code-level changes. |
| WordPress documentation | Core robots, sitemaps, templates and content behaviour | Confirm site-specific theme/plugin overrides. |
| Google Search documentation | Search appearance, canonicals, robots, structured data and crawl guidance | Do not promise ranking results. |
| Schema.org | Schema type vocabulary | Pair with Google guidance when rich result eligibility matters. |
| Current site evidence | Findings, scoring and retest results | Highest-confidence source when directly observed. |

## Register fields for future updates
