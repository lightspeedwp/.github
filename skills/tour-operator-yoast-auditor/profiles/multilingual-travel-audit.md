Use this profile when a travel website has multiple languages, regional pages or translated destination/tour content.

## Checks

- Language versions have clear canonical and indexation behaviour.
- Translated tours and destinations do not share duplicated metadata accidentally.
- Language switcher or alternate-language implementation is supported by evidence before making claims.
- Sitemaps include the intended language URLs.
- Destination and tour archive wording fits each language audience.

## Evidence requirements

Request representative URLs in each language, sitemap evidence and rendered/source metadata output before scoring multilingual behaviour.
