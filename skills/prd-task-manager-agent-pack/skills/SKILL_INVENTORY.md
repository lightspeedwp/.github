## Core PRD and task planning skills

| Skill | Role |
|---|---|
| lightspeed-prd-task-manager | Orchestrates PRD, technical brief, task planning, issue drafts, QA plan and project memory. |
| lightspeed-project-intake-router | Turns rough briefs, Figma links, GitHub repos and notes into a kickoff pack. |
| lightspeed-project-researcher | Researches source evidence before PRD and task planning. |
| lightspeed-prd-generator | Creates PRDs for Figma-to-WordPress and WordPress delivery projects. |
| lightspeed-figma-wordpress-technical-brief | Converts Figma design-system intent into WordPress technical requirements. |
| lightspeed-task-breakdown-planner | Turns PRDs and technical briefs into epics, tasks, dependencies and waves. |
| lightspeed-github-issue-drafter | Formats approved tasks into GitHub-ready Markdown issue drafts. |
| lightspeed-implementation-plan-generator | Creates developer-ready implementation sequencing and handoff notes. |
| lightspeed-project-memory-manager | Creates and updates project memory bank files. |
| lightspeed-prd-task-reviewer | Reviews PRDs, briefs, tasks, issue drafts and QA plans before implementation. |
| lightspeed-prd-task-pack-exporter | Packages PRD/task outputs into a clean Markdown project pack. |

## Workflow control and reporting skills

| Skill | Role |
|---|---|
| lightspeed-requirements-traceability-mapper | Maps requirements to tasks, issues, acceptance criteria and QA coverage. |
| lightspeed-approval-gate-manager | Formalises sign-off checkpoints and decision logs. |
| lightspeed-change-request-router | Assesses scope changes against approved project artefacts. |
| lightspeed-project-status-reporter | Creates client/internal status reports and launch snapshots. |
| lightspeed-acceptance-test-planner | Creates acceptance test plans and validation matrices. |
| lightspeed-qa-findings-router | Triage QA findings into fixes, issue drafts and retest steps. |
| lightspeed-release-handoff-generator | Creates release notes, handoff packs and support transition notes. |

## Figma/WordPress launch skills

| Skill | Role |
|---|---|
| lightspeed-launch-task-router | Routes PRD/task outputs into specialist launch workflows. |
| lightspeed-launch-qa-planner | Plans final launch QA for block theme/plugin projects. |
| lightspeed-launch-readiness-auditor | Performs final pre-launch QA and go/no-go reporting. |
| lightspeed-figma-wordpress-parity-auditor | Audits Figma variables/tokens/components/patterns against WordPress implementation. |
| lightspeed-redirect-map-planner | Plans redirects, URL inventory, 404 risk and SEO migration. |
| lightspeed-schema-and-ai-discoverability-planner | Plans schema, FAQ schema, AI visibility, internal linking and claim-safe wording. |
| lightspeed-ga4-conversion-tracking-planner | Defines GA4/GTM measurement, form tracking and launch baseline reporting. |

## Content, claims and governance skills

| Skill | Role |
|---|---|
| lightspeed-website-content-generator | Creates website copy from approved artefacts and source notes. |
| lightspeed-faq-and-chatbot-source-curator | Consolidates FAQs and builds chatbot-safe source sets. |
| lightspeed-claim-register-auditor | Audits proof, stats and claims before publication. |
| lightspeed-policy-page-generator | Drafts policy/trust pages and retention decision notes. |
| content-collection-planner | Defines content artefacts and source requirements. |

## AI readiness and chatbot skills

| Skill | Role |
|---|---|
| lightspeed-ai-readiness | Runs guided AI-readiness process. |
| ai-readiness-assessor | Scores readiness and identifies AI adoption gaps. |
| ai-governance-documentor | Creates AI governance discovery summaries and guides. |
| ai-chatbot-planner | Plans bounded website chatbots and launch gates. |
