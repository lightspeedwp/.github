Score each area from 1 to 5.

## Trigger Fit

1: The output does not address Linear project templates or documents.

3: The output is broadly relevant but drifts into generic project management.

5: The output is clearly Linear-first and matches the requested document job.

## Input Handling

1: Invents missing context or ignores supplied constraints.

3: Uses supplied context but leaves important ambiguity unmarked.

5: Uses available evidence, states assumptions, and asks only necessary questions.

## Structure

1: Hard to scan or not usable in Linear.

3: Mostly usable but contains bloated or duplicated sections.

5: Clear headings, concise prompts, practical tables/checklists, and no filler.

## Planning Value

1: Provides generic sections without improving decisions or execution.

3: Covers basics but misses risks, ownership, or next actions.

5: Makes scope, decisions, risks, dependencies, owners, and next actions visible.

## Risk Handling

1: Creates unsupported commitments or assigns ownership without evidence.

3: Some uncertainty is marked, but important assumptions are mixed with facts.

5: Confirmed facts, assumptions, recommendations, and open questions are separated.

## Reusability

1: Too bespoke or too generic to reuse.

3: Reusable with cleanup.

5: Reusable immediately for similar LightSpeed Linear project workflows.

## Minimum Passing Bar

A production-quality output should score at least:

- 4 on trigger fit;
- 4 on structure;
- 4 on risk handling;
- 4 on planning value;
- 3 on every other category.

## Failure Modes

Revise the output if it:

- reads like a generic PM essay;
- hides open questions;
- duplicates project and issue template responsibilities;
- invents dates, owners, or approvals;
- includes client-facing commitments without evidence;
- is too long to be practical in Linear;
- lacks a clear next action or validation path.
