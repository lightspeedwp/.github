# Team Usage Guide

## What this skill is for

Use this skill as the LightSpeed team’s front door for AI-readiness estimating and routing. It helps decide whether a request should stay in the estimator workflow or move to a specialist workflow such as readiness assessment, governance, content collection, chatbot planning, launch readiness, measurement planning, schema, claims, SEO, or post-launch optimisation.

## Good starter prompts

- Assess this client website for AI readiness and recommend the next LightSpeed package path.
- We have a rough chatbot enquiry. Work out what evidence we need before quoting.
- Route this project into the right LightSpeed AI-readiness workflow.
- Review these source notes and tell me whether we need governance, content collection, or chatbot planning next.
- Turn this discovery call into an internal AI-readiness recommendation with assumptions and open questions.
- Check whether this is ready for chatbot implementation or needs foundation work first.

## Expected outputs

- Routing recommendation
- AI-readiness package path
- Source inventory and gaps
- Governance/content/chatbot next-step plan
- Internal estimate notes
- Client-ready summary when requested
- Specialist prompt starters for the next skill

## Team handoff pattern

When handing work to another teammate, include:

1. Client/project name.
2. Current stage.
3. Evidence reviewed.
4. Confirmed facts.
5. Open questions.
6. Recommended route.
7. Specialist skill to use next.
8. Prompt starter for the next run.

## Do not use this skill for

- Final legal, privacy, security, or compliance approval.
- Publishing or sending content without review.
- Deep implementation without a confirmed technical scope.
- Generic marketing copy unrelated to AI-readiness, governance, content, chatbot, launch, or measurement readiness.
