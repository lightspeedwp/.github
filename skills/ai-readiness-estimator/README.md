# LightSpeed AI Readiness Estimator

This is a consumable ChatGPT skill package for the LightSpeed team. It provides a stable routing and output framework for AI-readiness estimating, governance, content collection, chatbot planning, launch-prep, measurement, schema, claims, SEO and optimisation workflows.

## Files

- `SKILL.md` — skill entrypoint and core behaviour.
- `agents/openai.yaml` — display metadata.
- `references/skill-routing-guide.md` — routing source of truth.
- `references/output-standards.md` — response structure and commercial posture.
- `references/quality-checklist.md` — review checklist before output.
- `references/team-usage.md` — team installation and prompt guidance.
- `assets/routing-cheatsheet.md` — quick reference for common routing decisions.

## Team note

Install the skill as `skill.zip`. Use it for routing and scoping; keep final legal, privacy, security, claims and commercial approvals with a human reviewer.
