# LSX → WordPress (theme.json) Alignment Kit (v2)

- `theme.json` — ready-to-use scaffold (fluid type, numeric spacing, semantic palette)
- `tokens/figma-variables.json` — Figma variables (source of truth)
- `tokens/css-tokens.css` — CSS custom properties (with fluid examples)
- `docs/*` — mapping & guides
- `.github/*` — Copilot instructions, prompts, chat modes, space files
- `scripts/convert_tokens_to_themejson.mjs` — token → theme.json converter
- `package.json` — `npm run build:themejson`

Use with **ai-block-theme-template** or standalone.
