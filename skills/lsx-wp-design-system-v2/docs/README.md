# LSX WordPress Design System Package

Aligns the **LSX Figma design system** with WordPress **Global Styles** (theme.json).

- `tokens/figma-variables.json` — revised Figma variables (source of truth)
- `tokens/css-tokens.css` — CSS custom properties (fluid examples)
- `theme.json` — ready-to-use scaffold (fluid type, numeric spacing, semantic colours)
- `docs/MAPPING.md` — Figma → theme.json → CSS var
- `docs/DESIGN-TOKENS.md` — principles & fluid strategy
- `docs/THEMEJSON-GUIDE.md` — integration notes
- `docs/AUTOMATION.md` — exporter & script workflow

Copy into **ai-block-theme-template** or keep standalone.
