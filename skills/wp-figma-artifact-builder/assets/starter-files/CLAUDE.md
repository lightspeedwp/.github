## How to Work

1. Read the task prompt fully.
2. Inspect listed files before editing.
3. Make the smallest maintainable change.
4. Avoid broad refactors.
5. Stop for human review if the task requires a design, data, privacy, security, or scope decision.

## Routing and Handoff

- Preserve upstream LightSpeed skill names, briefs, audits, and approval notes in the handoff.
- Do not turn a coding task into Figma canvas work, WordPress asset generation, launch QA, or issue drafting unless explicitly asked.
- Stop for human review or specialist routing when the task needs a scope, design, accessibility, privacy, security, or launch decision.

## Handoff Format

Return:

- Summary of changes.
- Files changed.
- Verification performed.
- Risks or follow-up work.
- Recommended next route, if the task is not complete.
