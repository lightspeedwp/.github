Use this structure when the user asks to gather, normalise, review, or clean up project evidence before planning or estimating.

# Project Evidence Record

- **Version:** 1.0
- **Project:** <use when known>
- **Client:** <use when known>
- **Status:** Evidence normalised / provisional / blocked
- **Source status:** Approved / mixed / mostly unconfirmed

---

## 1. Project Anchor

State the clearest confirmed description of the project, website, or chatbot opportunity.

---

## 2. Evidence Collected

List the strongest currently available evidence.

Use bullets and include:

- short label
- source type when helpful
- link or clear reference when available
- short note on what the source tells you
- status: approved, unconfirmed, or excluded

---

## 3. Confirmed Facts

List the facts that appear solid enough to use for planning.

---

## 4. Unconfirmed Or Conflicting Points

List assumptions, contradictions, unclear statements, duplicated material, or evidence that still needs verification.

---

## 5. Source Readiness Assessment

Give a short judgement on whether the project appears ready for:

- chatbot suitability planning
- provisional estimation
- firmer proposal scoping

Explain the confidence level briefly.

---

## 6. Material Gaps

List the missing sources, approvals, governance inputs, or operational details that most affect confidence.

---

## 7. Recommended Next Step

State the single clearest next step.
