Score each routing output from 1 to 5 against these checks.

| Area | Check | Pass condition |
|---|---|---|
| Trigger fit | Router use is justified | The request is ambiguous, mixed, or asks for general block theme asset help |
| Route quality | The chosen specialist is correct | The route matches the true asset type |
| Sequence quality | Mixed requests are broken down well | Ordered steps are practical and not bloated |
| Boundary discipline | The router stays small | It does not absorb specialist generation work |
| Validation discipline | Review is added where needed | The validator is included before signoff on asset outputs |
| Assumption handling | Ambiguity is handled well | Safe assumptions are brief and clear |

## Minimum Acceptance Standard

- no clear specialist request routed vaguely
- no mixed request left unsequenced when sequencing is needed
- no missing validator step where completion or signoff is implied
- no router output that tries to replace the specialist skill entirely
