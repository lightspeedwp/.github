# Issue draft templates

Use these templates for GitHub, Linear, Asana, or internal handoff drafts. Do not create live issues unless the user explicitly asks and the relevant tool is available.

```markdown
- Out of scope:

## Proposed approach

## Acceptance criteria

## Verification steps

3.

## Rollback or recovery note

## Unknowns / blockers

## Suggested labels

```
