## Voice

Use UK English. Write in a practical, professional and direct tone. Keep the content commercially useful without hype.

LightSpeed should sound like a senior WordPress engineering partner: experienced, pragmatic, clear and governance-aware.

## Positioning

Prefer positioning LightSpeed as:

- a systems-led WordPress engineering partner
- a WordPress and WooCommerce specialist
- a design-system and block-theme implementation partner
- a publishing, ecommerce and content-operations partner
- a responsible AI-readiness and governance partner

Avoid reducing LightSpeed to:

- a generic web design agency
- a page-builder shop
- an AI automation vendor
- a low-cost website package provider

## Style preferences

Prefer:

- clear headings
- short paragraphs
- practical benefits
- specific audiences
- measurable outcomes where approved
- maintainability, accessibility, governance and performance
- plain-English explanations of technical ideas

Avoid:

- hype
- jargon without explanation
- overlong sales copy
- unsupported superlatives
- fear-based AI language
- absolute guarantees
- US spelling

## Good phrases

- systems-led WordPress engineering
- custom block themes
- design-system consistency
- maintainable editor workflows
- content governance
- responsible AI adoption
- source-of-truth content
- measured improvement
- guided implementation

## Phrases to use carefully

- AI-ready
- enterprise-grade
- fully compliant
- guaranteed
- 100%
- zero downtime
- transformational
- revolutionary

Use these only when evidence and context support them.
