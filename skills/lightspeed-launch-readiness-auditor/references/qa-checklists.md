## Content and IA

- Primary navigation is final.
- Footer links are final.
- Homepage content is approved.
- Priority service/solution pages are approved.
- Legal/policy pages are present.
- CTAs point to the correct forms or booking flows.
- Placeholder copy has been removed.
- Draft labels or private notes are not visible.
- Page titles and headings are logical.
- Images have alt text where meaningful.

## Broken links

- Crawl live and staging sites.
- Check all navigation links.
- Check footer links.
- Check CTA buttons.
- Check form thank-you redirects.
- Check PDF/download links.
- Check social links.
- Check internal links in body copy.
- Check redirects from old URLs.
- Check 404 template.

## Forms

- Required fields work.
- Optional fields work.
- Error messages are clear.
- Success message or thank-you page works.
- Notification email sends.
- CRM/inbox routing works.
- Spam protection works.
- Consent/privacy notice is visible where needed.
- GA4/GTM conversion event fires.
- Mobile form layout works.

## Accessibility

- Keyboard navigation works.
- Focus states are visible.
- Skip link is present where relevant.
- Headings follow logical order.
- Landmarks are appropriate.
- Colour contrast passes in light and dark modes.
- Form labels are programmatic.
- Error messages are accessible.
- Buttons and links have accessible names.
- Motion is reduced where requested.

## Lighthouse/PageSpeed

- Run homepage.
- Run service/solution templates.
- Run article/blog template.
- Run contact/form page.
- Record performance, accessibility, best practices and SEO scores.
- Note LCP, CLS, INP/TBT where available.
- Flag render-blocking, image, font and third-party script issues.

## Mobile/responsive

- Test small mobile, large mobile, tablet, laptop and desktop widths.
- Check header/menu behaviour.
- Check cards, grids and long headings.
- Check sticky elements.
- Check forms.
- Check footer.
- Check horizontal overflow.
- Check dark/light mode if present.

## Analytics/tagging

- GA4 installed once.
- GTM installed once, if used.
- Consent mode/cookie behaviour confirmed where relevant.
- Consultation CTA clicks tracked.
- Form submissions tracked.
- Lead magnet downloads tracked.
- Email/phone clicks tracked if relevant.
- Chatbot handoff events planned if not live.
- DebugView/Tag Assistant tested.
