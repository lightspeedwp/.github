Use this before release or after major reference updates.

## Package validation

- [ ] Required files present.
- [ ] `SKILL.md` frontmatter valid.
- [ ] Progressive-loading paths match real files.
- [ ] Source register includes required columns and duplicate URL preservation.
- [ ] Reference data validation passes.
- [ ] QA generator runs for standard, WooCommerce, migration, and developer profiles.
- [ ] Package validates and exports as `skill.zip`.

## Scenario validation

Run scenario tests for:

1. Standard business setup.
2. Publisher/blog archive audit.
3. WooCommerce transactional store.
4. WooCommerce faceted navigation risk.
5. Migration/rebuild launch QA.
6. Schema customisation developer handoff.
7. Canonical override developer handoff.
8. Deep research pack refresh.
