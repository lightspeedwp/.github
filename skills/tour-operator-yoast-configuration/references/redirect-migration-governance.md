Use this reference for URL migrations, redirect maps, deleted pages, old campaign URLs, seasonal pages and launch QA.

## Evidence boundaries

- A redirect map is a plan, not proof of live redirects.
- A sitemap export is not proof that old URLs are gone from all submitted sitemap sets.
- A canonical tag on a target page can contradict the redirect plan.
- A status check proves only the tested URL at the tested time.

## Tour operator cases

- retired tour to replacement tour
- old destination slug to new destination slug
- merged travel-style archive to parent style page
- seasonal campaign URL to evergreen tour page
- old guide article to updated guide article
- enquiry landing page consolidation

## Recommended review fields

- old URL
- new URL
- reason
- intended status
- live status evidence
- target canonical
- target robots state
- sitemap state
- internal link cleanup needed
- approval owner
- rollback note
