# Client Communication Guardrails

Use this reference for client-facing summaries.

## Rules

- State what was observed, not what is assumed.
- Avoid ranking promises.
- Avoid saying Google will show a rich result.
- Explain risks in plain English.
- Keep technical details available but not overwhelming.
- Make approval needs clear.

## Safe wording

- "This may reduce confusion for crawlers and users."
- "We recommend checking the rendered output after the setting is changed."
- "This is a configuration risk, not proof of traffic loss."
- "The evidence supports a targeted review of these pages."
