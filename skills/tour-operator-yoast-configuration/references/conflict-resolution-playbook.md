Use this when evidence sources disagree.

## Common conflicts

- setting says indexable but rendered robots says noindex
- redirect map says one target but live URL points elsewhere
- sitemap includes a URL that redirects
- canonical points away from the approved page
- client preference conflicts with search intent
- translated page exists but hreflang points to a different page

## Response pattern

1. State each source and confidence.
2. Identify the conflict.
3. Explain the risk.
4. Recommend the smallest verification step.
5. Avoid changing settings until the approved source of truth is clear.
