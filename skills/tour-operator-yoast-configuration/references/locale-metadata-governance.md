# Locale Metadata Governance

Use this model for translated title and description approval.

## Classify each row

- approved source copy
- translation draft
- AI-assisted candidate
- client-supplied but unreviewed
- stale or unclear

## Approval rules

- Do not import translated metadata without approval status.
- Preserve meaning, local search intent and brand tone.
- Avoid literal translations when they harm clarity.
- QA rendered title and description after import.
