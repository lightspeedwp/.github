# Rendered Output QA Playbook

Use this reference when the evidence includes page source, rendered HTML, crawl output, HTTP headers, sitemap URLs or robots output.

## What rendered output can prove

- title and meta values currently visible to crawlers
- canonical targets
- robots directives
- schema graph presence
- breadcrumb markup
- social tags
- sitemap inclusion when sitemap URLs are sampled
- redirect status when checked directly

## What it cannot prove alone

- future Google display
- ranking impact
- approval status of copy
- full-site consistency without broader sampling
- Search Console interpretation

## Sampling guidance

For tour operator sites, sample:

- home page
- one destination page
- one tour page
- one accommodation page where present
- one travel-style archive where present
- one guide or FAQ page
- one enquiry page
- one translated page where present
- one old URL from the redirect map during migration work
