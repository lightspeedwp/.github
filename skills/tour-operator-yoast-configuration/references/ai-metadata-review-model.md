# AI Metadata Review Model

Use this model to review AI-assisted titles and descriptions.

## Review fields

- URL
- page type
- candidate title
- candidate description
- approved source evidence
- claim risk
- length risk
- duplication risk
- human approval status
- implementation route
- rendered-output QA status

## Red flags

- unsupported ranking or guarantee wording
- invented locations, amenities, routes or dates
- vague wording that could fit any tour
- duplicated metadata across destinations or tours
- mismatch between page intent and title
