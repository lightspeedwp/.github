# Multilingual and Hreflang Playbook

Use this reference for translated destinations, tours, accommodation pages, guides and enquiry pages.

## Checks

- translated page exists and matches the intended page relationship
- title and meta copy are approved for that locale
- canonical points to the page's own locale URL unless there is a documented exception
- hreflang set includes reciprocal alternates
- XML sitemap output includes the intended translated URLs
- visible language switcher does not point users to unrelated pages

## Evidence boundary

A translation-plugin setting does not prove rendered hreflang. Use rendered source or crawl evidence where possible.

## Output rule

Separate language relationship issues from metadata quality issues.
