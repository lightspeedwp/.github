# Audit Triage Model

Use this model to classify findings.

| Severity | Use when | Action |
|---|---|---|
| Critical | indexation, robots, sitemap, canonical or redirect failure affects high-value pages | act immediately |
| High | important template or page group has material SEO risk | schedule before launch or next release |
| Medium | bounded issue with plausible impact | add to planned remediation |
| Low | documentation or minor consistency issue | batch with housekeeping |

Always include confidence and the evidence type.
