# Output Template Library

## Purpose

Define reusable output shapes.

## Required sections

- Prompt only.
- Requirements doc.
- Full agent pack.
- Agent Builder spec pack.
- Routing review.
- Validation report.

## Validation notes

Every reusable output should include required fields and map to `schemas/output-template.schema.json` where structured.

## Validator

Checked by `scripts/validate-template-schema-alignment.py`.
