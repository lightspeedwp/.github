# Team Consumability Checklist

## Purpose

Make generated packs easy for LightSpeed teammates to review, adapt, and reuse.

## Required sections

- Value summary.
- Known risks.
- Next action.
- File map.
- Review gates.
- Open questions.

## Checklist

- [ ] First screen explains value, risk, and next step.
- [ ] Files use predictable names.
- [ ] Assumptions are separated from verified requirements.
- [ ] The pack can be reviewed without reading every file at once.
- [ ] Human-review gates are visible.

## Validator

Checked by `scripts/validate-markdown-structure.py`.
