# Starter Prompt Guide

## Purpose

Keep Builder import prompts short, safe, and phased.

## Required sections

- Prompt-size rule.
- Required Builder import prompt.
- Human-review language.
- Phase-by-phase instruction.

## Prompt-size rule

When the user mentions Agent Builder, Builder import, Builder-ready agent, prompt-size limits, a zip-based handoff, or splitting a large prompt into smaller phases, create a zip pack and a short import prompt rather than one large prompt.

## Required Builder import prompt

Use `BUILDER_IMPORT_PROMPT.md`.

## Validator

Checked by `scripts/validate-starter-prompts.py`.
