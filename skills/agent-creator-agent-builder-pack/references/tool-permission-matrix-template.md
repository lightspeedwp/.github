# Tool Permission Matrix Template

## Purpose

Keep read/write capability, constraints, and approval gates explicit.

## Required sections

- Capability.
- Default stance.
- Allowed when.
- Human approval needed.
- Notes.

## Template

```markdown
| Capability | Default stance | Allowed when | Human approval needed | Notes |
|---|---:|---|---|---|
```

## Validator

Checked by `scripts/validate-template-schema-alignment.py`.
