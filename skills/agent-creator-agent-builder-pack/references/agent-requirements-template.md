# Agent Requirements Template

## Purpose

Provide the required requirements document structure.

## Required sections

- Verified requirements.
- Assumptions.
- Agent mission.
- Scope and boundaries.
- Inputs and trusted context.
- Related shared team skills and routing.
- Tools and permissions.
- Output requirements.
- Quality checklist.
- Human-in-the-loop and escalations.

## Template

```markdown
# Agent Requirements — [Agent Name]

## Verified requirements
## Assumptions
## Agent mission
## Scope and boundaries
## Inputs and trusted context
## Related shared team skills and routing
## Tools and permissions
## Output requirements
## Quality checklist
## Human-in-the-loop and escalations
```
