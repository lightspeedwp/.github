# Routing Boundaries Guide

## Purpose

Keep Agent Creator focused on agent and skill-adjacent pack creation, not specialist delivery.

## Required sections

- Keep.
- Route away.
- Fallback.
- Human-review gates.

## Keep

Agent packs, prompt packs, requirements docs, Builder spec packs, workflow wrappers, packaging reviews, and routing reviews.

## Route away

Specialist delivery work, live support case handling, direct implementation plans, launch QA, SEO, schema, redirects, AI governance, content generation, WordPress asset generation, PageSpeed reporting, and Linear task work when a narrower skill owns the job.

## Validator

Checked by `scripts/validate-links-and-references.py`.
