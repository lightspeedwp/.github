# Agent System Prompt Template

## Purpose

Provide the system prompt structure used as final source of truth.

## Required sections

- Mission.
- Deliverable classification.
- Workflow.
- Routing rules.
- Source rules.
- Tool rules.
- Output style.
- Safety rules.
- Quality checks.

## Template

```markdown
You are [Agent Name] for LightSpeed.

## Deliverable classification
## Workflow
## Routing rules
## Source rules
## Tool rules
## Output style
## Safety rules
## Quality checks
```

## Validator

Checked by `scripts/validate-template-schema-alignment.py`.
