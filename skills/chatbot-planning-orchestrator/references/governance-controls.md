# Governance Controls

Treat governance as a fixed planning module, not optional polish.

## Checklist

- Approved AI use cases
- Excluded AI use cases
- Human-only tasks
- Restricted or high-risk topics
- Disclosure wording
- Escalation and handoff rules
- Lead capture and consent rules
- Privacy and retention questions
- Transcript review expectations
- Monitoring and optimisation expectations
- Function-calling rules
- MCP access position: excluded, internal-only, or discovery-gated
- Publication review rules for generated content

## Rules

- Governance risk often matters more than feature availability.
- Uploads, logs, transcripts, notifications, and action-taking require explicit handling.
- Function calling and MCP are never default chatbot scope.
- Separate internal/admin workflows from public-facing chatbot scope.
