# Intake Checklist

Use this checklist to normalise messy inputs into a clean intake state.

## Required Intake Items

- Project name or working label
- Website or product surface in scope
- Primary audience
- Main chatbot goal
- Top 1 to 3 user tasks or likely questions
- Existing evidence available
- Approved source candidates
- Explicit exclusions or unsafe material
- Known constraints, risks, or blockers
- Readiness status: ready, provisional, or blocked

## Intake Rules

- Start from evidence before asking questions.
- Use the strongest available evidence first.
- Distinguish confirmed facts from assumptions.
- Ask only the missing questions that materially affect scope, safety, or estimate confidence.
