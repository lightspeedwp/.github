# Estimate Position Rules

## Readiness Labels

- **Ready for estimate**: use only when goal, source approval, and governance basics are clear.
- **Provisional estimate**: use when the likely direction is clear but source, governance, or content readiness is incomplete.
- **Discovery-first**: use when missing evidence would make a scoped estimate misleading.

## Always State

- what problem the chatbot is solving
- what sources it will rely on
- what is excluded
- what assumptions are holding the estimate together
- what could change scope or delivery shape

## Rule

Do not estimate from enthusiasm. Estimate from evidence.
