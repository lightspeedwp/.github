# LightSpeed AI Readiness Agent Knowledge Upload Pack

This ZIP contains clean Markdown reference files for the LightSpeed AI Readiness Orchestrator Custom GPT-style agent.

## Important

Use the ZIP for transport/storage. For Custom GPT Knowledge, unzip the pack and upload the individual Markdown files in `upload-these-to-gpt-knowledge/`.

## Folder

- `upload-these-to-gpt-knowledge/` — upload these files individually to the Custom GPT Knowledge area.

## Install summary

1. Install the specialist skills first.
2. Create the Custom GPT.
3. Paste the Custom GPT instructions from `01-custom-gpt-instructions.md` into the GPT Instructions field.
4. Upload the Markdown files from `upload-these-to-gpt-knowledge/` to Knowledge.
5. Enable file uploads/document analysis.
6. Enable Code Interpreter & Data Analysis if you want the GPT to create downloadable Markdown ZIP packs.
7. Test with the prompts in `11-wizard-prompts.md`.
