Create these files when the user requests a project pack or memory system.

```text
memory-bank/
├── projectbrief.md
├── productContext.md
├── systemPatterns.md
├── techContext.md
├── activeContext.md
├── progress.md
└── tasks/
    └── _index.md
```

## projectbrief.md

Project goals, scope, stakeholders, URLs and key constraints.

## productContext.md

Audience, user journeys, business goals and success metrics.

## systemPatterns.md

Architecture patterns, design-system rules, block patterns and plugin conventions.

## techContext.md

Repositories, build tools, WordPress standards, dependencies and environments.

## activeContext.md

Current focus, recent decisions, blockers and next actions.

## progress.md

Milestones, completed work, pending work and launch gates.

## tasks/_index.md

Task index, status, owner role, dependencies and links to issue drafts.
