# Chatbot Launch Gate

Do not recommend launch until these are complete.

| Requirement | Ready? | Notes |
|---|---|---|
| Approved source content exists and is current | No |  |
| Source exclusion list exists | No |  |
| Allowed topics are documented | No |  |
| Restricted topics are documented | No |  |
| Fallback response is approved | No |  |
| Escalation route is operational | No |  |
| Disclosure wording is approved | No |  |
| Lead capture fields are minimised | No |  |
| Privacy/log-retention questions are answered | No |  |
| Transcript review owner is named | No |  |
| Success metrics are defined | No |  |
| Test script has been run against real questions | No |  |
| Rollback or disable process is defined | No |  |

## Go/no-go guidance

- Go: all critical requirements are ready and the bot has passed real question testing.
- Conditional go: minor content or wording issues remain, but no privacy, source, escalation or safety blockers exist.
- No-go: source content, governance, escalation, privacy or testing is weak.
