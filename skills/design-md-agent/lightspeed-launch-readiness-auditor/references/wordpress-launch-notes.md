# WordPress Launch Notes

## WordPress-specific checks

- Site Address and WordPress Address are correct.
- Permalinks are correct.
- Production robots.txt is correct.
- Production is not accidentally set to discourage search engines.
- Sitemap is generated and accessible.
- Caching is enabled and purged after deployment.
- Critical plugins are licensed and updated.
- Unused plugins are removed or disabled.
- Admin users are reviewed.
- Backups are confirmed before launch.
- SMTP/email delivery is tested.
- Media files load over HTTPS.
- Mixed content is resolved.
- Block patterns and reusable blocks render correctly.
- Custom post types and archives are accessible.
- Search works if used.
- 404 and search results templates work.

## WooCommerce checks, if relevant

- Payment gateways tested.
- Tax and shipping rules tested.
- Product pages and checkout pass mobile QA.
- Transaction emails send.
- Refund/returns policy is linked.
- Test orders are removed or clearly marked.
