# Issue Draft Review Checklist

- [ ] Issue has a clear title.
- [ ] Scope is specific and testable.
- [ ] Out of scope is clear.
- [ ] Acceptance criteria are complete.
- [ ] QA checks are included.
- [ ] Dependencies are listed.
- [ ] Labels and milestone are suggested.
- [ ] No unsupported claims are included.
- [ ] No source changes are requested without approval.
