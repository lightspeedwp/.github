# Schema and AI Discoverability Workflow

## 1. Confirm page set

Start with the supplied sitemap, page briefs, content pack or launch inventory. If no page list exists, ask for one or create a provisional list from the supplied content.

Classify pages as:

- homepage
- service page
- solution page
- lifecycle/process page
- article/blog post
- case study/work page
- FAQ page
- policy/trust page
- contact/consultation page
- landing page/download

## 2. Check content maturity

Use these labels:

| Status | Meaning | Use in schema? |
|---|---|---|
| Approved | Reviewed and safe to publish | Yes |
| Needs Review | Good draft, not final | Plan only, validate later |
| Evidence Required | Claims need proof | Do not mark claims as facts |
| Legal Review | Policy/privacy/compliance | Draft only |
| Not for Chatbot | Internal or unapproved | Do not use in chatbot-safe outputs |

## 3. Recommend schema

For each page, recommend primary and secondary schema types. Include implementation notes and validation requirements.

## 4. Map FAQs

Only recommend FAQPage schema when questions and answers are visible on the page and approved for publication.

## 5. Strengthen entity clarity

Recommend consistent naming, internal links, breadcrumbs, author/publisher details, service relationships and page summaries.

## 6. Add AI visibility baseline

Create a monthly monitoring checklist for branded and service-intent prompts across search and AI answer surfaces.

## 7. Validate before launch

Require schema validation, crawl checks, Search Console setup and post-launch monitoring.
