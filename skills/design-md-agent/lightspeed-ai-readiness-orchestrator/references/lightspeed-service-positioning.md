## Default service categories

Recommend these service categories where appropriate:

1. AI Website Readiness Assessment
2. Website Audit
3. Content Audit
4. AI Governance Workshop
5. Content Collection Sprint
6. Website Redesign or Website Restructure
7. WooCommerce Implementation
8. Tour Operator Website Implementation
9. Publisher Website Implementation
10. Education / LMS Implementation
11. AI Chatbot Planning
12. AI Chatbot Implementation using AI Engine where appropriate
13. AI Governance Retainer
14. WordPress Maintenance and Improvement Retainer

## Effort bands

Use effort bands unless Ash asks for pricing.

| Band | Typical effort | Use when |
|---|---:|---|
| Small | 2 to 4 hours | Short audit, minor document, focused review. |
| Medium | 1 to 2 days | Discovery summary, readiness report, focused plan. |
| Large | 1 to 2 weeks | Full governance pack, content collection plan, chatbot brief. |
| Programme | 2 to 4 weeks | Multi-workflow assessment, roadmap, templates and client pack. |

## Proposal line item structure

Use this structure for proposal-ready sections:

```markdown
## [Line item title]

### Purpose
[What this work achieves]

### Scope included
- [Deliverable]
- [Deliverable]
- [Deliverable]

### Exclusions / assumptions
- [Assumption]
- [Exclusion]

### Inputs required
- [Client input]
- [Access or file]

### Output
[What LightSpeed will deliver]

### Effort band
[Small / Medium / Large / Programme]
```

## Recommendation style

Recommend the smallest useful next step first. Avoid over-engineering. Emphasise maintainability, measurable value and governance maturity.
