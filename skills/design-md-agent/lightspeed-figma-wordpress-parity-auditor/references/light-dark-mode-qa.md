# Light and Dark Mode QA

## Check

- background and foreground contrast
- link and button contrast
- focus-state contrast
- card and border visibility
- image treatment
- logo variants
- form inputs
- validation states
- disabled states
- icons and illustrations
- embedded content

## Red flags

- text below WCAG contrast expectations
- focus rings disappearing in either mode
- cards blending into page background
- icons relying only on colour
- untested images or SVGs
- dark mode implemented with ad-hoc CSS instead of tokens
