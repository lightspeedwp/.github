# Accessibility State QA

## Required checks

- keyboard navigation
- visible focus state
- semantic headings
- landmarks
- form labels
- error messages
- link text clarity
- button names
- contrast in light and dark mode
- reduced motion handling
- skip links
- target sizes
- ARIA only where needed

## Accessibility states

Check default, hover, focus, active, disabled, error, success and selected/current states.

## Launch blockers

Treat missing keyboard access, invisible focus, inaccessible navigation, unlabeled forms and severe contrast failures as launch blockers.
