## Before DNS / launch switch

- [ ] Final URL inventory approved.
- [ ] Redirect table approved.
- [ ] P1 pages mapped.
- [ ] P2 pages reviewed.
- [ ] Intentional removals documented.
- [ ] Redirect rules loaded in staging or hosting environment.
- [ ] Redirect chains checked.
- [ ] Redirect loops checked.
- [ ] Internal links point to final URLs.
- [ ] XML sitemap uses final URLs only.
- [ ] Canonicals use final URLs.
- [ ] Robots.txt checked.

## Immediately after launch

- [ ] Test homepage redirect variants.
- [ ] Test top P1 redirects.
- [ ] Crawl old priority URLs.
- [ ] Crawl new site.
- [ ] Check forms and CTA links.
- [ ] Submit sitemap.
- [ ] Monitor 404s.
- [ ] Check Search Console within first 24-48 hours.

## Post-launch monitoring

- [ ] Review 404s daily for first week.
- [ ] Review redirect hits where available.
- [ ] Monitor organic landing pages.
- [ ] Monitor conversions/forms.
- [ ] Add missing redirects discovered from logs.
