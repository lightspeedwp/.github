# WordPress Rules

Use these rules as the primary block-style standard.

## Scope

- Block styles should be scoped to a specific block or tightly related block family.
- Prefer native WordPress styling mechanisms where possible.

## Naming

- Use readable editor-facing labels.
- Use lowercase hyphen-case slugs for style names.

## Styling

- Prefer theme presets and existing tokens before hardcoded values.
- Keep custom CSS selectors scoped to the registered block style.
- Use custom classes only where they add clear value.

## Boundary

- Broader layout or section styling belongs to the section-style generator.
