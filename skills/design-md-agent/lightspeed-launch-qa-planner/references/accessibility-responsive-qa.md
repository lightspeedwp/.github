# Accessibility and Responsive QA

## Accessibility checks

- keyboard navigation
- visible focus states
- skip links
- heading structure
- landmarks
- colour contrast in light and dark mode
- form labels
- error messages
- button and link names
- ARIA usage
- reduced motion preference
- touch target size
- screen-reader spot checks

## Responsive checks

Check at minimum:

- mobile small
- mobile large
- tablet portrait
- tablet landscape
- laptop
- desktop wide

## High-risk areas

- navigation and mega menus
- accordions/tabs
- carousels/sliders
- forms
- custom blocks
- cards with nested links
- dark mode contrast
- sticky headers
- modals and overlays
