# Success Metrics

Choose metrics based on project type.

## Business metrics

- qualified enquiries
- consultation bookings
- lead magnet conversions
- ecommerce conversion rate
- support-ticket reduction
- editorial publishing speed

## Technical metrics

- Lighthouse/PageSpeed scores
- Core Web Vitals
- accessibility findings
- broken links
- 404 count
- schema validation
- editor task completion

## Search and AI discoverability metrics

- organic impressions
- branded search accuracy
- FAQ engagement
- AI visibility baseline results
- structured data coverage
- internal linking coverage

Do not invent target numbers unless the user provides them. Suggest baseline-first measurement when data is missing.
