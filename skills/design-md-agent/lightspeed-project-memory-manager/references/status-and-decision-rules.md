# Status and Decision Rules

## Status labels

Use:

- Confirmed
- Assumption
- Needs Confirmation
- In Progress
- Blocked
- Superseded
- Done
- Deferred

## Decision log fields

Each decision should include:

- Date
- Decision
- Context
- Rationale
- Owner or approver
- Impact
- Review status

## Risk fields

Each risk should include:

- Risk
- Impact
- Likelihood
- Mitigation
- Owner role
- Review date
