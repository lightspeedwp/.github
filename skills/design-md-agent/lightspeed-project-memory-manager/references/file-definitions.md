# Memory File Definitions

## projectbrief.md

Summarise project identity, goals, non-goals, scope, audiences, success criteria and launch context.

## productContext.md

Capture business goals, user groups, user journeys, content needs, conversion goals and client-facing value.

## systemPatterns.md

Capture architectural and design-system patterns: Figma variables, `theme.json`, templates, patterns, blocks, plugin boundaries and editor experience.

## techContext.md

Capture repos, paths, tools, standards, environments, dependencies, build commands, QA tooling and WordPress defaults.

## activeContext.md

Capture the latest state of the project: what is happening now, blockers, current focus, next actions and open questions.

## progress.md

Track done, in progress, pending, blocked and deferred work.

## tasks/_index.md

Index epics, issues, task IDs, owners, statuses, dependencies and estimates.
