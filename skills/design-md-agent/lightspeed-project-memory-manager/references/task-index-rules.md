# Task Index Rules

Use `tasks/_index.md` as the main navigation file for work.

## Recommended columns

| ID | Task | Epic | Status | Owner role | Estimate | Dependencies | Source | Notes |
|---|---|---|---|---|---:|---|---|

## Task file requirements

Each task file should include:

- title
- source requirement
- description
- acceptance criteria
- technical notes
- QA notes
- dependencies
- estimate or complexity
- status
- links

## Estimate model

Use the estimate model requested by the user:

- hours
- T-shirt size
- sprint fit
- complexity/risk only

If unknown, use complexity/risk only.
