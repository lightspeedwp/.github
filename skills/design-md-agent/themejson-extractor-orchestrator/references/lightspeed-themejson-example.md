## Observed Palette Structure

The example theme defines a custom palette with grouped color families including:

- `base`
- `contrast`
- `neutral-100` through `neutral-900`
- `surface-100` through `surface-900`
- `brand-100` through `brand-900`
- `cta-100` through `cta-900`
- `accent-100` through `accent-900`
- `accent-two-100` through `accent-two-900`

## How to Use This Example

Use this example to:

- show what a mature block-theme palette family can look like
- ground discussions about sequential token extraction from Figma
- explain how extracted Figma variables may map into WordPress palette or custom token families

Do not use this example to:

- force the same slug family names onto another project
- assume every theme needs every family or every scale step
- override the user's own naming conventions when their system is already coherent
