| Status | Meaning | Use when |
|---|---|---|
| Green | On track | Work is progressing, no material blockers |
| Amber | At risk | Dependencies, decisions or QA issues need attention |
| Red | Blocked | Progress, launch, budget or quality is materially blocked |
| Grey | Not started / waiting | Work has not started or needs input |

## Severity model

| Severity | Meaning |
|---|---|
| Launch blocker | Must be fixed before launch |
| High | Significant scope, quality, timeline or client risk |
| Medium | Needs action, but not launch blocking yet |
| Low | Improvement or follow-up item |

## Recommended phrasing

- On track: "The project is progressing as planned."
- Amber: "The project remains viable, but decisions are needed to protect scope/timing."
- Red: "The project is blocked until the following issues are resolved."
