# Gate Types

## Intake approval

Confirms the project is classified correctly and has enough input for research.

## Research approval

Confirms source evidence, assumptions and blockers before PRD creation.

## PRD approval

Confirms goals, non-goals, personas, user stories, acceptance criteria, risks and success metrics.

## Technical brief approval

Confirms Figma-to-WordPress mapping, theme/plugin architecture, template/pattern requirements and editor experience.

## Task approval

Confirms implementation tasks, dependencies, estimates and acceptance criteria.

## GitHub issue approval

Confirms issue drafts are ready to create manually or via a connector after user approval.

## Implementation approval

Confirms branch strategy, workstreams, sequencing, testing approach and handoff notes.

## QA readiness approval

Confirms the site is ready for formal QA, not necessarily ready to launch.

## Launch approval

Confirms launch blockers, go/no-go status, rollback plan and post-launch monitoring.
