# Approval Status Model

Use these status labels consistently.

| Status | Meaning |
|---|---|
| Approved | Complete and signed off. |
| Approved with Conditions | Can proceed if named conditions are tracked. |
| Needs Revision | Work exists but must be updated before approval. |
| Blocked | Cannot proceed until blocker is resolved. |
| Pending Review | Awaiting stakeholder or specialist review. |
| Missing | Required material does not exist yet. |
| Not Applicable | Not relevant to this project. |

## Risk levels

- Critical: blocks launch or creates serious delivery/compliance risk.
- High: should be resolved before the next stage.
- Medium: can proceed with tracked mitigation.
- Low: document and monitor.
