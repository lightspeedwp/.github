## Website pages

Collect content or source material for:

- Homepage
- About page
- Service pages
- Product pages
- Contact page
- FAQ page
- Case studies
- Testimonials/reviews
- Blog/news/resources
- Downloads
- Help docs
- Privacy, cookie, terms and policy pages

## Page-level brief fields

For each page, ask for:

- page purpose
- target audience
- primary CTA
- key messages
- proof points
- FAQs
- source links/files
- owner
- review/approval contact
- SEO title and description if known
