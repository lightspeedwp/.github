# Project Type Classification

## Build types

| Type | Indicators | Notes |
|---|---|---|
| Block theme | theme.json, templates, parts, patterns | Default for new WordPress sites |
| Block theme + block plugin | custom blocks, src/blocks, build/ | Use for reusable or dynamic UI |
| Hybrid conversion | classic theme, PHP templates, partial block adoption | Needs migration risk review |
| WooCommerce block theme | product/cart/checkout templates | Requires ecommerce QA |
| Publishing platform | archives, authors, taxonomy, migrations | Requires editorial workflow and migration controls |
| Tourism platform | tours, destinations, itineraries, Wetu | Route to Tour Operator workflows |
