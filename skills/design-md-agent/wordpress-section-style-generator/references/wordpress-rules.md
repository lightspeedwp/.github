# WordPress Rules

Use these rules as the primary section-style standard.

## Scope

- Section styles apply to reusable layout zones or page bands.
- They should stay more focused than full template generation.

## Styling

- Prefer theme presets and existing tokens before hardcoded values.
- Keep custom CSS scoped to the section treatment.
- Use custom classes only where they add clear value.

## Boundary

- Single-block styling belongs to the block-style generator.
- Full template composition belongs to template generators.
- Pattern file creation belongs to the pattern generator.
