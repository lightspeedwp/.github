# Routing Matrix

## Parameter Generator

Use for metadata preparation, normalization, starter headers, and `theme.json` fragments.

## Validator

Use for compliance review, metadata checks, placement checks, hierarchy checks, and signoff readiness.

## Pattern Generator

Use for `/patterns/*.php` generation, starter patterns, hidden implementation patterns, and pattern usage preparation.

## Template Part Generator

Use for `/parts/*.html` files, shared reusable parts, and template-part insertion markup.

## Template Generator

Use for standard hierarchy-aware templates in `/templates`.

## Custom Template Generator

Use for named custom templates that also require `theme.json` `customTemplates` registration.

## Block Style Generator

Use for styles scoped to one block or a tightly related block family.

## Section Style Generator

Use for reusable layout-zone or page-band styling beyond a single block.
