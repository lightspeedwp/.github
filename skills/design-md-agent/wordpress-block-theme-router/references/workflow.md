# Workflow

## Purpose

This reference expands the routing sequence for block theme asset requests.

## Standard Sequence

1. Identify the dominant asset type in the request.
2. Decide whether metadata preparation is needed first.
3. Route to one specialist skill for the main task.
4. Add validator review when the work is nearing completion or signoff.
5. Return a short reasoned route, not a generic explanation.

## Mixed Requests

When multiple asset types are present:

- find the primary requested outcome
- create a short ordered sequence
- keep the sequence readable and practical

## Things To Avoid

- absorbing all specialist logic into the router
- sending the user through unnecessary intermediate steps
- asking broad open-ended questions when a safe route is clear
