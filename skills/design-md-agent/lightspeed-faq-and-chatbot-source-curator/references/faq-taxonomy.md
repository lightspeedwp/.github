# FAQ Taxonomy

Use these fields when mapping FAQs.

| Field | Guidance |
|---|---|
| FAQ ID | Use stable IDs such as FAQ-001 |
| Question | User-facing wording |
| Short answer | 1-3 sentence public answer |
| Source page | Primary page where the answer is grounded |
| Related pages | Optional supporting pages |
| Topic | Use the standard topic groups |
| Audience | Client, prospect, developer, marketer, editor, ecommerce owner, publisher, tourism operator |
| Funnel stage | Awareness, consideration, decision, support |
| Schema suitable | Yes/No |
| Chatbot-safe status | Use chatbot-safe labels |
| Review status | Approved, Needs Review, Evidence Required, Legal Review |
| Owner | Person or role responsible |
| Notes | Internal comments |

## Company FAQ vs page-level FAQ

Use company FAQ when the question applies across LightSpeed.
Use page-level FAQ when the answer depends on a service, sector, policy or technical context.
