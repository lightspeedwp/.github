# Artefact Update Rules

## PRD update note

Include:

- requirement ID or section
- old wording if known
- proposed wording
- reason
- approval status

## Technical brief update note

Include:

- affected area: theme, plugin, template, pattern, block, token, integration
- implementation impact
- affected files or folders if known
- QA impact

## GitHub issue update note

Include:

- affected issue title
- change summary
- acceptance criteria update
- dependency update
- labels/milestone update
- blocker status

## QA update note

Include:

- new test case
- affected viewport/device
- accessibility consideration
- regression risk
- launch gate impact

## Memory bank update note

Include:

- decision summary
- active context update
- progress update
- assumptions/risks update
