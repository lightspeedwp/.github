## Preferred input pack

The best input pack includes:

1. Page brief or content checklist.
2. Source-of-truth register.
3. Claim register.
4. Approved stats list.
5. FAQ source library.
6. Governance notes.
7. Brand/style notes.
8. Existing website copy.

## Minimum input for a page draft

If the user only wants a first draft, ask for or infer:

- page title
- page purpose
- target audience
- primary CTA
- key services/solutions covered
- proof points and confidence status
- required FAQs

If missing, produce a draft with assumptions and open questions.

## Handling uploaded packs

When a user uploads a zip or folder of content artefacts:

1. Identify the files.
2. Summarise available evidence.
3. Build or update the requested content.
4. Include a source notes section.
5. Do not claim that every file was approved unless stated.
