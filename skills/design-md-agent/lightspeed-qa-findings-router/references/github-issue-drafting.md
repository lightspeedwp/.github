# GitHub Issue Drafting Rules

Create one GitHub issue per independently testable fix.

## Issue body structure

```markdown
## Summary

## Source finding

## Affected area

## Expected result

## Actual result

## Reproduction steps

## Evidence

## Acceptance criteria

## Retest steps

## Suggested labels

## Dependencies / blockers

## Internal LightSpeed notes
```

## Suggested labels

- `qa`
- `bug`
- `launch-blocker`
- `accessibility`
- `responsive`
- `figma-parity`
- `block-theme`
- `block-plugin`
- `forms`
- `analytics`
- `seo`
- `schema`
- `content`
- `policy`
- `performance`
