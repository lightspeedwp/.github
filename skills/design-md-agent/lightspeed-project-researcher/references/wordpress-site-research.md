# WordPress Site Research Notes

For live or staging sites, review or request evidence for:

- site purpose and audience
- navigation/IA
- page/template list
- forms and CTAs
- search/indexability
- redirects/migration scope
- performance baseline
- accessibility baseline
- analytics/tracking baseline
- schema/rich results
- privacy/cookie/accessibility policies
- WooCommerce or custom plugin features where relevant

## Do not overclaim

If the site cannot be crawled or audited, mark implementation evidence as pending and create an audit task.
