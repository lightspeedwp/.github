# Figma Research Notes

When Figma evidence is supplied, extract or request:

- design system URL
- frame/page URLs
- Figma Make prototype URL
- screenshots or exports
- variables/tokens export
- colour modes, including light/dark
- typography scale
- spacing scale
- component inventory
- section/pattern inventory
- responsive states
- focus/accessibility states
- content and navigation intent

## Output fields

| Figma item | WordPress implication | Evidence status | Notes |
|---|---|---|---|
| Variables | theme.json tokens |  |  |
| Components | Blocks/block styles |  |  |
| Sections | Patterns/template parts |  |  |
| Pages | Templates/page types |  |  |
| Modes | Light/dark styles |  |  |
| Interactions | Interactivity/API or JS needs |  |  |
