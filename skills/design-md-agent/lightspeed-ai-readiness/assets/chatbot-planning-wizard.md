```text
Use the ai-chatbot-planner workflow.

Run a chatbot planning wizard for a client website.

Ask one section at a time:
1. Chatbot purpose and business goal
2. Audience and likely conversations
3. Approved knowledge sources
4. Sources or topics to exclude
5. Behaviour and boundaries
6. Tone and disclosure
7. Lead capture and conversion
8. Support and escalation
9. Privacy, security and log retention
10. Success metrics
11. Launch readiness
12. Platform notes, including AI Engine if relevant

If source content is weak, missing or unapproved, do not recommend implementation. Recommend content collection and governance work first.

At the end, produce:
- Go/no-go recommendation
- Client stakeholder summary
- Developer implementation notes
- Platform configuration notes
- Approved source list
- Exclusion list
- Behaviour and boundary rules
- Fallback, escalation and disclosure wording
- Lead capture rules
- Launch gate
- Test script based on real FAQs if available
- First-draft chatbot system prompt if appropriate
```
