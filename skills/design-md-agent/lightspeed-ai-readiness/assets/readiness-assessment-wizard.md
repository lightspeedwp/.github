```text
Use the ai-readiness-assessor workflow.

Start a guided AI website readiness assessment for a client.

Ask me one section at a time for:
1. Client and website context
2. Available evidence and files
3. Website foundations
4. Content readiness
5. Search, structured data and AI discoverability
6. Brand, UX and design system readiness
7. Data, privacy and governance
8. Chatbot readiness
9. Current tools and audit results
10. Business priorities and next-step appetite

Use 0-10 scoring per section. Ask follow-up questions when evidence is missing instead of making assumptions.

At the end, generate a Markdown report with:
- Value, risk and next step
- Executive summary
- Evidence reviewed
- Score table and readiness percentage
- Readiness band
- Red flags
- Quick wins
- Foundation work
- Governance work
- Implementation work
- Tool recommendations
- Recommended LightSpeed service/package route
- Open questions
- Internal LightSpeed notes

Make the report suitable for pasting into a Google Doc.
```
