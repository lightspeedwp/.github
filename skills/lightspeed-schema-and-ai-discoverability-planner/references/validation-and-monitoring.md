## Pre-launch validation

| Check | Tool/process | Owner | Status | Notes |
|---|---|---|---|---|
| Schema validation | Schema.org validator / Rich Results Test where relevant |  |  |  |
| Crawl/indexability | Screaming Frog, Sitebulb or equivalent |  |  |  |
| Internal links | Crawl and manual QA |  |  |  |
| FAQ visibility | Manual page review |  |  |  |
| Claim review | Claim register |  |  |  |
| Search Console setup | Google Search Console |  |  |  |
| GA4 events | GA4/GTM |  |  |  |
| Sitemap/robots | Manual and crawl review |  |  |  |

## Post-launch monitoring

| Timeframe | Check |
|---|---|
| Launch day | Confirm no index blockers, major schema errors or critical 404s. |
| Week 1 | Review Search Console coverage, redirects, crawl issues and form events. |
| 30 days | Review impressions, clicks, query changes and AI visibility baseline. |
| Monthly | Repeat AI visibility checks and update content/internal links. |

## Go/no-go guidance

Do not mark .schemas/search launch-ready if:

- key pages are blocked from indexing unintentionally
- major schema errors exist on core templates
- FAQ schema references invisible or unapproved content
- claim register has unresolved high-risk claims
- redirect plan is missing for high-value URLs
