## Common schema types

| Page type | Primary schema | Secondary schema | Notes |
|---|---|---|---|
| Homepage | Organization, WebSite | SearchAction, BreadcrumbList | Use consistent name, URL, logo, sameAs and contact points where approved. |
| Services overview | CollectionPage or WebPage | BreadcrumbList, ItemList | Link to individual Service pages. |
| Service page | Service | FAQPage, BreadcrumbList | Use only factual service descriptions and approved provider details. |
| Solution page | Service or WebPage | FAQPage, BreadcrumbList | Use Service if it describes an offered service; WebPage if mainly educational. |
| Article/blog post | Article | Person, Organization, BreadcrumbList | Include author, date, publisher and mainEntityOfPage where implementation allows. |
| Case study/work page | CreativeWork or Article | Organization, BreadcrumbList | Avoid unverified outcome claims. |
| FAQ page | FAQPage | BreadcrumbList | Only visible approved FAQs. |
| Policy/trust page | WebPage | Organization, BreadcrumbList | Avoid unsupported compliance guarantees. |
| Contact page | ContactPage or WebPage | Organization, BreadcrumbList | Use approved contact details only. |
| Lead magnet page | WebPage | BreadcrumbList | Track conversions; avoid misleading claims. |

## WordPress implementation notes

- Confirm whether schema is generated by theme, SEO plugin, custom plugin or blocks.
- Avoid duplicate conflicting Organization schema from multiple plugins.
- Keep schema output aligned with visible page content.
- Validate generated JSON-LD after caching/minification is enabled.
