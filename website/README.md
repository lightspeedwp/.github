# Awesome GitHub Site

Public website for the `Awesome GitHub` project.

## Scope

- Home
- Why this exists
- References

## Behaviour

- Uses GitHub Pages-friendly static output.
- Includes a light and dark mode switcher in the shared shell.
- Keeps the header and footer reusable across all pages.

## Local development

```bash
cd website
npm install
npm run dev
```

## Build

```bash
cd website
npm run build
```
