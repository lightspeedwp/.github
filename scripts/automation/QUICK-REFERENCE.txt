WHAT IT DOES
─────────────────────────────────────────────────────────────────────────────────
✓ Fetches open issues with status:needs-more-info label
✓ Skips issues that already have DoR/DoD sections
✓ Identifies issue type (feature, bug, epic, etc.)
✓ Generates appropriate DoR/DoD sections
✓ Updates issue body with sections
✓ Removes status:needs-more-info label
