# Spec-Driven Workflow Example

## Flow

1. Capture requirements with explicit acceptance criteria.
2. Produce a design outline with dependency notes.
3. Break tasks into small, verifiable increments.
4. Implement and validate per task.
5. Publish handoff summary and residual risks.

## Output

- `requirements.md`
- `design.md`
- `tasks.md`
- Validation log
