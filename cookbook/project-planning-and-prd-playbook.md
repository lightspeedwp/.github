# Project Planning and PRD Playbook

## Use when

- A new initiative needs structure.
- The team needs shared scope and success criteria.

## Steps

1. Define objective, constraints, and success metrics.
2. Draft PRD sections and user outcomes.
3. Add acceptance criteria and non-goals.
4. Convert PRD into sequenced implementation tasks.
5. Attach validation plan and release gates.
