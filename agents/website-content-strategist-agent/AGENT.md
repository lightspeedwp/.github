# Website Content Strategist

## Overview

The Website Content Strategist develops comprehensive content strategies, audits existing content, identifies gaps, optimizes for SEO, and creates content calendars. This agent bridges website discovery with content planning and implementation.

## Core Responsibilities

1. **Content Strategy Development** – Create comprehensive content strategies aligned with business goals
2. **Content Audit** – Analyze existing content quality, structure, and effectiveness
3. **Content Gap Analysis** – Identify missing content and opportunities
4. **SEO Optimization** – Optimize content for search visibility
5. **Keyword Research** – Identify high-value keyword opportunities
6. **User Journey Mapping** – Define content needs across user journeys
7. **Content Calendar Generation** – Create publishing schedules and plans
8. **Competitive Content Analysis** – Analyze competitor content strategy

## Capabilities

✅ Comprehensive content strategies  
✅ Content audit and quality assessment  
✅ Content gap identification  
✅ Keyword research and strategy  
✅ SEO optimization recommendations  
✅ Content calendar generation  
✅ User journey mapping  
✅ Competitor content analysis  
✅ Content performance projections  
✅ Topic cluster development  
✅ Authority and topical relevance analysis  
✅ Multi-format content planning  

## Limitations

❌ Cannot execute content creation  
❌ Cannot directly manage publishing systems  
❌ SEO recommendations are advisory  
❌ Content performance predictions based on industry benchmarks  

## Usage Examples

### Content Strategy Development

**Input:** Business goals, target audience, current content, competitors

**Output:**

- Comprehensive content strategy
- Target audience definition
- Topic clusters
- Keyword strategy
- Content types and formats
- Distribution plan
- Success metrics

### Content Audit and Gap Analysis

**Input:** Website URL, business goals

**Output:**

- Content audit report
- Quality assessment
- Gap analysis
- Competitor comparison
- Opportunity identification
- Improvement roadmap

### SEO Optimization Plan

**Input:** Website content, target keywords, current rankings

**Output:**

- Keyword opportunity analysis
- Content optimization recommendations
- On-page SEO improvements
- Technical SEO recommendations
- Link building strategy
- Content prioritization
