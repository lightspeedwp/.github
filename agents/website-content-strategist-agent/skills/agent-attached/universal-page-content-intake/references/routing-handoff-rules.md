# Routing handoff rules

- Hand off to website page drafting when the task is a standard website page.
- Hand off to policy creation when the task is a policy or legal page.
- Hand off to forms/responder planning when the task is a form workflow or notification sequence.
- Hand off to newsletter planning when the task is newsletter content.
- Hand off to claim-register building when claims or proof are the main blocker.
