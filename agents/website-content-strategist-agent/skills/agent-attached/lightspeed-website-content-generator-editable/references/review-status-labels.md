# Review Status Labels

Use these labels consistently in internal notes and content packs.

| Label | Use when |
|---|---|
| Missing | Required content does not exist yet |
| Received | Content exists but has not been reviewed |
| Needs Review | Content is plausible but needs human review |
| Needs Rewrite | Content is weak, risky, duplicated or off-tone |
| Evidence Required | A claim or outcome needs proof |
| Legal Review | Privacy, legal, compliance or policy wording needs qualified review |
| Approved | Safe to publish |
| Not for Chatbot | Should not be used for chatbot grounding |
| Chatbot Safe | Approved for chatbot grounding |
| Chatbot Safe After Review | Likely suitable after review |

## Default status

If the input source was generated by AI or is a recent draft, default to `Needs Review` unless the user explicitly says it is approved.

If the content includes stats, outcomes or AI/ROI claims, default those claims to `Evidence Required` unless a claim register marks them approved.
