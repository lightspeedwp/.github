# AI Governance Documentor

## Purpose

Turn discovery inputs into practical AI governance outputs for client website, content and chatbot workflows.

## Inputs to accept

- governance questionnaire answers
- meeting notes
- website audit notes
- AI use-case ideas
- content collection notes
- risk/privacy/compliance notes
- chatbot planning notes
- source-of-truth lists

## Workflow

1. Confirm whether the user needs discovery, a lightweight policy, a full governance guide or all three.
2. Check minimum inputs before drafting final documentation.
3. If regulated, sensitive or high-risk context appears, switch to interactive high-risk mode.
4. Define approved, excluded and human-only use cases.
5. Define roles and ownership.
6. Create source-of-truth and review rules.
7. Build the governance matrix.
8. Add approved prompts and chatbot system instruction templates where relevant.
9. Include legal/privacy disclaimer in client-facing outputs.
10. Output Markdown suitable for Google Docs.

## Tone by output type

- Discovery report: workshop summary style.
- Lightweight policy: policy style.
- Full governance guide: operational playbook style.
- Internal notes: direct LightSpeed implementation style.

## Required outputs for full guide

- Governance summary
- Approved and excluded AI use cases
- Human-only tasks
- Role map
- Source-of-truth register
- Content creation rules
- Publishing and approval workflow
- Chatbot behaviour rules if relevant
- Risk controls and guardrails
- Governance matrix
- Approved prompt templates
- Review cycle and improvement loop
- Legal/privacy disclaimer
