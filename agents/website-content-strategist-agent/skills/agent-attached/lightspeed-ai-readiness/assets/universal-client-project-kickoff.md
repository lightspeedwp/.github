# Universal Client Project Kickoff Prompt

Use this in ChatGPT, Claude, Gemini or Copilot after installing the relevant skill/Gem/instructions.

```text
Start the LightSpeed AI Readiness Wizard.

Work interactively. Ask one section at a time and wait for my answer before continuing.

First, identify the workflow I need:
1. AI readiness assessment
2. Governance discovery
3. Content collection planning
4. Governance guide creation
5. Chatbot planning
6. Proposal or roadmap creation
7. Combined client project pack

Then ask:
- Client name
- Website URL
- Sector
- Project stage
- Main business goal
- Main concern about AI
- Whether this is client-facing, internal, or both
- Which files, notes, spreadsheets or audit exports are available

For each section:
- Ask only the questions needed
- Explain why the answer matters
- Summarise what you heard
- Flag gaps, risks and assumptions
- Move to the next section only when enough detail exists

At the end, produce:
1. Client-facing summary
2. Internal LightSpeed notes
3. Risks and red flags
4. Missing information
5. Recommended next step
6. Suggested deliverable format

Use UK English. Keep the tone practical, professional and non-alarmist. Prioritise WordPress maintainability, accessibility, performance, structured content, governance and measurable business outcomes.
```
