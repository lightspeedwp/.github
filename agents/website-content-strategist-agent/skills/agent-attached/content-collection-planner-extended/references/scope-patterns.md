## Full website

- positioning and offer narrative
- page inventory
- approved source docs
- claims and proof inventory
- policies or trust requirements
- media inventory
- page owners and approvers

## Standard pages

### About page

- vision
- mission
- values
- founder or company story
- differentiators
- trust signals
- CTA destination

### Service page

- service definition
- target audience
- key pain points
- process
- proof points
- FAQs
- CTA route

### Solution page

- problem framing
- solution narrative
- audience fit
- implementation approach
- outcomes or proof
- FAQs
- CTA route

### Product page

- product summary
- features
- benefits
- specifications
- pricing or package logic
- objections
- CTA route

### Contact or enquiry page

- contact routes
- form purpose
- response expectation
- trust notes
- CTA wording

## Single sections

- hero
- intro
- value proposition grid
- proof block
- FAQ block
- CTA block
- form block
- newsletter signup block
