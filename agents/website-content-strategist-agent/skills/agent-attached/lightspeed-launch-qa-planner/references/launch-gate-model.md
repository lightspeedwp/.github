# Launch Gate Model

| Status | Meaning | Example |
|---|---|---|
| Launch Blocker | Must be fixed before launch | Broken forms, no redirects, privacy page missing, inaccessible navigation |
| Must Fix | Should be fixed before launch unless leadership accepts risk | Important layout issue, missing metadata, broken non-critical CTA |
| Can Launch With Follow-up | Non-critical issue with owner and date | Minor copy issue, low-risk spacing mismatch |
| Post-launch Improvement | Improvement backlog | Enhancement, extra animation, optional content expansion |
| Not Applicable | Not relevant to this build | WooCommerce check on non-commerce site |

## Go/no-go planning guidance

- `Go`: no launch blockers, critical evidence reviewed and accepted.
- `Conditional go`: no launch blockers, a small number of must-fix items accepted by owner.
- `No-go`: one or more launch blockers exist or critical evidence is missing.

Treat missing evidence as a risk. If the item is critical, missing evidence can be a launch blocker.
