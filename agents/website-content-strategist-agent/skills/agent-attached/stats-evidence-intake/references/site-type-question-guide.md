# Site-type question guide

## Standard brochure site

- What approved trust or experience signals support this page?
- Which figures are genuinely approved for public use?

## WooCommerce site

- Which ratings, review counts, fulfilment figures, or trust signals are approved?
- Which numbers directly support this page's conversion goal?

## Tour operator site

- Which traveller, itinerary, review, or destination figures are approved?
- Which numbers risk implying unsupported guarantees?

## One-off page

- Which figures are essential to this page's conversion logic?
- Would a non-numeric proof point be safer?
