## Strong evidence

- analytics export
- Search Console or GA4 export
- Lighthouse/PageSpeed report
- ticketing system export
- project management report
- signed client approval
- published case study
- deployment or migration log
- audited spreadsheet with owner and date

## Moderate evidence

- internal team estimate with named owner
- documented meeting note
- screenshot from a trusted system
- repeatable manual audit result
- historical project summary with source links

## Weak evidence

- memory-based estimate
- draft AI-generated claim
- unsourced percentage improvement
- generic industry benchmark used as LightSpeed proof
- vendor marketing benchmark without context

## Evidence notes

Record:

- source name
- source link/file
- owner
- date checked
- methodology
- scope
- confidence level
