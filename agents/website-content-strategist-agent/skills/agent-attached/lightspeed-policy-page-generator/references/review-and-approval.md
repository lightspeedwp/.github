# Review and Approval Rules

## Status labels

Use:

- Draft
- Needs Review
- Legal/Privacy Review Required
- Approved Internally
- Ready to Publish
- Blocked

## Launch blockers

Mark as a launch blocker when:

- privacy policy is missing or outdated
- cookie/tracking behaviour is unknown
- chatbot transcript retention is undefined
- lead-form data flow is unknown
- AI governance page claims unsupported practices
- accessibility statement claims compliance without audit evidence

## Review fields

Every policy/trust output should include:

- owner
- reviewer
- legal/privacy reviewer
- source inputs
- missing decisions
- target publish location
- review date
- next review date
