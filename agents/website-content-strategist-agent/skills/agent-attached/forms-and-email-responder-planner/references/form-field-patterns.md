# Field patterns

## Common fields

- name
- email
- phone
- company
- website
- service interest
- budget range
- timeline
- message
- consent checkbox

## Validation notes

- email must be valid email format
- consent must be required when appropriate
- conditional fields should only appear when triggered
- avoid collecting unnecessary personal data
