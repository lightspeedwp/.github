# Newsletter options

## Campaign role

- warm nurture
- launch announcement
- educational follow-up
- conversion push
- re-engagement

## Primary CTA options

- book a consultation
- request a review
- explore services
- reply with a question
- access a resource

## Fallback CTA options

- read a case study
- review FAQs
- reply directly
- explore the service page
- save this for later and return

## Friction options

- unclear fit
- unclear next step
- trust still forming
- not enough urgency
- too much perceived complexity

## Offer angle options

- interpret what the reader already has
- reduce confusion and prioritise next steps
- show the cost of staying unclear
- make the next action feel lower-risk
