# FAQ Intake and Claim Mapper

## When to use this skill

Use this skill when a website page, page family, or section needs structured FAQ planning before drafting or publication.

Use it especially when:

- the page needs visitor-objection handling
- the page depends on decision-stage questions
- the answers may include trust, proof, policy, guarantee, comparative, or performance language
- the page template still needs its five FAQ planning slots filled

## Workflow

1. Identify the page type, site type, and conversion stage.
2. Define exactly five useful FAQ planning slots for the page.
3. Prioritize real visitor questions, objections, routing questions, and trust concerns over filler.
4. For each FAQ, capture:
   - question
   - answer summary
   - internal link if useful
   - publish on page: yes, hidden, deferred, or answered elsewhere
   - claim-sensitive yes or no
   - claim-register action
5. If an answer is claim-sensitive, route it into the claim register before treating it as publish-ready.
6. If the answer cannot be supported safely, mark it for rewrite, evidence required, approval required, or answer elsewhere.

## Smart questioning rules

Ask the smallest useful question set based on page type.

Examples:

- homepage: objections, trust questions, route-selection questions
- service page: process, proof, timeline, fit, next-step questions
- pricing page: inclusions, exclusions, fit, commitment, trust questions
- contact or form page: response expectations, privacy, next-step questions
- getting started page: onboarding expectations, inputs needed, support route questions

## FAQ rules

- Every page should support exactly five FAQ planning slots.
- If the page should not visibly publish FAQs, still define the five most useful questions in the planning layer and mark them as hidden, deferred, or answered elsewhere.
- Avoid generic filler questions.
- Prefer decision-stage, trust-stage, and routing-stage questions.
- Use internal links where they improve progression or clarity.

## Output

Return:

- FAQ planning summary
- Five FAQ entries
- Claim-sensitive FAQ list
- Claim-register actions
- Recommended next step
