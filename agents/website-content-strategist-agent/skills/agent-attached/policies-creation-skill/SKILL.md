# Policies Creation Skill

## When to use this skill

Use this skill when the deliverable is a policy, principles, governance, or legal-style page.

## Memory state

Use Memory only for durable policy-work defaults.

Save:

- policy page type
- authority order for policy decisions
- review owner or review requirement
- standard disclaimer or review sensitivity notes when approved
- recurring navigation or policy-hub conventions

Do not save:

- legal conclusions that are not approved
- draft legal wording variants
- unresolved compliance assumptions
- temporary review comments

## Workflow

1. Identify the policy page type.
2. Match it to the correct policy template.
3. Confirm the authority source and review sensitivity.
4. Draft only within the approved scope.
5. Flag where legal, privacy, governance, or executive review is still needed.

## Output

Return a clean policy-page structure or draft using the matched policy template.
