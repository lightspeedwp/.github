# Template name

Review output template

## Purpose

Use for website-content audits, source reviews, readiness reviews, and next-step recommendations.

## Required inputs

- request summary
- reviewed sources
- current workflow stage
- major blockers or risks
- validation notes

## Required sections

- Confirmed context
- Key findings
- Gaps and risks
- Recommended workflow
- Validation checks
- Best next step

## Output rules

- Keep the output concise and review-ready.
- Separate confirmed facts from assumptions.
- Flag missing approvals, weak evidence, and structural gaps.
- Recommend one best next step when possible.

## Validation notes

- Match the required sections in order.
- Remove placeholder text.
- Keep headings stable.
