# Templates folder

## Purpose
This folder stores canonical output blueprints for repeatable deliverables.

## Naming conventions
- Use lowercase kebab-case names ending in `-template.md`.
- Keep one canonical template per output family unless two families are materially different.
- Update an existing template before creating a second same-purpose file.

## File outline
- `review-output-template.md` — canonical structure for review-style, readiness, and next-step outputs.
