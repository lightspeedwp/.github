Use this guide for page, policy, newsletter, form, responder, and chatbot-intake workflows.

## Save in Memory

- confirmed page type or content type
- template family that should normally be used
- approved CTA model or destination pattern
- recurring section requirements
- recurring form routing or responder style
- confirmed policy review sensitivity or review owner
- confirmed chatbot intake purpose, exclusions, and escalation route
- recurring claim sensitivity or approval sensitivity that affects future related work

## Do not save in Memory

- temporary draft variants
- unapproved claims
- raw source copy pasted from documents
- brainstorming options that were not chosen
- sensitive personal form submissions unless they are explicitly appropriate to retain
- temporary QA comments that will not matter again
