## `lightspeed-preferences.md`

```md
# LightSpeed project preferences

## Output structure defaults
- Preferred default structure: Summary, key findings, recommended next step, draft output
- Preferred heading style: Sentence case Markdown headings
- Preferred summary style: Short prose summary before bullets
- Preferred ending style: One clear next step

## Metadata defaults
- Metadata fields to include: Project, stage, source status, review status
- Versioning preference: v1.0 for first formal draft
- Divider-line preference: Use horizontal rules before each main section
- Traceability notes: Note approved vs unapproved claims where relevant

## Review framing defaults
- Preferred review depth: Medium-depth review with clear priorities
- Preferred way to show blockers: Separate blocker section with impact noted
- Preferred way to show gaps: Distinguish source gaps from approval gaps
- Preferred way to show next step: Single recommended next action

## Drafting conventions
- Tone defaults: Clear, commercially confident, practical
- CTA style defaults: Specific consultation or enquiry CTAs
- Proof or evidence standard: Flag unsupported claims explicitly
- Internal linking preference: Suggest internal links where they improve routing
- Section-length preference: Keep sections scannable and concise

## Last updated
- Date: 2026-05-15
- Reason for update: Established default project conventions
```
