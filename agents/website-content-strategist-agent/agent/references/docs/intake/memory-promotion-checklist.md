# Memory promotion checklist

Promote a value from intake into durable Memory only when all relevant checks pass.

- [ ] The value is useful beyond the current run.
- [ ] The value affects future routing, drafting, review, or approvals.
- [ ] The value was explicitly confirmed by the user or an approved source.
- [ ] The value is not just a questionnaire default.
- [ ] The value is not a speculative claim, risk note, or unsupported fact.
- [ ] The save policy for this field allows durable storage.
- [ ] Any requester-specific value is properly namespaced when needed.
