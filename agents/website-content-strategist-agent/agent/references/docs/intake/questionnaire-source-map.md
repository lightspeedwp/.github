## Purpose

This file maps questionnaire-library sources to the workflow types they best support.

Use it to decide:

- which questionnaire files are relevant for the current task
- which files are only secondary references
- which files should be ignored for the current workflow
- when to ask a focused clarification question before continuing

The questionnaire library is a selective intake resource. It is not a mandatory form set and should not be pasted into chat.

---

## Core selection rules

- Select only the questionnaire files that materially improve the current intake-heavy workflow.
- Do not merge every questionnaire into one giant intake.
- Prefer the most directly relevant structured source first, then use adjacent files only if they add missing fields, risk prompts, approval points, or useful defaults.
- If a questionnaire theme appears in more than one format, prefer the richer editable source and treat alternate formats as fallback references.
- If the agent cannot tell why a questionnaire applies, ask one focused question: **What was this questionnaire intended to help capture for this workflow?**
- After asking that question, continue with a safe default instead of stalling.

---

## Ignore rules

Ignore a questionnaire file when:

- it belongs to a different project type
- it adds no useful field, risk prompt, approval point, or default for the current task
- it would inflate intake without improving the next decision
- a richer equivalent source already covers the same ground
- its assumptions conflict with the actual workflow scope

When ignoring files, do so deliberately and briefly explain why if the user asks for the audit trail.

---

## Suggested audit output pattern

When a request calls for a questionnaire-aware intake audit, summarise:

1. relevant questionnaire files and why they apply
2. ignored questionnaire files and why they do not apply
3. reusable fields extracted from the selected files
4. likely defaults inferred from the selected files
5. blockers that still need confirmation
