## Purpose

This folder is the current-state reference layer for questionnaire-aware intake, wizard-driven onboarding, evidence handling, claim review, exclusions, approvals, handoffs, and Memory promotion for this agent.

Use this folder as the stable build target and current reference surface.

Do not treat the older `refactor-prompt/agent-refactor-prompt-pack/` files as the long-term reference layer. Those files are transition and refactor working notes. Their durable outcomes should be captured here in `docs/intake` and related stable reference locations.

## Directory intent

`docs/intake/` is the canonical intake-reference layer for:

- selective questionnaire use
- wizard-driven intake fields
- intake review states
- evidence and token extraction
- Memory-safe promotion rules
- exclusions and scope boundaries
- claim and risk routing
- source approval and approval gates
- handoff outputs and project-memory summaries
- agent-specific durable Memory recommendations

---

## How to use this manifest

When extending or maintaining the folder:

1. update this manifest whenever a new intake-reference file is added, removed, or substantially repurposed
2. keep the original core target set complete
3. keep optional extensions clearly marked so the core set remains easy to audit
4. keep the transition-doc replacement map current when a stable reference supersedes an older working note
