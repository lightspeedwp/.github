# Examples folder

This folder contains **completed demo outputs** that match the agent's template families and formatting rules.

Use these examples as reference when you want to see:

- what a filled template should look like
- how strategic intake should appear once completed
- how page, policy, email, and component outputs should be structured
- how the Markdown validation rules should be reflected in real deliverables

These examples are written to the same structural expectations used by the specialist skills and formatting rules. Treat them as **reference outputs**, not as reusable client copy.

## Example groups

- `pages/website-page-examples.md`
- `pages/utility-and-feedback-page-examples.md`
- `policies/policy-page-examples.md`
- `components/component-and-email-examples.md`
- `intake/website-and-chatbot-intake-examples.md`

## Usage rule

When creating new work:

1. choose the right template
2. follow the specialist workflow
3. use the examples for shape and completeness
4. keep the final output aligned to the Markdown validation rules
