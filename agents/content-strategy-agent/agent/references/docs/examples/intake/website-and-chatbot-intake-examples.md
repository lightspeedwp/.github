## Website intake example

### Project basics

- Project name: Alder & Stone website refresh
- Scenario type: Standard WordPress brochure site
- Current stage: Intake
- Main site objective: Increase qualified consultation enquiries

### Audience and conversion

- Primary audience: Owners and marketing leads reviewing agency options
- Main user intent: Evaluate fit, trust, and strategic capability
- Primary conversion goal: Consultation booking
- Secondary conversion goal: Service exploration

### Source and authority inputs

- Approved sources: Discovery brief, current website copy, stakeholder notes
- Authority order: Discovery brief, approved copy, stakeholder notes

### Recommended next step

Run voice and tone strategy, then define page-level conversion goals before drafting.
