Use this guide when storing reusable strategic defaults about audience, user flows, and page-level conversion goals.

## What to save

Save only durable conversion defaults that should shape future related work, such as:

- primary audience segments
- audience intent notes
- primary conversion goal
- secondary conversion goal
- core user-flow priorities
- CTA model and routing model
- page-role definitions by page family
- funnel-stage defaults
- trust or friction notes that materially affect conversion drafting

## What not to save

Do not save:

- one-off campaign hypotheses unless they will recur
- speculative target metrics without approval
- rough brainstorms about user behaviour
- isolated test ideas that are not part of the recurring strategy

## Suggested Memory location

Use `lightspeed-project-context.md` for project-level conversion context and `lightspeed-preferences.md` for durable output or CTA defaults.

## Validation rule of thumb

A saved conversion value should be:

- confirmed or clearly chosen as a working default
- reusable across future related requests
- directly useful for routing, drafting, or review
- specific enough to influence CTA, structure, or flow decisions
