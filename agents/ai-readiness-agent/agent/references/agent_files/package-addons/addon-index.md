## Purpose

This file lists the AI add-ons that can attach to a base package after the primary package path is chosen.

## Add-On Rule

- Always determine the primary AI package path first.
- Only then decide whether an add-on applies.
- Do not recommend an add-on as the first commercial route.

## Add-Ons

### WooCommerce AI Readiness / SEO Add-on

Can attach to:

- AI Readiness Foundation
- AI Search and Structured Data

Recommend when:

- WooCommerce product structure, taxonomy, or ecommerce complexity materially affects AI readiness or discoverability
- the base package remains correct but ecommerce-specific scope must be layered on

### Tour Operator JSON-LD Audit Add-on

Can attach to:

- AI Readiness Foundation
- AI Search and Structured Data

Recommend when:

- the client is in travel, tours, itineraries, or activities
- schema complexity must be audited before responsibly quoting implementation
- the base package remains correct but tourism-specific entity modelling requires specialist scoping

## Recommendation Rule

Add-ons are considered only after the base package is chosen and the audit confirms that the extra scope is real.
