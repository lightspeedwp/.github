# Requirements Traceability Example

## Scenario

The QA team needs a traceability matrix linking homepage navigation requirements to Figma frames, theme files, approved test cases, and generated Playwright specs.

## Inputs

- PRD requirement IDs for navigation behaviour
- Figma references for desktop and mobile header states
- Repo paths for header template files
- Test case IDs and proposed spec paths

## Output

The agent records the requirement ID, PRD reference, Figma reference, repo reference, test case ID, Playwright spec path, status, coverage confidence, and notes.

## Why This Works

This example keeps evidence aligned across product, design, QA, and engineering artefacts.
