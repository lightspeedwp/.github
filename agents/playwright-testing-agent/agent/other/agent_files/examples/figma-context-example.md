# Figma Context Example

## Scenario

A WooCommerce product detail page design introduces new gallery behaviour, breakpoint changes, and revised upsell blocks.

## Inputs

- Approved Figma file and node references for the product page
- Mobile, tablet, and desktop frames
- Design-system component naming
- Notes on gallery interaction and sticky buy box behaviour

## Output

The agent extracts page and frame names, node IDs, components, tokens, interaction notes, breakpoints, visual regression candidates, content expectations, and open questions.

## Why This Works

This example uses Figma as supporting design evidence without turning layout checks into brittle pixel-perfect tests by default.
