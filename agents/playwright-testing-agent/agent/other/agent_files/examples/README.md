# examples

## Purpose
This folder contains worked examples that show the expected shape, level of detail, and traceability of agent outputs.

## Naming conventions
- Use descriptive kebab-case names.
- Use the `-example.md` suffix for example markdown files.
- Keep example names paired with their corresponding schema or output type where possible.

- Keep examples aligned with the corresponding schema and current validation rules.
- Do not treat examples as canonical templates or validation contracts.
