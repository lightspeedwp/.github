# templates

## Purpose
This folder contains the canonical reusable output templates used by the Playwright Testing Agent.

## Naming conventions
- Use descriptive kebab-case names.
- Use the `-template.md` suffix for reusable template files.
- Keep one template per output type or artifact family.

## Current file inventory
- `test-case-template.md`
- `test-suite-plan-template.md`
- `playwright-spec-template.md`
- `bugherd-failure-template.md`
- `repo-analysis-template.md`
- `figma-context-extraction-template.md`
- `requirements-traceability-template.md`

## Maintenance rules
- Treat templates as the canonical structure for recurring outputs.
- Keep matching examples and schemas aligned when a template changes.
- Do not use examples as substitutes for templates.
