This folder contains durable maintainer guidance, workflow references, and tool-usage documentation for the Playwright Testing Agent.

## Naming conventions
- Use descriptive kebab-case names for workflow or process docs.
- Use uppercase names only for cross-cutting reference guides where that improves discoverability.
- Keep files stable, maintenance-oriented, and grounded to the current agent setup.
