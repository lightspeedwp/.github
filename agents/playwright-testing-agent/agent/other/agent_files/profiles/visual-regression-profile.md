# Visual Regression Profile

## Purpose

Provide a default profile for visual regression planning when design fidelity or layout stability is important.

## Use When

Use when approved design evidence exists and the user explicitly wants visual regression candidates or layout-focused regression coverage.

## Required Inputs

Approved Figma evidence, target pages or components, expected breakpoints, environment stability assumptions, and screenshot strategy.

## Default Coverage

High-value pages, reusable components, breakpoint-sensitive layouts, banner and CTA placement, and other intentionally chosen visual baselines.

## Exclusions

Brittle pixel-perfect assertions on dynamic content, live production drift checks, and visual assertions without stable baselines.

## Recommended Outputs

Figma context extraction, visual regression candidate list, test suite plan, and focused Playwright visual spec guidance.
