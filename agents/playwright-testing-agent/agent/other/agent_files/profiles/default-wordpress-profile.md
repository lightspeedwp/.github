# Default Wordpress Profile

## Purpose

Provide a default coverage profile for WordPress frontend QA on brochure or content-led builds.

## Use When

Use when the site is primarily WordPress-driven and WooCommerce behaviour is not the main testing focus.

## Required Inputs

Approved requirements, page templates, environment URL, and any relevant content or design evidence.

## Default Coverage

Navigation, header and footer, key page templates, forms, search, blog templates, responsive behaviour, and accessibility smoke checks.

## Exclusions

Checkout, order flows, destructive admin actions, and production-only monitoring unless explicitly requested.

## Recommended Outputs

Test suite plan, human-readable test cases, traceability matrix, and Playwright smoke or functional specs.
