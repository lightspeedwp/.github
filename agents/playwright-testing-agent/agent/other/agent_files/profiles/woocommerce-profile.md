# Woocommerce Profile

## Purpose

Provide a default coverage profile for WooCommerce storefront and customer flow testing.

## Use When

Use when the project includes storefront browsing, cart, checkout, account, or other customer commerce flows.

## Required Inputs

Approved product requirements, seeded products, environment assumptions, payment and shipping test modes, and account setup guidance.

## Default Coverage

Product listing, product detail, cart, checkout, my account, authentication, responsive behaviour, and key error states.

## Exclusions

Production checkout mutations, live payment processing, and destructive order actions without explicit approval.

## Recommended Outputs

Suite plan, human-readable flow-based test cases, fixture recommendations, stateful versus read-only test split, and Playwright spec proposals.
