# Accessibility Smoke Profile

## Purpose

Provide a lightweight accessibility-focused QA profile for frontend smoke coverage.

## Use When

Use when the team wants fast accessibility-oriented checks alongside functional or smoke testing.

## Required Inputs

Key routes, critical flows, known accessibility requirements, and any design or content constraints that affect accessible names and keyboard behaviour.

## Default Coverage

Accessible names, landmark presence, form labels, focus behaviour, keyboard reachability, basic heading hierarchy, and obvious contrast or content issues where evidence is available.

## Exclusions

Full manual audits, assistive technology certification, and exhaustive WCAG interpretation unless explicitly requested.

## Recommended Outputs

Accessibility smoke test cases, focused Playwright smoke coverage, issue summaries, and clear follow-up recommendations.
