# Migration Rebuild Audit Profile

## When to load

Load for migrations, rebuilds, domain moves, URL changes or post-launch validation.

## Audit lens

Focus on redirects, canonicals, sitemap changes, metadata migration, taxonomy changes, archive indexation, schema continuity and launch risk.

## Key checks

- Old-to-new URL mapping for high-value pages.
- Canonicals on staging and production.
- robots and noindex state before launch.
- Metadata carry-over for key pages.
- Taxonomy/archive changes.
- WooCommerce product/category URL changes.

## Output expectation

Use go/no-go language for launch QA and clearly mark blocked evidence.
