# WooCommerce Catalogue Audit Profile

## When to load

Load for non-transactional WooCommerce catalogue or quote-led product sites.

## Audit lens

Prioritise product discoverability, categories, product identifiers, quote-led product pages, duplicate filters and indexation strategy.

## Key checks

- Product and category metadata.
- Canonical and sitemap coverage.
- Product schema quality where output exists.
- Filtered URL and duplicate-content risks.
- Quote CTA pages and product social sharing.

## Routing note

Audit findings here. Route catalogue SEO setup or default templates to `woocommerce-yoast-configuration`.
