# Developer Handoff Intake

## When to load

Load when the user asks to turn findings into developer tasks or implementation notes.

## Questions

Ask only if missing:

- Target developer or team.
- Repo, theme, plugin or deployment context.
- Whether code changes are expected.
- Whether Yoast APIs, filters or custom schema are involved.
- QA owner and environment.
- Deployment constraints or launch timing.

## Routing note

Prepare handoff notes, not code changes, unless another workflow explicitly owns implementation.
