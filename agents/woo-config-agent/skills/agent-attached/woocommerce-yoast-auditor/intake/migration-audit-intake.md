# Migration Audit Intake

## When to load

Load for migration, rebuild, domain change, permalink change or post-launch validation.

## Questions

- Old URL structure or crawl export.
- New URL structure or staging URL sample.
- Redirect map availability.
- Content type and taxonomy changes.
- Domain or protocol changes.
- Launch date or current launch status.
- Known high-value pages.
- WooCommerce catalogue or product URL changes.
- Known canonical, sitemap, robots or metadata risks.

## Output expectation

If redirect/canonical evidence is missing, label the finding as blocked and state the minimum evidence needed.
