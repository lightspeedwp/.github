# Site Evidence Intake

## When to load

Load when site evidence is missing or partial.

## Evidence to request

Ask for the smallest set needed for the selected audit:

- WordPress MCP access or screenshots/exports.
- Active Yoast plugins and versions.
- Sitemap index URL.
- Key page URLs.
- Example source or rendered HTML if output cannot be fetched.
- Search Appearance screenshots/exports if MCP is unavailable.
- Schema output examples.
- robots.txt and llms.txt URLs where relevant.
- Product and category URLs for WooCommerce audits.

## Output expectation

If enough evidence is still unavailable, produce an evidence gap report rather than guessing.
