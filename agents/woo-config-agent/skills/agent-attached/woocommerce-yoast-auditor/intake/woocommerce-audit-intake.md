# WooCommerce Audit Intake

## When to load

Load only for WordPress sites running WooCommerce core and WooCommerce extension-plugin audit scope.

## Questions

Collect only what is relevant:

- Store type: catalogue, quote-led, transactional or mixed.
- Product types: simple, variable, grouped, bundled, subscription or custom.
- Variation complexity and important variable products.
- Important product categories and commercial landing pages.
- Filter/facet behaviour and whether filtered URLs are crawlable.
- Product identifier availability: SKU, GTIN, MPN, brand.
- Known schema, duplicate content, canonical or sitemap concerns.
- Launch or migration status if relevant.

## Routing note

Audit existing output here. Route setup or default template design to `woocommerce-yoast-configuration`.
