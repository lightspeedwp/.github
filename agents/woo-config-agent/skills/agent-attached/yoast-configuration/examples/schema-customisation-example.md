# Example: schema customisation handoff

"We need to customise Organization schema for a client with multiple brands."

- `references/schema-reference.md`

1. Confirm goal: vocabulary validity, Google eligibility, entity modelling, plugin conflict, or custom data mapping.
2. Verify official Yoast schema API and relevant schema-piece docs before naming hooks or filters.
3. Recommend graph-aware extension rather than duplicate hard-coded JSON-LD.
4. Require JSON-LD validation, rendered output checks and regression coverage.
5. Mark unsupported implementation details as pseudo-code.
