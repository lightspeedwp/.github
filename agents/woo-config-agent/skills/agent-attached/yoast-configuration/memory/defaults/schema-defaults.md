# Schema defaults

- Prefer Yoast's connected schema graph over isolated custom JSON-LD.
- Keep organisation/person data accurate.
- Do not add duplicate schema plugins without conflict checks.
- Validate Schema.org vocabulary separately from Google rich-result eligibility.
- Treat FAQ and HowTo schema as useful structure but not guaranteed Google rich-result wins.
