# Example: migration audit

## Input

"Prepare Yoast SEO launch QA for a rebuild where URLs changed."

## Expected route

- `intake/migration-intake.md`
- `profiles/migration-rebuild.md`
- `references/qa-checklists.md`
- `templates/launch-qa-checklist.md`

## Example output shape

1. Request or identify old/new URL map, redirect plan, old metadata, current sitemap, robots.txt, and Search Console context.
2. Check staging leakage, canonicals, noindex rules, XML sitemaps, schema, social metadata and redirects.
3. Validate representative high-value URLs before launch and after launch.
4. Avoid promising Google indexing or ranking outcomes.
