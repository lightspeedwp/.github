# Yoast launch QA checklist

- [ ] Confirm active Yoast products and versions.
- [ ] Confirm production visibility and remove staging blocks only at launch gate.
- [ ] Check homepage metadata, canonical, robots and schema.
- [ ] Check representative posts/pages/CPTs/taxonomies/archives.
- [ ] Check WooCommerce product/product category/tag/shop pages if applicable.
- [ ] Check sitemap index and submitted sitemap URL.
- [ ] Check robots.txt and llms.txt if enabled.
- [ ] Check breadcrumbs and schema graph.
- [ ] Check redirects and canonical alignment for migrations.
- [ ] Record evidence and unresolved risks.
