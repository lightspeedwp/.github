# Example: standard business site Yoast configuration

## Input

"Configure Yoast for a five-page lead-generation WordPress site with a blog and service pages."

## Expected route

- `intake/client-site-intake.md`
- `profiles/business-website.md`
- `references/configuration-reference.md`
- `templates/yoast-configuration-report.md`

## Example output shape

1. Confirm assumptions: business site, non-ecommerce, no migration unless stated.
2. Recommend Yoast SEO Free as a baseline unless Premium features are operationally required and verified.
3. Configure site representation, homepage metadata, pages, posts, categories, media, author/date archives, sitemaps, schema, breadcrumbs and social metadata.
4. QA rendered output on homepage, service page, blog post, category archive and contact page.
5. Flag exact UI paths and product packaging as `needs live verification`.
