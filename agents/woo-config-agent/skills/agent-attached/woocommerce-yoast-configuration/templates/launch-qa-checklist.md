# Yoast launch QA checklist

## Scope

- Site/project:
- Environment:
- Launch type: new site / redesign / migration / WooCommerce / schema change / plugin upgrade
- Access level:

## Pre-launch

- [ ] Yoast product mix confirmed.
- [ ] Search appearance configured and reviewed.
- [ ] Content-type indexation decisions approved.
- [ ] Taxonomy/archive indexation decisions approved.
- [ ] Attachment URL behaviour checked.
- [ ] Author/date/search archives checked.
- [ ] XML sitemap index and child sitemaps checked.
- [ ] robots.txt reviewed.
- [ ] llms.txt reviewed if enabled.
- [ ] Canonicals checked on representative URLs.
- [ ] Meta robots checked on representative URLs.
- [ ] Schema graph checked on representative URLs.
- [ ] Breadcrumbs checked if enabled.
- [ ] Open Graph/Twitter/X metadata checked.
- [ ] WooCommerce product/category/tag/facet output checked if relevant.
- [ ] Redirect map checked if migration/rebuild.
- [ ] Developer customisations tested if relevant.

## Launch-day

- [ ] Live rendered source matches approved staging output.
- [ ] Sitemap URLs return 200 and contain expected URLs.
- [ ] No accidental sitewide noindex or robots block.
- [ ] Canonicals point to live final URLs.
- [ ] Redirect samples pass.
- [ ] Search Console property and sitemap submission tasks recorded.

## Post-launch

- [ ] Crawl representative pages.
- [ ] Check Search Console coverage and sitemap processing.
- [ ] Check product/schema warnings where relevant.
- [ ] Record issues, owners, and retest dates.
