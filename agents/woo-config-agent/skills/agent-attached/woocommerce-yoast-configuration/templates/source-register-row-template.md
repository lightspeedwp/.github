# Source register row template

Use this template when adding or refreshing a source-register row.

```text
| Page title | URL | Source type | Product or feature area | Key facts | Configuration relevance | Developer relevance | Limitations/version notes | Duplicate status | Verification status | Accessed date |
|---|---|---|---|---|---|---|---|---|---|---|
|  |  | confirmed yoast documentation / developer api behaviour / product marketing claim / google search behaviour / schema vocabulary / wordpress core behaviour / woocommerce behaviour / weak supporting evidence |  |  |  |  |  | Unique / Duplicate preserved; canonical scan target / Duplicate preserved; do not rescan unless redirect/content differs | research target / scanned evidence / verified current source / needs live verification / stale evidence / contradicted evidence | YYYY-MM-DD |
```

## Row quality checklist

- Page title matches the actual page title at time of scan.
- URL is canonical where known; duplicates are preserved with duplicate status.
- Key facts are specific and do not include unsupported interpretation.
- Configuration relevance explains what a Yoast setup/audit decision can use the source for.
- Developer relevance says whether the source supports APIs, filters, schema pieces, metadata presenters, sitemap logic, indexables or code customisation.
- Limitations include version sensitivity, UI volatility, product packaging caveats or Google/Search eligibility caveats.
- Verification status matches the evidence state model.
- Accessed date is only filled after a real scan.
