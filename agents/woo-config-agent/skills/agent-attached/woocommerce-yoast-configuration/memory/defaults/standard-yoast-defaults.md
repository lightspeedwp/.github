# Standard Yoast defaults

Use as memory-style defaults only after confirming they match agency policy.

- Configure site representation accurately.
- Index only valuable public content.
- Avoid indexing thin tags, internal taxonomies, internal search results and duplicate archives unless justified.
- Align noindex, canonical and sitemap behaviour.
- Validate schema and metadata on representative URLs.
- Verify current UI paths before client instructions.
