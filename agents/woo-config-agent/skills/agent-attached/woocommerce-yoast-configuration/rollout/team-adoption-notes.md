# Team adoption notes

Use this when multiple team members will use the Yoast configuration skill.

## Team rules

- Use the skill for Yoast-specific setup, audit, WooCommerce SEO, schema, developer handoff, source-register, and QA work.
- Do not use it as a generic SEO strategy replacement.
- Treat client-facing recommendations as evidence-bound.
- Ask for the smallest missing evidence only when it changes the decision.
- Use templates for repeatable outputs.
- Add scenario tests when a real-world failure or gap appears.

## Handoff boundaries

- Content gaps go to content planning or editorial owners.
- Code-level filters/API changes go to developer handoff.
- Google Search interpretation should be source-backed and caveated.
- WooCommerce product data issues should be separated from Yoast configuration.
