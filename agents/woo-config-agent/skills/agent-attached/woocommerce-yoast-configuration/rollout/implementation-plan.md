# Implementation plan

Use this when rolling the Yoast configuration skill into an agency workflow.

## Phase 1: internal pilot

1. Use the skill on one standard business site, one WooCommerce site, and one migration/rebuild.
2. Capture missing intake questions, weak recommendations, and QA gaps.
3. Update intake, profiles, QA, and templates from the pilot.

## Phase 2: reference maturity

1. Run the research workflow against the primary Yoast source register.
2. Update capability, configuration, feature, schema, WooCommerce, and developer references with scanned evidence.
3. Mark unresolved items as `unclear from available sources` or `needs live verification`.

## Phase 3: team adoption

1. Share the usage guide and report templates.
2. Define which deliverables are internal-only versus client-facing.
3. Add scenario tests for every repeated workflow.
4. Version the skill package and changelog every release.
