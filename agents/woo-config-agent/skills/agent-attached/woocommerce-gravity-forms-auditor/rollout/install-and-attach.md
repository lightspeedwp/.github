## Package installation

1. Upload `skill.zip` to the LightSpeed workspace skill library.
2. Confirm the skill appears as `woocommerce-gravity-forms-auditor`.
3. Attach it to WooCommerce-focused shared agents alongside, not instead of, `woocommerce-gravity-forms-configuration`.

## Attach to WooCommerce Configuration Agent

- Add this skill for read-only WooCommerce Gravity Forms audits, preflights, findings registers, and remediation handoffs.
- Keep `woocommerce-gravity-forms-configuration` attached for approved configuration changes.
- Use it for product enquiry, quote request, stock or availability enquiry, B2B/wholesale, deposit/payment risk, customer registration risk, order-support, customer-account support, WooCommerce extension-related form flows, and product page embed audits.
- Route checkout/tax/order/subscription/stock/shipping/refund/fulfilment architecture outside this skill unless a Gravity Forms subset is explicitly scoped and approved.

## Recommended pairing

- `woocommerce-gravity-forms-auditor`: inspect, assess, score, report, and hand off WooCommerce Gravity Forms findings.
- `woocommerce-gravity-forms-configuration`: verify current state, plan, configure, validate, and report approved WooCommerce Gravity Forms changes.
