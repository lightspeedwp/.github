# Public Poll

Use for editorial polls, quick audience feedback, or campaign questions.

## Recommended stance

- Require Polls Add-On detection before using Poll fields, Poll block, Poll widget, or poll shortcode.
- Decide whether visitors see results before voting, after voting, or not at all.
- Warn that visible results can influence later votes.
- Do not use public polls for high-stakes decisions without anti-abuse and data-quality controls.

## Suggested fields

1. Poll question.
2. Poll choices.
3. Optional consent if responses are tied to personal data.
4. Optional hidden campaign/source fields only when attribution is approved.

## Validation

- Test result display settings.
- Test spam controls and repeat submission behaviour.
- Check page cache/CDN impact if results appear stale.
