## Goal

Collect community story submissions from readers while keeping editorial control over what becomes public content.

## Recommended stance

- Entry-first moderation if Advanced Post Creation is not available.
- Draft or Pending Review post status if Advanced Post Creation is available and approved.
- No automatic public publishing from anonymous users.
- File uploads limited to images or PDFs that editorial staff actually need.

## Suggested fields

- Submitter name.
- Submitter email.
- Community area.
- Story title.
- Story summary.
- Full story.
- Photo upload, optional.
- Photo credit/rights confirmation.
- Consent/privacy acknowledgement.

## Feed notes

Use Advanced Post Creation only when installed and active. Map from standard/advanced fields, not Post Fields. Use Draft or Pending Review, map title/content deliberately, and only copy uploads to the Media Library when editorial ownership and rights checks are confirmed.

## Handoff

Send entries or generated draft posts to the editorial owner with a checklist covering spam, privacy, image rights, taxonomy, claims, and publish readiness.
