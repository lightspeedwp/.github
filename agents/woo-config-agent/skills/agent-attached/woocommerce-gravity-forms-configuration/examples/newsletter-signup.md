# Newsletter signup example

Use this as a lightweight Gravity Forms pattern for consent-based newsletter capture.

## Default fields

- First name, optional.
- Email address, required.
- Marketing consent, required.

## Configuration stance

- Keep visible labels.
- Use a concise confirmation message.
- Use a domain-aligned From address and submitter Reply-To only where useful.
- Add list-sync feeds only after the email marketing add-on and target list are confirmed.
- Record consent wording and retention assumptions in the handoff.

## Testing

- Submit a valid email and consent.
- Submit an invalid email and confirm validation is useful.
- Confirm entry creation.
- Confirm admin notification.
- Confirm list feed only on staging/test list before production sync.
