# Customer Satisfaction Survey

Use for a post-project, post-support, or post-purchase feedback form.

## Recommended stance

- Use the Survey Add-On only if installed and active.
- Keep the form short and avoid collecting personal data unless follow-up is required.
- State whether responses are anonymous, pseudonymous, or identified.
- Use Likert/Rating questions with clear scale labels.
- Keep results internal unless the client explicitly approves public reporting.

## Suggested fields

1. Overall satisfaction rating.
2. Likert matrix for service quality, communication, value, and speed.
3. Free-text improvement question.
4. Optional follow-up consent.
5. Optional name and email shown only when follow-up consent is selected.

## Validation

- Submit with and without follow-up consent.
- Check survey result view and entry export behaviour.
- Confirm notifications do not expose sensitive feedback beyond approved recipients.
