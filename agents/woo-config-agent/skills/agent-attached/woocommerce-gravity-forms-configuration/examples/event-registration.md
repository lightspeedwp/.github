# Example: event registration form

Use for simple event interest or attendance registration where WooCommerce ticketing is not required.

## Recommended fields

- Name
- Email
- Phone, optional
- Event/session choice
- Number of attendees
- Accessibility or dietary notes, optional
- Consent

## Feeds

- Admin notification to event owner.
- User confirmation email if email deliverability is validated.
- Marketing/CRM feed only when consent and add-on connection are confirmed.
- Payment feed only when the event requires a Gravity Forms payment flow and test mode is approved.

## Guardrails

- Do not use as a full ticketing/seat-allocation system unless scoped and approved.
- Avoid collecting unnecessary health or identity data.
- If payments are involved, use the payment feed risk workflow.
