Use this reference for the default form expectations on a WooCommerce store.

## Core forms

- Contact form
- Product or order enquiry form when needed
- Newsletter or marketing signup form where used
- Returns, wholesale, or trade enquiry form only when the store model requires it

## Standard expectations

- Required fields are concise and only collect what is needed
- Notification routing is defined and tested
- Confirmation messaging is clear and trustworthy
- Anti-spam protection is enabled
- Consent and privacy requirements are included where needed
- Form language matches the store tone and customer expectations

## WooCommerce-specific reminders

- Do not duplicate checkout fields in separate forms unless there is a clear operational reason
- Make sure enquiry forms distinguish between pre-sales, order-support, and general contact use cases when that matters
- Link to relevant store policies when forms involve returns, delivery, or privacy-sensitive requests
- Review mobile usability for all customer-facing forms

## QA reminders

- Test in incognito mode
- Test on mobile
- Confirm notification delivery
- Confirm autoresponders or confirmation messages if used
