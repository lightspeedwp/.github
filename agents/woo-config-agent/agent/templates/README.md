Use this folder for reusable output structures the agent should follow when producing recurring deliverables.

For this agent, templates should stay WooCommerce-first and support audit, implementation, QA, launch-readiness, Gravity Forms, and Yoast SEO work.

## Recommended file naming

- `<deliverable>-template.md`
- `<workflow>-template.md`

## Current templates

- `woocommerce-audit-report-template.md`
- `implementation-summary-template.md`
- `pre-launch-summary-template.md`
- `gravity-forms-plan-template.md`
- `yoast-seo-audit-template.md`
