Use this recurring prompt when you want to audit a specified attached local skill, identify the changes needed to make it fit this WooCommerce Configuration Agent, and remove stale references to the Tour Operator Configuration Agent.

## Recommended prompt

```text
Audit the specified attached local skill for fit against this WooCommerce Configuration Agent, then report the improvements needed to adapt that skill cleanly.

Primary goal:
Make the specified local skill consistent with this agent's current WooCommerce-first role, attached reference set, connected-app guidance, output standards, and maintenance boundaries.

Mandatory cleanup goal:
Find and remove or replace any stale references to the Tour Operator Configuration Agent.

Audit scope:
1. Review the specified local skill's instructions, metadata, default prompt language, references, workflow framing, and output assumptions.
2. Check whether the skill is clearly aligned to this WooCommerce Configuration Agent rather than an older or different agent identity.
3. Check whether the skill's terminology, task framing, deliverables, and evidence standards match this agent's current WooCommerce-first role.
4. Check whether the skill relies on stale assumptions about:
   - agent name or role
   - connected apps
   - attached references
   - output standards
   - maintenance boundaries
   - unsupported folders, files, or workflows
5. Check whether the skill still contains any references to the Tour Operator Configuration Agent, tour-operator workflows, or adjacent domain language that no longer fits this agent.
6. Check whether the skill should now reference WooCommerce, Yoast, Gravity Forms, accessibility, implementation-planning, remediation-triage, or internal maintenance boundaries differently to match the current agent.

Adaptation rules:
- Treat this WooCommerce Configuration Agent's current main instructions, attached local skills, attached file tree, and grounded connected apps as source of truth.
- Keep the agent WooCommerce-first.
- Preserve narrow skill purpose where it is still valid.
- Prefer replacing stale wording over layering duplicate guidance.
- Remove Tour Operator Configuration Agent references completely when found.
- Replace stale cross-domain wording only where the current agent's grounded role justifies the change.
- Do not invent unsupported apps, files, references, routes, folders, schemas, or workflows.
- Do not broaden the skill into generic WordPress consulting unless the current agent's instructions already require that.

Deliverables:
1. Audit summary
   - what the skill currently does
   - whether it fits this WooCommerce Configuration Agent cleanly
   - where it still reflects older or mismatched agent identity

2. Required improvements
   - exact wording, routing, reference, metadata, or workflow changes needed
   - exact Tour Operator Configuration Agent references or adjacent stale wording that must be removed or replaced
   - any WooCommerce-specific alignment changes needed

3. Adaptation plan
   - the minimum safe edits needed to make the skill fit this agent
   - any file-level follow-up work needed
   - any validation checks that should be run after editing

4. Risk notes
   - any ambiguous areas where the correct WooCommerce replacement wording is not fully grounded
   - any places where the skill should stay narrower instead of being over-adapted

Acceptance criteria:
- No Tour Operator Configuration Agent references remain.
- The specified skill reads as part of this WooCommerce Configuration Agent's workflow set.
- The skill's role, wording, and outputs align with the current grounded agent configuration.
- The audit clearly separates confirmed issues from suggested improvements.
```

## Use notes

- Use this for audit-first adaptation work on an existing attached local skill.
- Name the exact local skill being audited when you run the prompt.
- Treat the current attached configuration as canonical when older skill wording disagrees.
- Keep the pass conservative: remove drift and adapt the skill, but do not repurpose it beyond this agent's grounded role.
