## Purpose

Use this folder for worked examples and sample deliverables that show the expected shape of common WooCommerce agent outputs.

Examples illustrate output style and structure, but they are not the canonical policy source when a matching reference, schema, or instruction rule exists elsewhere.

## Naming conventions

Use names that clearly describe the example's scenario or deliverable:

- `example-<scenario>.md` for worked scenario outputs
- `sample-<deliverable>.md` for sample deliverables
- `<subject>-example.json` for structured examples

## File inventory

No example files are currently grounded in the attached file tree beyond this README.

If example files are added later, keep the inventory aligned to the attached examples that are actually present.

## Canonical role rules

- Treat examples as illustrative patterns, not source-of-truth policy.
- Keep examples aligned with the current instructions, schemas, and templates they demonstrate.
- Remove or update example references when the examples themselves are not attached.
