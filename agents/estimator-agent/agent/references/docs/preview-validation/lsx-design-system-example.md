LSX Design System

## Core references

- GitHub repository: <https://github.com/lightspeedwp/lsx-design-2025>

## Suggested uses

Use this context when testing workflows such as:

- evidence gathering from a product or design-system website
- feature and scope assessment from a live and demo experience
- package routing for a design-system-led or product-led website project
- add-on identification from documentation, repo, component-library, or system complexity
- estimate drafting grounded in website, repository, design-system, and documentation references
- readiness-review checks before treating a quote as final

## Source priority notes

Use sources in this order unless the test specifically requires a different path:

1. Installed agent files and commercial rules
2. Live site and demo evidence
3. Google Drive specifications and project documentation
4. Figma design-system references
5. GitHub repository evidence

## Example preview seed

Use LSX Design System as the test project. Review the live site, demo environment, and supporting references first. Separate confirmed facts from assumptions, identify any missing routing inputs, recommend the best-fit base package, and note only the add-ons that materially apply.
