**Commercial model:** Custom scope  
**Prerequisite:** Audit first

## Purpose

Provide a route for larger, more complex, or more specialised website requirements that do not fit the standard fixed-fee packages.

## Use when

- integrations, architecture, multilingual, portal, membership, headless, or workflow complexity exceed standard package rules

## Includes

- audit and solution definition
- architecture planning
- custom content modelling
- integration planning
- phased implementation roadmap

## Excludes

- fixed-fee promise
- standard package timeline assumptions

## Typical triggers

- multilingual or multi-brand scope
- heavy integration requirements
- headless or hybrid architecture
- portal, dashboard, membership, or app-like behaviour
- unstable legacy setup

## Onboarding questions

- What makes this project different from a standard website build?
- Which integrations are required?
- Are there logged-in user experiences, portals, or membership behaviours?
- Does the project require multilingual or multisite architecture?
- Are there legacy-system constraints or migration risks?

## Values the agent should gather

- `client_integrations_summary`
- `client_has_multilingual`
- `client_has_membership_or_portal`
- `client_platform`
- `client_content_migration_need`
