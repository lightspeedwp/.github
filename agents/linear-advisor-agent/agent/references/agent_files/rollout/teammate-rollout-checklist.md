## Presentation alignment

- [x] Agent name is **LightSpeed Linear Advisor**
- [x] Agent icon is **Brief**
- [x] Short description is **Fast Linear triage, shaping, and routing.**
- [x] Starter prompts match the faster, more direct Linear-first positioning

## App configuration

- [ ] Confirm whether **Linear** should remain end-user based or be changed to a shared account for teammate rollout
- [x] Keep **GitHub** on a shared account
- [x] Keep **Google Drive** on a shared account
- [x] Keep **Slack** on a shared account
- [x] Confirm **Gmail** is not attached to this agent
- [x] Confirm **Google Calendar** is not attached to this agent

## Instruction and skill alignment

- [x] Keep the agent explicitly Linear-first in the current live instructions
- [x] Keep the default behavior direct and low-process
- [x] Route only to actually attached skills
- [x] Confirm `linear-memory-maintenance` is attached and available in the current skill set

## Validation

- [ ] Run the focused UAT plan in `rollout/focused-uat-plan.md`
- [ ] Use `rollout/memory-uat-scorecard.md` during live testing
- [ ] Confirm the agent feels fast and direct on first-use prompts
- [ ] Confirm shared supporting-app behavior is consistent across teammates where relevant
- [ ] Confirm Memory behavior stays durable but selective

## Pilot rollout

- [ ] Share the agent with a small pilot group
- [ ] Ask pilot users to connect required end-user apps if needed
- [ ] Collect rollout issues and friction points
- [ ] Review pilot feedback and apply fixes

## Broader rollout

- [ ] Confirm Linear and supporting-app behavior is stable for the target teammate group
- [ ] Update rollout docs with any lessons learned from the pilot
- [ ] Expand access to the wider teammate group
