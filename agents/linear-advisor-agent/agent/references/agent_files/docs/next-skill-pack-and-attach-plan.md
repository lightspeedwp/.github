## 5. Current Capability Gaps Worth Watching

The agent is much more complete now, so remaining gaps should be treated as optional enhancements rather than missing basics.

### Possible future additions

#### A. Acceptance Criteria Specialist

**Why it may help**

The template pack now includes acceptance-criteria patterns, but there is not yet a dedicated specialist for turning rough scope into sharper done definitions at scale.

**Only worth adding if**

- the agent frequently receives issue drafts that are otherwise strong but consistently weak on reviewable acceptance criteria; or
- acceptance-criteria drafting becomes a repeated narrow use case of its own.

#### B. Client Request Normalizer

**Why it may help**

The new client-brief conversion skill already covers this partially, but a narrower normalizer could be useful if the team sees repeated vague client language that needs cleaning before fuller conversion.

**Only worth adding if**

- client-facing material repeatedly needs normalization before any other specialist can work well; and
- that job becomes meaningfully different from the current client-brief converter.

#### C. Source and Claim Review Specialist

**Why it may help**

If more public-facing or risk-sensitive client outputs emerge, a narrower specialist for evidence strength, claims, exclusions, and review gates may become useful.

**Only worth adding if**

- the agent increasingly handles public-facing material, regulated claims, pricing claims, or external publication workflows.

---

## 6. Current Recommendation On New Skills

**Do not add more specialist skills by default right now.**

The current agent is already more coherent than it was before, and the higher risk now is **over-specialization** rather than undercoverage.

Prefer to:

1. test the current skill boundaries in preview;
2. tighten the routing when overlap appears;
3. improve reference files and template packs; and only then
4. add a new skill if a repeated narrow job still has no clean home.

---

## 7. Best Next Improvements Before New Skills

Higher-value work than adding another skill immediately:

- keep the routing guide aligned with real preview behavior;
- expand the template pack where repeated patterns emerge;
- continue cleaning outdated historical docs;
- improve questionnaire-backed client conversion examples if needed; and
- test real boundary cases such as converter vs architect, converter vs gap analyzer, and architect vs sub-issue splitter.

---

## 8. When To Actually Add Another Skill

Add a new specialist skill only if all of these are true:

- the job appears repeatedly;
- the job is narrow and distinct;
- the current routing guide cannot absorb it cleanly;
- the existing specialist skills would become muddier if stretched to cover it; and
- a dedicated skill would reduce confusion rather than create another overlap problem.

---

## 9. Final Roadmap Verdict

The agent no longer needs a major "next skill pack" in the old sense.

It now needs:

- disciplined use of the current skill set;
- cleaner references and templates;
- selective preview testing; and
- only occasional targeted capability additions where repeated gaps are proven.

That is the healthier roadmap for the current Linear Workflow Skill Factory.
