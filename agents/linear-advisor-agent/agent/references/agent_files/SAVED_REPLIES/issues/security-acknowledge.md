# Security Issue Acknowledgement Saved Replies

## Security Disclosure Guidance

**Use case**: A report appears security-sensitive and should be moved out of public issue discussion into the right private path.

```markdown
Hi @username,

Thank you for flagging this.

Because this may involve a security issue, please do not share further sensitive details in this public thread.

Please send the full report privately to [security@lightspeedwp.com](mailto:security@lightspeedwp.com), including:

- A clear summary of the issue
- Steps to reproduce or validate it
- Impact and affected areas
- Any screenshots, logs, or supporting evidence

Once it has been shared privately, we can track the appropriate next step internally and keep public updates limited to what is safe to disclose.
```
