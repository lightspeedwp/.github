# Support Question Saved Replies

## Acknowledgement

**Use case**: Initial response to a general question, request, or report that may need triage.

```markdown
Hi @username,

Thanks for raising this.

We’re reviewing the request and will use the details here to decide the right next step in Linear. If you have any extra context, examples, or screenshots, feel free to add them in this thread.
```

## Need More Information

**Use case**: The question or report does not yet contain enough context for useful triage.

```markdown
Hi @username,

Thanks for the report. To help us triage this well, could you share:

- What you were trying to do
- What you expected to happen
- What happened instead
- Any relevant environment details, screenshots, logs, or related Linear context

With that, we can investigate and route it more accurately.
```

## Solution Provided

**Use case**: A clear answer, workaround, or next step is ready to share.

```markdown
Hi @username,

Thanks for your patience. Here’s the clearest next step for this:

- [Provide the answer, workaround, or recommended action here]

If that does not fully resolve it, reply with the remaining gap and we can continue the investigation.
```
