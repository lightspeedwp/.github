# Needs Reproduction Saved Reply

## Request for Reproducible Example

**Use case**: The issue may be real, but the current report is not specific enough to investigate or route with confidence.

```markdown
Hi @username,

Thanks for reporting this. To investigate it properly, we need a minimal reproducible example or a clearer reproduction path.

If possible, please add:

- Exact step-by-step reproduction instructions
- Expected result vs. actual result
- URLs, screenshots, logs, or recordings that show the issue
- Relevant environment details or related Linear references

Once we can reproduce the behavior, we can continue investigation and route the issue more accurately.
```
