# Needs More Information Saved Replies

## Request More Info

**Use case**: A Linear issue cannot be triaged, routed, or scoped confidently because key context is still missing.

```markdown
Hi @username,

Thanks for logging this. Before we can move it forward in Linear, we need a bit more context:

- [ ] What problem are you seeing, in one clear sentence?
- [ ] What did you expect to happen, and what happened instead?
- [ ] Exact steps to reproduce, if this is a bug or inconsistent behavior
- [ ] Impact: who is affected, how often it happens, and how urgent it is
- [ ] Relevant screenshots, logs, links, or related Linear issues/docs if available

We’ve kept this in `status:needs-more-info` until that context is added. Once we have it, we can continue triage and route it properly.
```
