# Output Templates

Use these templates when creating Linear workflow skills.

## Skill Summary Template

```markdown
## Skill summary
- Purpose:
- Main triggers:
- Inputs:
- Outputs:
- Sources/tools:
- Domain boundaries:
- Risks:
- Safe defaults:
```

## Status Update Template

```markdown
## Summary
[One-paragraph summary]

## Progress
- [Completed or moved forward]

## Risks and blockers
- [Risk or blocker]

## Next steps
- [Planned next step]
```
