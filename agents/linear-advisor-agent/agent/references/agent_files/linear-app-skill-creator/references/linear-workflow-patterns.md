# Linear Workflow Patterns

Use this reference when creating skills for Linear-centred workflows.

## Common Skill Types

### Issue triage skills

Use for skills that classify, enrich, route, deduplicate, prioritise, or prepare issues for human review.

### Planning and roadmap skills

Use for skills that support project planning, initiative shaping, cycle preparation, dependency review, or roadmap communication.

### Status update skills

Use for skills that draft or review project or initiative updates.

### Customer-request analysis skills

Use for skills that review customer requests, aggregate themes, and turn raw input into planning signal.

### Documentation and coordination skills

Use for skills that help draft docs, comments, hand-off notes, or workflow instructions tied to Linear work.

## Workflow Boundaries

- Read-only analysis: summarise, assess, compare, classify, or recommend without changing records.
- Drafting support: prepare issue text, comments, documents, or updates for review.
- Workflow guidance: define triage, planning, or review behaviour without pretending to execute it.
- Write-oriented skills: describe when creation or updating is appropriate, but make review points explicit when the workflow could alter commitments or planning.

## Quality Gates

For Linear workflow skills, check clarity, evidence handling, prioritisation logic, workflow fit, hand-off quality, and safety.
