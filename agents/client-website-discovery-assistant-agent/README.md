# Client Website Discovery Assistant Agent Export

This export contains only files that were readable in the current container environment.

It includes:

- Visible workspace agent files from `/workspace/AGENTS.md`, `/workspace/agent_files`, and non-git memory context.
- Locally readable skill folders from `/root/.codex/skills`.
- Locally readable plugin-provided skill folders from `/root/.codex/plugins/cache/openai-marketplace`.
- Manifests describing exported files, skill inventory, inaccessible/protected resources, redactions, and checksums.

It does not include hidden system or developer messages, connector credentials, authentication tokens, protected platform internals, or unreadable external resources.
