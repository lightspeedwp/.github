# Pattern and Template QA

## Pattern QA

Check each pattern for:

- name
- category
- source Figma section
- intended page/template use
- placeholder content
- editable areas
- block hierarchy
- responsive behaviour
- light/dark mode behaviour
- accessibility states
- editor usability

## Template QA

Check each template for:

- header/footer consistency
- correct template part usage
- content hierarchy
- breadcrumbs where relevant
- metadata placement
- CTA placement
- related content blocks
- schema opportunities
- mobile behaviour

## Matrix columns

Use:

- template/pattern name
- Figma reference
- WordPress reference
- expected result
- desktop status
- tablet status
- mobile status
- accessibility status
- issue severity
- owner
