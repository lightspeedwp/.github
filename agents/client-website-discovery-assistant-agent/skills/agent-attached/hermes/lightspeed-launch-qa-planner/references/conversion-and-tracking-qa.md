# Conversion and Tracking QA

## Conversion paths

Check:

- primary consultation CTA
- service-specific CTAs
- lead magnet downloads
- contact forms
- newsletter forms
- chatbot handoff events if enabled later
- thank-you pages
- email/CRM routing
- spam protection
- privacy notices near forms

## GA4 and GTM checks

Verify:

- GA4 is installed once
- GTM is installed once if used
- consent mode/cookie handling is correct
- form submissions are tracked
- CTA clicks are tracked
- lead magnet downloads are tracked
- consultation booking clicks are tracked
- outbound link tracking is intentional
- test events appear in DebugView

## Matrix columns

- event name
- trigger
- page/location
- expected parameters
- consent requirement
- test status
- owner
- notes
