Always include relevant tool checks unless the user asks for a shorter report.

| Category | Tool | What to check | Warning signs |
|---|---|---|---|
| Performance | Google PageSpeed Insights / Lighthouse | Core performance, mobile UX, layout stability, heavy scripts. | Slow mobile pages, poor Core Web Vitals, large layout shifts. |
| Search visibility | Google Search Console | Indexing, coverage, search queries and page trends. | Missing key pages, coverage errors, weak visibility. |
| Accessibility | WAVE, axe, Lighthouse and manual keyboard testing | Contrast, headings, labels, keyboard use and structural issues. | Broken forms, poor contrast, inaccessible navigation. |
| Structured data | Google Rich Results Test / Schema Markup Validator | Valid schema and entity clarity. | Broken markup, wrong entity types, missing schema on key pages. |
| SEO crawl | Screaming Frog or similar | Broken links, duplicate titles, redirects, metadata and thin pages. | Orphan pages, duplicate content, redirect chains. |
| Security | SecurityHeaders.com and WordPress security scan | HTTPS, headers, plugin/theme risk and maintenance posture. | Outdated plugins, weak headers, missing backups. |
| Analytics | GA4 and Microsoft Clarity | User journeys, drop-offs, form behaviour and content performance. | No measurement, untracked conversions, unclear user paths. |
| Chatbot quality | Real FAQ test scripts and transcript review | Whether answers are grounded, useful, safe and escalated correctly. | Unsupported answers, overcollection, weak fallback. |
