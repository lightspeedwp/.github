# Recommended Content Collection Folder Structure

Use this structure when creating a downloadable zip or Google Drive folder plan.

```text
client-content-collection/
├── README.md
├── 01-brand-and-company-information/
├── 02-website-content-drafts/
├── 03-products-services-or-offers/
├── 04-policies-and-compliance/
├── 05-images-video-and-media/
├── 06-ai-and-chatbot-source-content/
├── 07-approved-final-versions/
└── 08-open-questions-and-gaps/
```

## Naming convention

```text
YYYY-MM-DD-client-topic-status-owner.ext
```

Examples:

```text
2026-04-26-acme-service-pricing-approved-jane.xlsx
2026-04-26-acme-faq-draft-marketing.docx
2026-04-26-acme-returns-policy-legal-review.pdf
```
