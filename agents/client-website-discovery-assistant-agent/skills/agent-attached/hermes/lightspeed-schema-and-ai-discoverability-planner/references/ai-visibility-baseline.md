## Purpose

Create a repeatable monthly baseline for how the brand, services and priority topics appear in AI/search surfaces.

## Surfaces to check

- Google Search and AI Overviews where available
- ChatGPT
- Perplexity
- Gemini
- Claude
- Bing/Copilot where relevant

## Query groups

| Query group | Examples | Notes |
|---|---|---|
| Branded | What is LightSpeedWP Agency? | Check accuracy and positioning. |
| Service intent | WordPress agency for WooCommerce redesign | Check whether LightSpeed appears or is describable. |
| Sector intent | WordPress publishing platform agency | Check sector relevance. |
| AI readiness | AI readiness audit for WordPress websites | Check positioning and competitors. |
| Comparison | LightSpeedWP alternatives / WordPress design system agency | Check sentiment and accuracy. |

## Tracking fields

| Date | Surface | Query | Mentioned? | Cited? | Position/summary | Accuracy | Source cited | Issue | Action |
|---|---|---|---|---|---|---|---|---|---|

## Caution

AI visibility fluctuates. Treat this as monitoring and improvement, not a guaranteed ranking channel.
