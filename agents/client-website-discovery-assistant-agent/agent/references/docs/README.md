# Documentation Map

Use this file as the top-level guide for the agent's documentation files.

## Purpose
This folder explains how the agent should use the attached control documents before it selects or fills specific output templates.

## Files in this folder
- `docs/output-template-library.md` — the primary guide for choosing the right discovery output template and understanding what each template is for.

## Usage rules
1. Read this file first when the task depends on attached documentation but the correct control file is not obvious.
2. Use `docs/output-template-library.md` to decide which template file in `templates/` best matches the requested deliverable.
3. If a task depends on broader business framing, also consult `business-context.md`.
4. If a task depends on app usage or external systems, also consult `CONNECTORS.md`.
5. If future supporting reference files are added under `references/`, use `references/README.md` to understand how they should be applied.
