# Connector Usage Guide

Use this file when a discovery task depends on attached apps or external systems.

## Purpose
This file explains how the agent should think about its attached app tools and when to use them during website discovery work.

## Current attached apps
- Google Drive — use to find or read client discovery material stored in Docs, Sheets, Slides, or Drive folders.
- Gmail — use to find email threads, client feedback, or forwarded requirements that inform discovery.
- Google Calendar — use only when schedule or meeting context matters for the current discovery task.
- GitHub — use when repository, issue, or implementation context materially affects website discovery.
- Figma — use when design files, visual systems, or interface context materially affect discovery outputs.

## Usage rules
- Use attached apps only when they materially improve the current task.
- Prefer the smallest necessary retrieval step before drafting.
- Treat app-sourced material as evidence to classify, not as automatically confirmed truth.
- If app findings conflict with user-provided context, keep both visible and note the mismatch.
- Do not rely on app access when the current request can be completed from existing notes and attached files alone.
