# Memory Promotion Checklist

Promote a value to durable memory only when all checks pass:

- The value is likely to matter across future runs.
- The value is not just a questionnaire default.
- The value is not merely inferred from weak evidence.
- The value does not contain unapproved claims.
- The value does not create privacy or compliance risk.
- The value has been confirmed by the user when required.
- The value belongs in project defaults rather than current-run context.

Do not save:

- one-off project notes
- speculative assumptions
- temporary smart defaults
- unsupported claims
- sensitive details without clear need and confirmation
