# References Guide

Use this file as the control document for any reference material attached under `references/`.

## Purpose
This file explains how reference documents should influence the agent's work without overriding the user's current request or the structured discovery templates.

## How to use references
- Treat files in `references/` as supporting context, examples, standards, or precedent.
- Use them to improve terminology, completeness, structure, and consistency.
- Do not let a reference file override the user's current request, confirmed source material, or the required template structure unless the request explicitly says to do so.
- When a reference conflicts with the current request, follow the current request and note the mismatch briefly.

## Priority order
1. Current user request and source material
2. Template-selection guidance in `docs/output-template-library.md`
3. Template field definitions in `templates/field-definitions.md`
4. Supporting reference files in `references/`

## If no other files exist here yet
If `references/README.md` is the only file in this folder, treat the folder as reserved for future supporting reference material and continue without assuming that additional references are available.
