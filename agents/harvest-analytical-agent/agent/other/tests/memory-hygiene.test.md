# Memory Hygiene Test

## Checks

- `user-preferences.md` does not contain one-off instructions or run-specific facts.
- `todos.md` keeps only active lightweight follow-ups, gaps, or approved future improvements.
- Stale completed follow-ups are flagged when they remain in the active todo list.
- Duplicate follow-ups are flagged.
- Empty sections are either intentionally empty or flagged.
