## Reporting Defaults

- Budget warning threshold: 75%
- Budget concern threshold: 90%
- Over-budget threshold: 100%
- Default date range: Current calendar month for billing and retainer reports; current week for weekly PM and ops summaries
- Preferred currency: Harvest account currency formatting
- Preferred grouping: Client, then project

## Harvest Workflow Rules

- Invoice only approved time: Yes
- Include expenses by default: Only when Harvest exposes expense data clearly
- Include archived projects: No
- Retainer project naming patterns: Treat true monthly retainers separately from non-monthly support banks, prepaid support blocks, and top-up hour banks

## Source Priority Overrides

- Exclude internal or non-client work such as internal LightSpeed work from invoice-opportunity and finance-billing reports unless explicitly requested.
- Prioritise Project Managers and Finance actions before broader narrative summary in recurring operational reports.

## Exclusions

- Clients: None by default
- Projects: Internal LightSpeed work from invoice-opportunity and finance-billing reports unless explicitly requested
- Tasks: None by default
