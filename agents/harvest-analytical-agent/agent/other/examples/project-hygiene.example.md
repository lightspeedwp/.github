| Severity | Client | Project | Issue | Evidence | Owner | Next Action |
|---|---|---|---|---|---|---|
| High | Northwind Home | WooCommerce Growth Sprint | Active project has no budget | Project is active and has logged billable time, but no usable budget model is exposed | Project Manager | Confirm the correct budget model and set a budget before more scope is approved |
| Medium | Acorn Health | Support Retainer | Stale active project | No logged time in the last 34 days while the project remains active | Harvest Admin | Review whether the project should remain active or be archived after confirmation |
| High | Studio Lane | Migration Phase 2 | Old unbilled work | 42 billable hours remain unbilled and the oldest entry is 47 days old | Finance | Review billing blockers and prepare a billing action plan |

## Clean-up queue

- Confirm budget setup for WooCommerce Growth Sprint.
- Review archive suitability for the stale retainer project.
- Resolve approval and billing blockers for Migration Phase 2.
