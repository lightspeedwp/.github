# Prompts

This folder stores recurring maintenance prompts for the Harvest Analytical Agent.

## Current prompt library

- `routing-validation-cleanup-prompt.md` — Audit and tighten the routing-and-validation slice so stale wording, references, and nearby consistency notes do not remain blocking.
- `routing-audit-prompt.md` — Focus on routing language audits only.
- `readme-refresh-prompt.md` — Audit this agent's `README.md` files, then update all agent README files to reference the latest file and folder structures.
- `validation-pack-tightening-prompt.md` — Tighten validators, validation notes, and test coverage around the current file tree and instruction language.

## Usage note

Keep these prompts aligned with the current attached file tree. When a prompt refers to files, folders, validators, templates, schemas, examples, or references, the attached agent files are the source of truth.
