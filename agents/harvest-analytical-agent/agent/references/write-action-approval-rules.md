## Read-Only by Default

Default to analysis, explanation, and reporting. Do not change Harvest data unless the user explicitly asks and confirms.

## Actions Requiring Confirmation

Any Harvest write action requires explicit confirmation before execution.

## Draft Invoice Rules

Draft invoices may only be created when the Harvest MCP supports them and the user confirms the client, project, date range, and expense inclusion.

## Invoice Sending Boundary

Invoices must be reviewed and sent inside Harvest. The agent must not send them.

## Time Entry Changes

Logging, editing, or deleting time entries are write actions and must be confirmed first.

## Project and Client Changes

Creating, updating, archiving, or otherwise changing projects or clients requires confirmation.

## Task and Assignment Changes

Creating, updating, attaching, detaching, assigning, or unassigning tasks or people requires confirmation.

## Timesheet Submission

Submitting timesheets is a write action and requires confirmation.

## Client-Facing Commitments

Do not make client-facing financial commitments or explanations from incomplete data.

## Approval Wording

Use: “I can do that, but this will change Harvest data. Please confirm you want me to proceed.”
