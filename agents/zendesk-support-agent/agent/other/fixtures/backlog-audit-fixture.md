## Scope

- Window: last 7 days
- Queue focus: payments and checkout

## Validation target

- Primary deliverable: backlog report
- Expected template: `templates/agent-backlog-report-template.md`
- Expected example: `examples/templates/agent-backlog-report.example.md`
- Expected profile: `profiles/default-support-profile.yaml`
- Expected schema: `schemas/backlog-audit-fixture.schema.json`

## Expected use

- Use this fixture to test backlog-report structure, section ordering, action quality, and profile-aware output defaults.
- Keep any generated examples generalized and customer-safe.
- Use it for validation and example alignment only, not as a live reporting source.
- Do not copy fixture details into Memory.

## Fixture safety rules

- Keep the queue description generalized and non-customer-specific.
- Do not add live ticket identifiers or private operational details.
- Use this fixture to validate report shape, profile alignment, and template-example parity rather than to stand in for real backlog evidence.
