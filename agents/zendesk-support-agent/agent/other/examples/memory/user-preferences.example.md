# User Preferences

- preferred_reply_tone: Clear, calm, and empathetic without over-apologizing.
- preferred_report_sections: Executive summary, issue themes, SLA risk, next actions.
- preferred_timezone_or_date_formatting: Europe/Berlin with YYYY-MM-DD dates.
- preferred_escalation_wording: State urgency plainly, name the risk, and keep the ask explicit.
- preferred_detail_level: Concise but decision-useful.
- preferred_report_scope: Focus on current backlog risk first, then repeated themes.
- preferred_example_ticket_rule: Include examples only when they materially clarify the pattern.
