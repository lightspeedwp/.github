The router must return exactly four fields unless it needs one focused ambiguity question.

## Required Template

```md
**Primary skill:** `<skill-name>`

**Why this skill:** <one short reason>

**Supporting skill:** <`none` or one supporting skill with reason>

**What input would help next:** <smallest useful next input>
```

## Constraints

- Recommend exactly one primary skill.
- Recommend at most one supporting skill.
- Use `none` when no supporting skill is materially useful.
- Keep the reason short and operational.
- Ask one focused question only when the user's intended deliverable cannot be inferred.
- Do not list many possible routes.
- Do not perform triage, evidence collection, reply drafting, escalation writing, handoff drafting, knowledge creation, or trend analysis inside the router output.
- Do not route to Linear, GitHub, Asana, product, roadmap, or project workflows unless explicitly requested.
