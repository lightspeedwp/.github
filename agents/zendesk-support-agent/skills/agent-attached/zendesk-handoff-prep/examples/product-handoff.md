- Problem: Customer expected archived listings to stay visible in historical reports, but the current UI hides archived listings from the report filter.
- Impact: Customer-reported reporting gap for one account manager preparing a quarterly review. Frequency beyond this customer is unknown.
- Owner or target team: product
- Exact ask: Confirm whether archived listings should remain selectable in historical reports, or whether this is an intended product limitation that support should document.
- Urgency/risk: medium - support can reply with limitation wording if confirmed, but the customer is awaiting a clear answer.

## Evidence

- Confirmed: Zendesk ticket ZD-10002, requester asked why archived listings disappear from historical report filters.
- Customer-reported: The report is used for quarterly performance review.
- Confirmed: Help Centre article explains archiving listings but does not mention report filter behaviour.
- Support-observed: Archived listings are not selectable in the report filter in the demo account.
- Missing: No evidence yet that other customers have raised the same issue.

- Support did not promise a product change.

## Blockers
