# Memory Policy

This skill should not rely on personal user memory.

## Safe to remember only with explicit approval

- stable Zendesk group naming conventions
- support queue ownership rules
- standard report cadence
- approved risk thresholds
- preferred report format for the shared team
- approved macro or Help Centre routing conventions

## Do not remember

- individual customer issue details
- private ticket content
- one-off report findings
- temporary backlog counts
- current SLA or CSAT results
- assumptions from a single analysis run
- personal user-specific Zendesk access details

## Shared-agent default

If a report needs a stable preference but none is approved, apply the skill defaults and state them in the evidence basis.
