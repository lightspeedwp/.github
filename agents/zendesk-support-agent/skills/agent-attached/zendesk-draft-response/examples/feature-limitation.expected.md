## Customer reply draft

At the moment, the system does not support automatically splitting one booking across multiple invoices.

The safest workaround is to adjust the invoice manually after the booking has been created, so the billing structure matches how you need to charge the customer. I would not want to present automatic split invoicing as available or planned unless that has been confirmed through the product process.
