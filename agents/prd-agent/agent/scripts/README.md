# scripts/

## Purpose
Store helper scripts that support validation, consistency checks, and agent-maintenance workflows.

## Files in this folder
- Validation helpers.
- Scaffolding or maintenance scripts.
- Utility scripts referenced by tests or rollout workflows.

## Naming conventions
- Use lowercase kebab-case.
- Use clear verb-led names, such as `validate-agent.sh` or `check-readmes.py`.
- Keep script names aligned to a single clear responsibility.
