# assets/

## Purpose
Store reusable non-template supporting assets that strengthen planning outputs without acting as worked examples.

## Files in this folder
- Diagrams that explain repeatable planning flows or system relationships.
- Supporting images and visual references used across multiple outputs.
- Downloadable support artefacts such as checklists, reference exports, or reusable visual attachments.
- Asset indexes or metadata files when an asset set needs lightweight documentation.

## Naming conventions
- Use lowercase kebab-case.
- Prefix by asset type when helpful, for example `diagram-intake-routing-v1.png` or `visual-reference-prd-structure.pdf`.
- Keep assets reusable and source-agnostic.
- Do not store filled examples here; examples belong in `examples/`.

## Distinction from examples
Assets are reusable support materials. Examples are worked planning outputs that demonstrate how the agent should behave in practice.
