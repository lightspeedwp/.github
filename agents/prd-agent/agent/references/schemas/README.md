# schemas/

## Purpose
Store structured schemas for planning artefacts, validation rules, and machine-readable references.

## Files in this folder
- JSON, YAML, or markdown schema references.
- Artefact field definitions.
- Validation-oriented structural specs.

## Naming conventions
- Use lowercase kebab-case.
- Match schema names to the artefact they define, such as `prd-schema.yaml`.
- Keep versions explicit only when multiple active schema versions are required.
