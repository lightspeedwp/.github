# intake/

## Purpose
Store the intake system that helps the agent convert rough project material into a grounded, reviewable planning starting point.

## Files in this folder
- Intake templates and field libraries.
- Source and claim control registers.
- Risk, review, approval, and memory-promotion checklists.
- Intake routing and handoff support documents.

## Naming conventions
- Use lowercase kebab-case.
- Name files by the intake control they represent, such as `claim-register.md` or `source-approval-register.md`.
- Keep intake files procedural and reusable rather than tied to one project.
