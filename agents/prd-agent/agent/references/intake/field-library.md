# Field library

## Purpose

Define the standard intake fields used across summaries, briefs, PRDs, reviews, and handoff work.

## Core fields

- project-name
- request-summary
- business-goal
- stakeholder-context
- user-context
- source-systems
- constraints
- dependencies
- delivery-stage
- confidence-level
- estimate-readiness-status

## Notes

Use these field names consistently when structuring intake and planning artefacts.
