# examples/memory/

## Purpose
Store realistic example memory files that show how durable planning memory should look in practice.

## Files in this folder
- Filled memory examples that mirror the starter files in `memory/defaults/`.
- Example records that demonstrate structured, durable continuity.
- Example memory states that can be checked against the schemas in `memory/schemas/`.

## Naming conventions
- Use lowercase kebab-case.
- Match the corresponding memory-default filename when possible, for example `activecontext.example.md`.
- Keep examples realistic, durable, and free from transient noise.
