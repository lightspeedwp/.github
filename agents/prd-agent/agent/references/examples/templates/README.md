## Purpose

Store filled example outputs that demonstrate how the canonical templates in `templates/` should look when used correctly.

## Current files in this folder

- `example-project-intake-summary.md` — strong filled example for the intake summary template.
- `example-planning-brief.md` — strong filled example for the planning brief template.
- `example-prd.md` — strong filled example for the PRD template.
- `example-technical-brief.md` — strong filled example for the technical brief template.
- `example-gap-analysis.md` — strong filled example for the gap-analysis template.
- `example-estimate-pack.md` — strong filled example for the estimate-pack template.
- `example-handoff-pack.md` — strong filled example for the handoff-pack template.
- `example-quality-review.md` — strong filled example for the quality-review template.
- `example-validation-report.md` — strong filled example for the validation-report template.

## Naming conventions

- Use lowercase kebab-case.
- Prefix worked examples with `example-`.
- Keep the filename aligned to the canonical template name when possible.

## Important distinction

These files are filled examples, not source templates. If a structure change should affect all future outputs, update the canonical file in `templates/` first, then update the matching example here
