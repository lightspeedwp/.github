## Naming conventions
- Use lowercase kebab-case.
- Prefix worked examples with `example-`.
- Keep the filename aligned to the canonical template name when possible.

## Important distinction
These files are filled examples, not source templates. If a structure change should affect all future outputs, update the canonical file in `templates/` first, then update the matching example here.
