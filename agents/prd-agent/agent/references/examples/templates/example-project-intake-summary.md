# Project intake summary

## Request summary

Create a scoped planning package for a WordPress publishing-site redesign using mixed notes, a repo link, screenshots, and a partial brief.

## What we know

- The current site is content-heavy and navigation is difficult.
- Stakeholders want improved publishing workflow support.
- The repo includes an existing theme that may constrain implementation.
- The design direction is only partially documented.

## What we do not know

- Final editorial workflow requirements.
- Analytics and accessibility baselines.
- Exact migration constraints.
- Whether content governance rules already exist.

## Assumptions

- The redesign will preserve core content architecture unless stakeholders specify a structural rewrite.
- Existing repo patterns are still relevant enough to inform technical planning.

## Risks and blockers

- Missing analytics baseline could weaken prioritisation.
- Unknown editorial constraints may affect scope.
- Partial design evidence may create false certainty around implementation effort.

## Evidence gaps

- Accessibility audit
- Analytics baseline
- Editorial workflow confirmation
- Source-of-truth design confirmation

## Recommended next artefact

Planning brief

## Next actions

Confirm workflow constraints, gather baseline evidence, validate the current design source of truth, and turn the intake into a planning brief.
