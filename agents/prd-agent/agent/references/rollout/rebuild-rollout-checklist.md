## Draft review

- system instructions reviewed
- starter prompts reviewed
- skill routing reviewed
- business context reviewed
- Phase 4 prompt path selected using `docs/phase-4-index.md`

## Validation pack execution

- validation scripts executed
- required folders and files verified
- README coverage verified
- schema and memory checks verified

## Workflow test execution

- intake workflow tested
- evidence synthesis tested
- PRD workflow tested
- estimate readiness tested
- estimate generation tested
- handoff readiness tested
- quality review tested
- memory decision tested

## App connection verification

- Google Drive verified
- GitHub verified
- Figma verified where available
- Linear verified
- Harvest verified
- Gmail verified
- any additional relevant evidence apps verified

## Skill attachment verification

- exact shared-skill matches attached where available
- local uploaded helper skills documented separately from shared-skill parity
- routing behaviour matches the source design
- unresolved exact-name gaps checked against `rollout/skill-parity-manual-resolution-checklist.md`

## Memory verification

- Memory enabled
- defaults present
- schemas present
- memory examples aligned

## Starter prompt verification

- six starter prompts present
- wording matches the intended rebuild behaviour

## Examples and fixtures verification

- examples present
- examples and templates separated correctly
- memory examples aligned with defaults and schemas
- fixtures include strong, weak, conflicting, and validator-failure cases where required

## Manual smoke tests

- mixed-input intake
- conflicting-source analysis
- strong PRD drafting
- too-early estimation refusal
- estimate-ready planning pack
- handoff-ready output

## Go-live checklist

- parity review completed
- validation issues resolved
- smoke tests passed
- known parity gaps documented
- if parity remains incomplete, the repair path is documented via `docs/phase-4-index.md` and `rollout/skill-parity-manual-resolution-checklist.md`

## Post-rebuild comparison checklist

- compare connector coverage
- compare skill coverage
- compare routing behaviour
- compare memory behaviour
- compare template consistency
- compare output quality and gap-finding strength
