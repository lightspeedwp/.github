# memory/

## Purpose
Store the durable-memory operating layer for planning continuity.

## Current files and subfolders in this folder
- `defaults/` — canonical starter memory files that define the durable continuity model.
- `schemas/` — validation-oriented schema files for durable memory records.

## Naming conventions
- Use stable, descriptive names tied to a durable planning concept.
- Keep starter memory files human-readable and updateable over time.
- Keep schema filenames explicit and validation-oriented.

## Important distinction
`memory/defaults/` is the canonical starter layer for durable planning continuity. `memory/schemas/` exists to validate that durable records remain structured, auditable, and aligned with the intended memory model.
