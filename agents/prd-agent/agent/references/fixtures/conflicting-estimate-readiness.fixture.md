# Conflicting estimate-readiness fixture

## Scenario

Different parts of the planning pack suggest opposite conclusions about estimate readiness.

## Conflicting signals

- The PRD appears mature and well structured.
- The technical brief still leaves major implementation constraints unresolved.
- Stakeholder notes imply scope is stable, but open questions suggest material uncertainty remains.
- Historical effort evidence exists, but the current delivery shape is not yet fully validated.
- Risks are documented, but not all of them are reflected in the readiness judgment.

## Expected use

Use this fixture to test estimate-readiness review, contradiction handling, and refusal to treat a superficially mature planning pack as estimate-ready when key implementation uncertainty remains.
