# Weak brief fixture

## Scenario

A planning brief exists, but it is too weak to trust as a foundation for a PRD or estimate.

## Weaknesses

- business goal is vague
- stakeholder context is incomplete
- scope boundaries are not clearly defined
- constraints and dependencies are only partially documented
- assumptions are mixed with facts
- key risks are understated or missing

## Expected use

Use this fixture to test planning-brief review, gap detection, and escalation to stronger source gathering before PRD drafting.
