# Weak handoff fixture

## Scenario
A planning pack is being treated as handoff-ready too early, even though important delivery conditions are still unresolved.

## Weaknesses
- scope has not been fully confirmed by stakeholders
- technical constraints are only partially understood
- dependencies are mentioned but not tracked clearly
- approvals required for handoff are unclear
- evidence gaps are understated, making the pack look more ready than it is

## Expected use
Use this fixture to test handoff-readiness review, blocker surfacing, and refusal to overstate delivery preparedness.
