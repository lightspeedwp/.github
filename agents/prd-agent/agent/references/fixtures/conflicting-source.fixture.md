# Conflicting-source fixture

## Scenario

The planning request includes multiple sources that disagree on scope, priorities, and implementation assumptions.

## Source conflicts

- Stakeholder notes say the redesign should preserve the current content model, but the draft brief implies a larger structural rewrite.
- A repository note suggests the current theme can be extended, while a technical comment suggests replacement may be required.
- Design screenshots imply one navigation direction, while written notes describe a different content hierarchy.
- Editorial feedback prioritises workflow efficiency, while the partial brief emphasises front-end visual change first.

## Expected use

Use this fixture to test evidence-discipline, contradiction handling, confidence control, and refusal to overstate planning certainty when source conflicts remain unresolved.
