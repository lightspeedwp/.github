# Mixed-input intake fixture

## Scenario

A publishing-site redesign request arrives with mixed planning evidence.

## Inputs

- partial stakeholder brief
- repo link
- screenshots of current navigation
- notes from an editorial call
- draft content-governance comments

## Known issues

- evidence is incomplete
- workflow priorities are not yet confirmed
- analytics and accessibility baselines are missing

## Expected use

Use this fixture to test intake normalisation, gap-finding, and recommended-next-artefact selection.
