# tests/

## Purpose
Store workflow tests, validation tests, and other repeatable checks for the agent setup.

## Files in this folder
- Workflow coverage tests.
- Validation-pack tests.
- Expected-output or fixture-linked test notes.

## Naming conventions
- Use lowercase kebab-case.
- Name tests by the workflow or check they cover, such as `test-prd-generation.md`.
- Keep names specific enough to map back to the behaviour under test.
