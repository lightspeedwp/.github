# profiles/

## Purpose
Store reusable planning profiles, stakeholder profiles, or project-type profiles that shape repeatable planning outputs.

## Files in this folder
- Audience or stakeholder profiles.
- Project archetype profiles.
- Output preference profiles where needed.

## Naming conventions
- Use lowercase kebab-case.
- Name profiles by subject, such as `stakeholder-profile-product.md`.
- Keep one profile per file where practical.
