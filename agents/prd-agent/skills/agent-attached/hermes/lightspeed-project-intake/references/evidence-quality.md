# Evidence quality

Treat a source as stronger when it is:

- current
- directly relevant
- specific
- internally consistent
- approved or clearly authoritative

Treat a source as weaker when it is:

- paraphrased from memory
- stale
- promotional rather than operational
- contradictory
- missing key context

Weak evidence can still inform assumptions, but it should not become confirmed scope.
