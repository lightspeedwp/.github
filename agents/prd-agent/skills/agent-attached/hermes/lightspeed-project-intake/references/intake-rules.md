# Intake rules

1. Start from the current request and newly supplied files or links.
2. Normalise scattered evidence into one coherent intake summary.
3. Separate:
   - confirmed facts
   - inferred assumptions
   - excluded or unapproved inputs
   - missing evidence
4. Prefer the smallest useful follow-up question set.
5. If the evidence is obviously strong enough for PRD drafting, still produce a concise intake layer first unless the user explicitly wants to skip it.
