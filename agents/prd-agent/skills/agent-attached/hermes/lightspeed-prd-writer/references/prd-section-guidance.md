# PRD section guidance

- **Evidence basis** — cite the strongest available inputs and note weak areas.
- **Goals / non-goals** — define desired outcomes and important exclusions.
- **Requirements** — write concrete requirements, not vague aspirations.
- **User stories** — keep them testable and relevant to scope.
- **Acceptance criteria** — make them observable.
- **Risks / assumptions / open questions** — keep uncertainty explicit.
