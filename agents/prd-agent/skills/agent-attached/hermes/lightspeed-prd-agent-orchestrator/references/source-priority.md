# Source priority

Rank evidence in this order unless the user overrides it:

1. current request and newly supplied artefacts
2. approved project-state records
3. approved PRDs, estimates, QA plans, and release packs
4. source systems and repositories
5. past summaries and memory defaults
6. public website or marketing material

For each source, assess:

- recency
- approval status
- completeness
- specificity
- contradiction risk

If a source is weak or stale, keep it as context, not as a confirmed fact.
