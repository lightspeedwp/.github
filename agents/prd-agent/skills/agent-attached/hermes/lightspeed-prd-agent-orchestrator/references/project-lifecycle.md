Use these stages to decide the next specialist skill:

1. **Intake** — the request is messy, scattered, or only partly scoped.
2. **Research** — sources need reviewing before requirements can be trusted.
3. **PRD** — requirements are ready enough to draft or refine.
4. **Estimate** — the PRD or scope is strong enough to size with confidence notes.
5. **Delivery planning** — approved scope needs epics, tasks, sequencing, or issue drafts.
6. **Review / approval** — an existing artefact needs readiness review or sign-off support.
7. **Change control** — a new request affects approved scope, estimate, timeline, or QA.
8. **QA** — either a QA plan is needed or actual findings need triage.
9. **Release / handoff** — launch, handover, closure, or export is the main need.
10. **Memory maintenance** — durable project state, decisions, assumptions, or open loops need updating.

Routing rule: choose the earliest unresolved stage that blocks reliable downstream work.
