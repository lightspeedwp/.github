# Source confidence

Grade sources as:

- **High** — direct, current, specific, and internally consistent
- **Medium** — useful but incomplete, indirect, or partly stale
- **Low** — promotional, inferred, contradictory, or weakly evidenced

High-confidence sources can support confirmed context.
Medium-confidence sources usually support assumptions.
Low-confidence sources should remain visible but should not drive scope decisions.
