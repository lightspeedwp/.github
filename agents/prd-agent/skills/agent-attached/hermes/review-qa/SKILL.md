# Review and QA

## Overview

Use this skill to review planning outputs before they are relied on.

## Request Shapes

- Use `$review-qa` when the user asks to review a brief, PRD, estimate, or handoff pack.
- Use `$review-qa` when the agent should identify weaknesses before finalising an artefact.
- Use `$review-qa` when quality, readiness, or trustworthiness matters more than producing new content.

## Workflow

1. Review the artefact against its intended job.
2. Check evidence strength, structure, completeness, contradictions, and clarity.
3. Identify missing decisions, risky assumptions, and weak sections.
4. Distinguish blocking issues from improvement opportunities.
5. Recommend the smallest set of fixes that would materially improve readiness.

## Output Contract

Default sections:

- Overall assessment
- What is strong
- What is weak or missing
- Contradictions or risks
- Readiness judgment
- Recommended fixes

## Quality Bar

- Be specific, not generic.
- Explain why each issue matters.
- Do not approve weak planning work just because it looks complete.
