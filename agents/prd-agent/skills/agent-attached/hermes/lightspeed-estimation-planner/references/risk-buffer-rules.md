# Risk buffer rules

Add explicit risk buffer when:

- evidence is incomplete
- integration behaviour is unclear
- legacy systems are unstable
- QA scope is broad
- stakeholder sign-off paths are uncertain

Explain why the buffer exists instead of hiding it inside base effort.
