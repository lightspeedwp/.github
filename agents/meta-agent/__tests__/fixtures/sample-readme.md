# Sample Custom Block

This is a sample custom WordPress block plugin that demonstrates Meta Agent v2.0 standards application.

## Features

- Fully customizable block
- Optimized performance
- Organized code structure
- Complete documentation
- Accessible to all users

## Installation

1. Download or clone this repository
2. Install dependencies with `npm install`
3. Build the block with `npm run build`
4. Activate the plugin in WordPress

## Usage

Add the block to any post or page:

1. Click the block inserter
2. Search for "Sample Block"
3. Customise the block settings as needed
4. Publish your content
