Use these files as selective intake references, not mandatory forms.

| File | Use when | Ignore when |
|---|---|---|
| `questionnaires/website-briefing-questionnaire.md` | General website discovery, project framing, goals, scope | Task is only tone, content cleanup, or post-launch review |
| `questionnaires/basic-website-package-questionnaire.md` | Small brochure sites, simple package discovery | Ecommerce, large content, or complex feature discovery |
| `questionnaires/standard-website-package-questionnaire.md` | Standard website planning with broader scope | Very small or highly specialized engagements |
| `questionnaires/ecommerce-briefing-form.md` | Ecommerce, catalogue, checkout, shipping, tax, operations | Non-commerce sites |
| `questionnaires/content-collection-questionnaire.md` | Content sourcing, page inputs, migration, asset collection | Design-only or architecture-only tasks |
| `questionnaires/content-collection-fillable-pdf-questionnaire.md` | Same as content collection when the PDF-derived structure is useful | A cleaner source already covers the same intake |
| `questionnaires/website-content-collection-questionnaire.md` | Website page-by-page content collection | Discovery is strategic only |
| `questionnaires/design-briefing-questionnaire.md` | Brand, creative direction, design briefing | Pure technical scoping |
| `questionnaires/website-design-questionnaire.md` | Website UX/UI and visual design direction | Non-design workflows |
| `questionnaires/tone-of-voice-questionnaire.md` | Messaging, voice, brand language, content style | Pure technical or operational workflows |
| `questionnaires/tour-operator-blog-questionnaire.md` | Tour operator content, blog, destination storytelling | Non-tour workflows |
| `questionnaires/tour-operator-website-planning-checklists.md` | Tour operator planning, launch, destination, itinerary, operational readiness | Non-tour workflows |

Decision rule: choose the smallest set of files that improves the current intake. Ignore files that do not materially help the active workflow.
