## Purpose

Provide a profile for LightSpeed experience-driven frontend builds that rely on custom WordPress components and reusable blocks.

## Use When

Use when the project emphasises custom frontend presentation, modular sections, reusable components, and implementation consistency across templates.

## Required Inputs

Design evidence, component or block inventory, repo structure, target routes, and any responsive or visual QA priorities.

## Default Coverage

Reusable blocks, page templates, hero and CTA behaviour, navigation, forms, responsive layout changes, and visual regression candidates.

## Exclusions

Backend-only logic, unsupported browser automation beyond Playwright scope, and pixel-perfect checks unless explicitly requested.

## Recommended Outputs

Figma context extraction, repo analysis summary, component-aware test cases, and a structured Playwright suite plan.
