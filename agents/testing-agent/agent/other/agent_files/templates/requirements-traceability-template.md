## Purpose

Provide a reusable matrix for linking approved requirements to design evidence, repo evidence, test cases, and generated specs.

## Inputs

Requirement IDs, PRD references, Figma references, repo references, approved test cases, and spec planning details.

## Output

A traceability matrix that shows current coverage status and confidence.

## Required Fields

- Requirement ID
- PRD reference
- Figma reference
- Repo reference
- Test case ID
- Playwright spec path
- Status
- Coverage confidence
- Notes
