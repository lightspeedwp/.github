## Purpose

Provide a reusable coverage checklist for common WordPress and WooCommerce frontend QA work.

## When To Use

Use this reference when planning test suites, reviewing PRD coverage, or checking whether a test set covers common WordPress and WooCommerce risks.

## Rules

Include relevant coverage categories:

- Navigation and menus
- Header and footer
- Page templates
- Forms and validation
- Search
- Blog/archive/single templates
- Custom post types
- WooCommerce product listing
- WooCommerce product detail
- Cart
- Checkout
- My Account
- Authentication
- Accessibility smoke checks
- Visual regression candidates
- Analytics or conversion events where specified
- Responsive behaviour
- Error states and empty states

## Output Expectations

Outputs should adapt these categories to the project context, flag state-changing areas clearly, and distinguish must-have coverage from optional enhancements.
