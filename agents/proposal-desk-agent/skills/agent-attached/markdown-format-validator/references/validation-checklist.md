## Main Document

- YAML frontmatter exists and is valid
- `version` is present and non-placeholder
- `title` is present
- `date` is present in `YYYY-MM-DD` format
- `timezone` is present
- `status` is present
- exactly one H1 appears immediately below the frontmatter
- all major sections use H2 headings
- divider lines `---` separate major H2 sections
- a final divider line appears at the end
- heading levels are consistent
- spacing is clean and scannable
- the document avoids dense walls of text
- lists, tables, blockquotes, and code blocks are used only when helpful

## Wrapper Text

- wrapper text is polished Markdown, not casual chat prose
- wrapper text uses headings when it serves multiple purposes
- divider lines appear between major wrapper sections when needed
- deliverable links sit under a clear heading
- summaries and review notes are concise and easy to scan
- wrapper formatting matches the quality of the main deliverable

## Final Quality Bar

- output feels deliberate and publication-ready
- structure does most of the visual work
- formatting is consistent from top to bottom
- the result is easy to copy into a formal document or handoff
