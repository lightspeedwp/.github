Use this template to structure each major proposal section or questionnaire answer so the response stays consistent across the full draft.

## When to use

- The request has multiple sections, workstreams, or question groups.
- The agent is drafting a first pass that should be easy to review and refine.
- A section needs a repeatable structure that distinguishes grounded content from assumptions and gaps.

---

## Standalone document structure

When this template is used as a substantial standalone document, place YAML frontmatter **above** the main H1.

Use this scaffold:

```yaml
---
version: 1.0.0
title: "[Section Name]"
date: "YYYY-MM-DD"
timezone: "Africa/Johannesburg"
status: "draft"
---
```

Then place the H1 below it:

```md
# [Section Name]
```
