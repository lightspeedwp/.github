# Internal Follow-Up Template

Use this template to draft concise internal messages that unblock proposal gaps, validations, and decisions.

## When to use

- A proposal draft needs specific input from internal owners.
- You need a paste-ready message for Slack, email, or a doc comment.
- Multiple functions need targeted asks with clear urgency.

---

## Standalone document structure

When this template is used as a substantial standalone document, place YAML frontmatter **above** the main H1.

Use this scaffold:

```yaml
---
version: 1.0.0
title: "Internal Follow-Ups"
date: "YYYY-MM-DD"
timezone: "Africa/Johannesburg"
status: "draft"
---
```

Then place the H1 below it:

```md
# Internal Follow-Ups
```

---

## Output template

# Internal Follow-Ups

## [Owner Group or Team]

**Subject / Purpose:** [Short reason for the follow-up]

Hi [name or team], I am pulling together the response for **[project or request]** and need your input on the items below.

- **What I need:** [Specific input, decision, proof point, or confirmation]
- **Why it matters:** [Why this affects proposal quality, risk, or completeness]
- **Requested by:** [Timing or deadline]
- **Current working assumption:** [Optional; include only if useful]

Please reply with:

1. **Item 1:** [Requested item 1]
2. **Item 2:** [Requested item 2]
3. **Item 3:** [Requested item 3]

If easier, a quick directional answer is enough for the first pass and I can refine from there.

## Variants

### Short Slack-style version

[Team or owner] — I need quick input for **[project]** on [topic]. Specifically:

- **Ask 1:** [Ask 1]
- **Ask 2:** [Ask 2]
- **Ask 3:** [Ask 3]
- **Needed by:** [time]
- **Why it matters:** [short reason]

### Decision request version

Hi [name or team], I need a decision on **[topic]** for **[project]**.

- **Decision needed:** [Decision]
- **Options under consideration:** [Option A / Option B / Option C]
- **Recommendation so far:** [Current recommendation]
- **Decision needed by:** [time]
- **Impact if delayed:** [Short impact statement]
