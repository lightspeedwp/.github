Use this template to summarise proposal-review findings after a grounded first pass is drafted.

## When to use

- A first-pass response is ready for internal review.
- You need to surface assumptions, risks, blockers, and decisions before the response is finalised.
- The team needs a concise internal summary rather than a full proposal draft.

---

## Standalone document structure

When this template is used as a substantial standalone document, place YAML frontmatter **above** the main H1.

Use this scaffold:

```yaml
---
version: 1.0.0
title: "Review Notes"
date: "YYYY-MM-DD"
timezone: "Africa/Johannesburg"
status: "draft"
---
```

Then place the H1 below it:

```md
# Review Notes
```
