Use this template when the user wants a concise, senior-friendly opening section that frames the proposal before the detailed response.

## When to use

- The request is an RFP, proposal brief, or solution response that benefits from a short top-line summary.
- The audience includes leadership, procurement, programme owners, or mixed stakeholders.
- The response needs a clear opening that connects client goals to the proposed approach.

---

## Standalone document structure

When this template is used as a substantial standalone document or as the opening section of a full response pack, place YAML frontmatter **above** the main H1.

Use this scaffold:

```yaml
---
version: 1.0.0
title: "Executive Summary"
date: "YYYY-MM-DD"
timezone: "Africa/Johannesburg"
status: "draft"
---
```

Then place the H1 below it:

```md
# Executive Summary
```
