# Output Template Library

Use this file to choose the right attached template or control file for the output the user wants.

## Output routing

| Requested output | Primary file to use | Notes |
|---|---|---|
| Full proposal response pack | `references/gold_standard_rfp_template.docx` | Use only when no stronger customer-required structure is provided. |
| Executive summary | `references/executive-summary-template.md` | Keep concise and senior-readable. |
| Section-by-section draft | `references/section-response-template.md` | Preserve customer section names when present. |
| Gap tracker | `references/gap-tracker-template.md` | Use for missing inputs, validations, and owner routing. |
| Review summary | `references/review-notes-template.md` | Use after a grounded first pass. |
| Internal owner follow-ups | `references/internal-follow-up-template.md` | Use for paste-ready asks and unblockers. |
| Audience-specific framing | `references/proposal-audience-templates.md` | Apply before drafting when buyer type materially changes framing. |

## Priority rules

1. Preserve the user's required format or the buyer's submission structure first.
2. If no required format exists, choose the best-fit attached template.
3. If multiple files seem relevant, choose one primary drafting template and use the others only as supporting guides.
4. Use `references/README.md` when you need a fuller explanation of what each reference file is for.
