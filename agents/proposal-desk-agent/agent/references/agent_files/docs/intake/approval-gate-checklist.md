Use this checklist when the workflow includes approval-sensitive content, external publication, higher-risk claims, regulated content, or consequential recommendations.

## Check before proceeding

- [ ] Approval owner is known when one is required.
- [ ] Source approval status is clear enough for the intended output.
- [ ] Restricted or draft-only material is not being treated as publishable.
- [ ] High-risk or unsupported claims are isolated for review.
- [ ] Pricing, performance, ranking, ROI, guarantee, testimonial, legal, privacy, safety, medical, or financial statements were checked.
- [ ] AI-generated recommendations that could affect decisions are labelled for review when needed.
- [ ] The output clearly distinguishes confirmed facts from inferred or defaulted values.
- [ ] Durable memory promotion is blocked for anything still awaiting approval.

## Output rule

If an approval gate is unresolved, continue only with the safe draft, review, or intake path. Do not present unresolved approval-sensitive content as final public-ready output.
