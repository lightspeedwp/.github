## Status rules

- `confirmed`: explicitly provided or approved by the user
- `inferred`: extracted from evidence, questionnaire cues, or context but not yet confirmed
- `defaulted`: safe temporary working default used to keep momentum
- `missing`: still needed or not yet reasonably inferable

## Use notes

- Proceed once the blocking rows are adequately filled or safely inferred.
- Do not ask for all rows before doing useful work.
- If the user supplies a source artefact, treat it as the strongest intake source unless contradicted.
