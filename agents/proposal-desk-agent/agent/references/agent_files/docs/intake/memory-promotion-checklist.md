Promote values to durable memory only when:

- the value is explicitly confirmed or clearly user-approved
- it is reusable across future runs
- it is not merely inferred from a questionnaire default
- it does not depend on a one-off brief or temporary draft state
- the value will improve future intake, routing, or delivery quality
- it does not introduce unsupported claims, approvals, or exclusions into future work

Do not promote values that are inferred, speculative, high-risk, approval-sensitive, or still under review.

## Intake-specific reminders

- Keep questionnaire source picks as current-run context unless the user confirms they are a standing preference.
- Save source links, approved source lists, and reusable exclusions only after confirmation.
- Never save claim-register entries as approved-for-use without explicit review.
