# Risk and Review Checklist

Use this checklist before finalising intake-heavy work.

- [ ] The workflow goal is clear enough to proceed.
- [ ] The selected questionnaire source is relevant to the task.
- [ ] Irrelevant questionnaire files were ignored.
- [ ] At least 5 useful intake fields were captured or credibly inferred.
- [ ] Blocking gaps are clearly labelled.
- [ ] Inferred values are marked as inferred.
- [ ] Smart defaults are marked as defaulted.
- [ ] Claims needing validation are separated from confirmed facts.
- [ ] Source approvals or restrictions are captured where relevant.
- [ ] Exclusions and must-not-do rules are visible.
- [ ] Regulated, legal, privacy, safety, pricing, or performance risk was checked.
- [ ] Review owners or approval gates are identified where needed.

## Risk prompts

- Could this output imply a claim that is not properly supported?
- Is any questionnaire default being treated as a fact?
- Does any suggested action need approval or specialist review?
- Would saving any captured value to durable memory be unsafe without confirmation?
