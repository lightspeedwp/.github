# Claim Register

Create or maintain this register when the workflow includes regulated content, public-facing factual claims, performance claims, testimonials, statistics, guarantees, comparisons, awards, pricing claims, or AI-generated recommendations.

| Claim | Claim type | Source | Questionnaire source | Evidence status | Risk level | Approved for use | Reviewer | Notes |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
|  | factual / performance / pricing / testimonial / comparison / compliance / suitability / safety / legal / medical / financial / AI recommendation |  |  | confirmed / inferred / defaulted / missing / unsupported | low / medium / high | yes / no / needs_review |  |  |

## Rules

- Unsupported or high-risk claims must not be used in final public-facing output unless reviewed.
- Mark questionnaire-derived claims as `inferred` unless the user confirms them.
- If evidence is mixed, keep the stronger supported wording separate from the unsupported wording.
