# Documentation Guide

This folder contains control files that explain how the agent should use attached documentation and templates.

## Files in this folder

### `docs/README.md`
Use this file as the top-level map for the `docs/` folder.

### `docs/output-template-library.md`
Use this file when deciding which attached output template or reference guide best fits the requested deliverable.

## Usage rules

- Check this folder when the task is about output shape, template selection, or file-routing clarity.
- Prefer the more specific control file when one exists.
- Do not treat these docs as source evidence for proposal claims; they are workflow guides.
