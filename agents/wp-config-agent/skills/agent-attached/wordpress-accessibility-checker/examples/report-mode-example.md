# Example: Report Mode Output

User asks: "Review the Accessibility Checker findings for the priority pages and tell us what to fix first."

Good behaviour:

1. Confirm report mode.
2. Inspect issue evidence and affected content.
3. Group repeated issues by source.
4. Prioritise by user impact, not just issue count.
5. Return an audit report with limitations.

Example finding row:

| Priority | Issue | Where | User impact | Recommended fix | Owner/status |
| --- | --- | --- | --- | --- | --- |
| Serious | Empty linked image alt text | Home page hero CTA image | Screen reader users cannot identify the linked destination | Add functional alt text that describes the destination, or replace the image link with a labelled button | Content/fix planned |
