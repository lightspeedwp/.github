This register preserves the primary Yoast scan set required for future research. Entries marked `research target` are queued for verification and must not be treated as scanned evidence until an accessed date, key facts, and confidence notes are added during a live research workflow.

## Source capture rules

- Capture page title, URL, accessed date, product/feature area, key facts, configuration relevance, developer relevance, limitations/version notes, source type, duplicate status, and confidence for every scanned page.
- Preserve duplicate URLs in this register and mark the duplicate relationship; scan the canonical page once unless the duplicate reveals redirect or changed content.
- Prefer Yoast developer docs for behaviour and APIs, Yoast product pages for packaging, Google Search Central for Google interpretation, Schema.org for vocabulary, and WordPress/WooCommerce docs for platform dependencies.
- Do not use random blog posts, affiliate reviews, old comparison articles, or unsupported forum answers except as weak context clearly labelled as such.
