## Implementation sequence

1. Freeze the approved row set.
2. Save/export the current metadata state where possible.
3. Apply approved low-risk rows first in staging or a controlled admin session.
4. Apply template-level changes only after representative URL testing.
5. Run rendered-output QA before marking complete.
6. Record rejected, deferred, and changed rows separately.

## QA checklist

- [ ] Rendered `<title>` checked.
- [ ] Rendered meta description checked.
- [ ] Canonical checked on sample URLs.
- [ ] Meta robots checked on sample URLs.
- [ ] Open Graph/Twitter/X metadata checked where relevant.
- [ ] Product schema checked where relevant.
- [ ] XML sitemap inclusion/exclusion checked where relevant.
- [ ] Search/social preview caveat included where client-facing.
