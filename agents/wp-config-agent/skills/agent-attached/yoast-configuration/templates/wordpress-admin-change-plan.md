## Pre-change checks

- Export or screenshot current Yoast settings.
- Capture representative rendered source for affected templates/URLs.
- Capture sitemap, robots.txt and llms.txt state when relevant.
- Confirm cache/CDN purge route.
- Confirm rollback/reversal route for risky indexation/canonical changes.

## Post-change QA

- Rendered title/meta description/canonical/meta robots.
- XML sitemap inclusion/exclusion.
- robots.txt and llms.txt response where relevant.
- Schema JSON-LD and graph consistency.
- Breadcrumb output.
- WooCommerce product/category output where relevant.
- Crawl or Search Console follow-up when appropriate.
