Use this before any WooCommerce SEO, product schema, product archive, ProductGroup, Offer, AggregateOffer, faceted-navigation, or store-launch recommendation.

## Store context

1. Store type: catalogue, transactional, subscriptions, memberships, bookings, marketplace, B2B, wholesale, enquiry-led, or hybrid.
2. Product types: simple, variable, grouped, external/affiliate, downloadable, virtual, subscription, bundle, composite, booking, custom product type.
3. Product count, category count, tag count, attribute count, and variation count.
4. Important conversion pages: shop, product categories, product detail pages, cart, checkout, account, enquiry forms, quote requests.
5. Product data completeness: SKU, GTIN, MPN, brand, manufacturer, price, sale price, stock, availability, reviews, ratings, shipping, returns, images, descriptions.
6. Filter/facet system: WooCommerce layered nav, FacetWP, SearchWP, custom filters, query parameters, AJAX filters, search pages.
7. Product archive strategy: which categories, tags, attributes, brand pages, or filtered landing pages should be indexable?
8. Current Yoast products and other SEO/schema plugins installed.

## Evidence to request

- Representative simple product, variable product, category archive, tag archive, attribute archive, shop page, filtered URL, sale product, out-of-stock product.
- Rendered source for metadata, canonical, robots, Open Graph, Product/ProductGroup/Offer/AggregateOffer/AggregateRating/Review/Breadcrumb schema.
- Product sitemap and product taxonomy sitemap URLs.
- Crawl export with canonical/noindex/sitemap status.

## Safe defaults

- Treat Yoast WooCommerce SEO as a distinct workflow, not a generic Yoast Free/Premium audit.
- Index only useful product and category URLs.
- Noindex product tags and arbitrary filter combinations unless deliberately curated.
- Validate schema on representative products and variations.
- Align product archive indexation with sitemap inclusion and canonical output.
- Record product data gaps separately from Yoast configuration issues.
