## First-pass classification

Choose one primary path:

- Form configuration
- Notification/email delivery
- Spam/security false positive
- Cache/script optimisation
- Theme/plugin conflict
- Add-on/feed/API issue
- Payment/user registration
- File upload/storage
- Environment compatibility
- Unknown

## Diagnostic sequence

1. Confirm Gravity Forms status, version, add-ons, WordPress/PHP versions, and current user capability.
2. Confirm whether entries are being created.
3. Check notifications, confirmations, feeds, and conditional logic.
4. Check spam entries and anti-spam settings.
5. Check page cache, CDN cache, and script optimisation.
6. Check Gravity Forms logs or enable temporary logging if approved.
7. Run a controlled test submission.
8. Compare result against expected behaviour.
9. Escalate only with evidence, reproduction steps, and logs/screenshots.
