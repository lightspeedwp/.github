Each workflow should be adapted to site evidence, active add-ons, consent/privacy requirements, accessibility, and MCP capabilities. For each workflow, produce purpose, required add-ons, site capabilities, fields, confirmations, notifications, feeds, spam/security defaults, accessibility requirements, test checklist, and handoff notes.

## Basic contact form

- **Purpose**: General inbound enquiry with short fields and fast completion.
- **Required add-ons**: None beyond Gravity Forms core.
- **Required site capabilities**: Gravity Forms active; form create/update or manual admin path; SMTP/email evidence for important notifications; target page/embed capability if publishing.
- **Recommended fields**: Name, Email, Message, Consent; Phone optional.
- **Confirmations/notifications**: Text confirmation; admin notification with Reply-To set to submitter email; user autoresponder optional.
- **Feeds/add-ons**: Only configure feeds confirmed installed/licensed and approved.
- **Spam/security defaults**: Honeypot or layered anti-spam, no unnecessary sensitive data, file-upload restrictions where relevant.
- **Accessibility requirements**: Visible labels, clear required fields, concise descriptions, keyboard-friendly flow, useful error messages.
- **Test submission checklist**: Submit realistic test data, verify confirmation, admin notification, user notification if configured, entry content, feed result, spam status, and page embed.
- **Handoff notes**: Record form ID/title, page URL, fields, notifications, feeds, add-ons, risks, and next owner.
