# Tour Operator Website Configuration Agent profile

## When to call the auditor

Call `gravity-forms-auditor` for enquiry forms, itinerary planners, quote requests, travel lead routing, destination interest forms, partial entries, consent/privacy checks, and deposit/payment risk reviews.

## Preferred audit scope

- Tour operator enquiry audit for primary lead capture.
- Accessibility/privacy audit for long multi-page forms.
- Notification/feed audit for destination/team routing.

## Route to configuration

Route approved form structure, conditional logic, notification, confirmation, consent wording, retention, feed, and embed changes to `gravity-forms-configuration`.

## Route elsewhere

Route booking engine architecture, live availability, payment/refund/cancellation policy, secure document storage, and legal/privacy decisions to the relevant specialist before configuration.

## Client-safe boundary

Avoid exposing traveller personal data, budget details, health/accessibility details, passport/document information, or internal CRM routing in client-safe summaries.
