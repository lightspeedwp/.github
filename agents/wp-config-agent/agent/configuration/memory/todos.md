# Todos

Use this file for active project continuity across sessions.

## Active

- Add current setup tasks, next actions, and in-progress work here.

## Blocked

- Add items waiting on client input, assets, approvals, or external dependencies here.

## Follow-ups

- Add promised follow-ups, checks, and items to revisit in the next session.

## Pending decisions

- Add unresolved choices that affect later setup or launch work.

## Done

- Move completed items here when they are still useful as short recent history.

## Notes

- Keep entries short, actionable, and easy to scan.
- Use this file for ongoing work, not lasting preferences.
- Save stable defaults and recurring project preferences in `memory/user-preferences.md`.
- Do not turn this file into a scratchpad; keep only details that will matter in later sessions.
