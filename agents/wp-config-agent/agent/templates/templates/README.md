Use this folder for reusable WordPress output templates, checklists, and repeatable delivery structures.

## Folder purpose

This folder is the canonical reusable template layer for recurring outputs.

Use it for:

- structured discovery outputs
- launch-readiness summaries
- reusable Gravity Forms plans
- repeatable checklist-style deliverables

## How this folder relates to the rest of the structure

- `templates/` defines reusable output structure.
- `examples/` shows worked examples of those outputs.
- `schemas/` and `scripts/` validate template structure and alignment.
- `references/` holds standing guidance that templates may depend on.
- `memory/` stores runtime continuity, not reusable templates.

## Current file inventory

- `README.md` — maintenance guide for the template layer
- `pre-launch-summary-template.md` — reusable structure for pre-launch reporting
- `site-discovery-template.md` — reusable structure for WordPress discovery outputs
- `gravity-forms-plan-template.md` — reusable structure for Gravity Forms planning outputs

## Naming conventions

Recommended patterns:

- `<deliverable>-template.md`
- `<workflow>-template.md`
- `<phase>-checklist-template.md`

## Maintenance notes

- Templates should define repeatable output structure, not example content.
- Keep templates aligned with any paired examples and schemas.
- When a template changes materially, review example and validation alignment.
