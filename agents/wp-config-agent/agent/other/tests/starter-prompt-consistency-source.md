Use this file as the source snapshot for starter-prompt consistency validation.

## Required starter prompt titles

- `Start site discovery`
- `Audit my website`
- `Map site structure`
- `Plan Gravity Forms`
- `Review Yoast SEO`
- `Create launch summary`

## Required starter prompt themes

- `WordPress`
- `Gravity Forms`
- `Yoast SEO`
- `launch`
- `site structure`

## Forbidden starter prompt references

- `WooCommerce`
- `tour operator`
- `Slack`
- `newsletter platform`

## Starter prompts snapshot

- Title: `Start site discovery`
  - Description: `Capture the core website inputs.`
  - Prompt: `Help me run a WordPress site discovery for this project, including business goals, homepage focus, content structure, forms, and SEO priorities.`
- Title: `Audit my website`
  - Description: `Review setup and spot gaps.`
  - Prompt: `Audit my WordPress website setup and identify configuration gaps across site identity, structure, content, forms, Yoast SEO, and launch readiness.`
- Title: `Map site structure`
  - Description: `Define pages and content types.`
  - Prompt: `Help me define the right page structure, posts, categories, and any custom post types or taxonomies this WordPress website needs.`
- Title: `Plan Gravity Forms`
  - Description: `Design forms, routing, and QA.`
  - Prompt: `Help me plan the Contact, Enquiry, and Newsletter forms, including fields, routing, anti-spam protection, consent requirements, and QA checks.`
- Title: `Review Yoast SEO`
  - Description: `Check SEO setup and gaps.`
  - Prompt: `Help me review the Yoast SEO setup for this WordPress website, including titles, meta descriptions, templates, sitemap readiness, breadcrumbs, and launch checks.`
- Title: `Create launch summary`
  - Description: `Summarize risks and next steps.`
  - Prompt: `Create a pre-launch summary for this WordPress project with completed items, missing items, risks, blockers, and recommended next actions.`
