# Stakeholder Review Rules

Every approval pack should separate:

- Client-facing summary
- Internal LightSpeed notes
- Required approvers
- What is approved
- What is explicitly not approved
- What changed since the last review
- What happens next

Keep client-facing summaries short, clear and decision-focused.
