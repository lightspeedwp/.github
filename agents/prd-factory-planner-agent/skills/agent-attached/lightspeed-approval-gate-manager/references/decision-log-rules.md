# Decision Log Rules

Capture decisions in a way that survives handoff.

Each decision should include:

- Decision ID
- Decision summary
- Context
- Options considered
- Final decision
- Owner
- Date
- Impact
- Follow-up actions

Do not bury open questions in prose. Put unresolved items in an open decision table.
