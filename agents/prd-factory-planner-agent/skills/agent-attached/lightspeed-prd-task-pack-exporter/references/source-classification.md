# Source Classification

| Status | Meaning | Pack handling |
|---|---|---|
| Approved | Reviewed and safe to use | Include directly |
| Draft | Useful but not final | Include with review note |
| Needs Review | Requires stakeholder review | Flag in README and file notes |
| Evidence Pending | Claims or facts need proof | Flag in source notes |
| Blocked | Cannot proceed without input | Add to next actions |
| Missing | Not supplied | Create placeholder file if important |
