# Pack Quality Checklist

Before finalising a project pack, check:

- README exists.
- File index exists.
- Client-facing and internal notes are separated.
- Draft and missing sections are labelled.
- Source links are captured.
- Open questions are listed.
- Approval gates are clear.
- GitHub issue drafts are not auto-created.
- Launch routing is included where relevant.
- Memory bank files are present where requested.
