# PRD Review Rules

Flag PRD issues when:

- goals are vague
- non-goals are missing
- personas are generic
- user stories lack value
- requirements are not testable
- success metrics are missing
- assumptions are not separated from facts
- open questions are hidden inside prose
- client-facing and internal notes are mixed
