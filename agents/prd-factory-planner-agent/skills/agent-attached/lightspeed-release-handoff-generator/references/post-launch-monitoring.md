# Post-Launch Monitoring

Default monitoring windows:

- launch day
- first 48 hours
- first 7 days
- first 30 days
- 60/90 day improvement review

Monitor:

- uptime and errors
- redirects and 404s
- forms and email routing
- GA4/GTM events
- Search Console coverage
- Core Web Vitals/PageSpeed
- accessibility regressions
- ecommerce/payment flows if relevant
- chatbot handoffs if enabled
- client-reported issues
