# LightSpeed Implementation Workstream Model

Use these workstreams where relevant.

| Workstream | Typical outputs |
|---|---|
| Project setup | Repo review, environment notes, dependency check |
| Design tokens | Figma variables to theme.json mapping |
| Block theme | theme.json, templates, parts, styles, patterns |
| Block plugin | custom blocks, block variations, render callbacks, assets |
| Content model | CPTs, taxonomies, fields, templates |
| Editor experience | pattern naming, block controls, editor styles, governance |
| Accessibility | focus states, headings, contrast, keyboard, ARIA where needed |
| Responsive | mobile, tablet, desktop, wide viewport states |
| Performance | asset loading, images, fonts, caching, Core Web Vitals |
| WooCommerce | product templates, checkout, account, cart, emails where relevant |
| Forms and tracking | forms, consent, GA4 events, GTM triggers |
| SEO and launch | redirects, schema, metadata, sitemap, Search Console |
| QA and release | test plans, go/no-go gates, rollback notes |
