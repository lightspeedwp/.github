# Editor Experience Requirements

## Define editor guardrails

Document:

- which templates editors may edit
- which patterns are reusable
- which blocks are allowed in key areas
- which colours/typography options are exposed
- which layout options are restricted
- placeholder guidance
- image ratio guidance
- CTA and form placement rules

## Quality rule

A design-system implementation is not complete until content editors can use it without breaking layout, accessibility or brand consistency.
