# Change Approval Checklist

- [ ] Change request is clearly summarised.
- [ ] Approved scope has been checked.
- [ ] PRD impact is understood.
- [ ] Technical impact is understood.
- [ ] Task/issue impact is understood.
- [ ] QA/launch impact is understood.
- [ ] Estimate/timeline impact is understood.
- [ ] Required approvers are identified.
- [ ] Decision is recorded.
- [ ] Project memory is updated.
