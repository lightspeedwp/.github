# System Patterns

## Working implementation pattern

- use a block-first WordPress architecture as the baseline
- map Figma tokens into `theme.json`
- map repeatable marketing sections into patterns before considering bespoke blocks
- keep theme responsibilities focused on presentation, templates, patterns, and token application
- move structured content logic or integration-heavy behaviour into a companion plugin only if discovery confirms that need

## Editor model

- support guided flexibility for the marketing team through approved pattern sets, page templates, and controlled variation options
- avoid a fully freeform editor model that would weaken consistency across seasonal landing pages
