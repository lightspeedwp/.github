# Memory Promotion Checklist

Promote a value from intake into durable Memory only when all checks pass.

- The value is still likely to matter in a future run.
- The value is specific enough to reuse safely.
- The value is not just a one-off draft detail.
- The source is clear and trustworthy.
- The user has confirmed it when confirmation is required.
- The save target is correct: `confirmed_project_memory`, not `current_run_context`.
- Inferred or defaulted values stay out of durable Memory unless later confirmed.
