# Output Modes

## Quick brief

Use for early sales/discovery or when little evidence is available.

Include:

- project summary
- likely build type
- key risks
- missing inputs
- recommended next workflow

## Full project pack

Use for a real implementation.

Include:

- PRD
- Figma-to-WordPress technical brief
- task plan
- GitHub issue drafts
- implementation plan
- QA and launch plan
- specialist routing
- project memory bank

## GitHub issue mode

Use when the PRD and technical brief are approved.

Include:

- issue index
- one issue per independently testable task
- acceptance criteria
- technical notes
- QA notes
- dependencies/blockers
- labels/milestones
- owner-role suggestions

Do not create issues unless explicitly approved.
