# References Folder Guide

Use this folder for durable reference material that supports decisions but does not override package specs, commercial rules, or templates.

## Purpose

- hold reusable reference notes
- separate supporting references from governing files
- make reference reading order explicit

## Reading rule

Always read this file first when working inside `/references`.

## Agent rule

Treat files in `/references` as supporting context unless a file explicitly says it is authoritative. If a future reference file conflicts with `/packages`, `/package-addons`, `/commercial-rules`, or `/templates`, follow those governing folders first.
