# Content Migration Add-on

**Applies to:** Publisher Website Package, Tour Operator Website Package, WooCommerce Website Package, WordPress Foundations Package, Custom Website Solution

## Purpose

Handle content migration volume or complexity that exceeds the allowance in the base package.

## Use when

- the client is moving significant content from an existing site
- content structure needs mapping or cleanup during migration

## Includes

- migration audit
- migration plan
- agreed migration execution within scope
- QA pass on migrated content

## Excludes

- unlimited migration
- full rewrite of migrated content
- legacy-system extraction engineering beyond standard scope

## Onboarding questions

- Roughly how much content must be migrated?
- Is the source platform WordPress or something else?
- Does the content need restructuring during migration?
