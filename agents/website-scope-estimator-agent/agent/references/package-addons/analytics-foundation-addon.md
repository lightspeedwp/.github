# Analytics Foundation Add-on

**Applies to:** Publisher Website Package, Tour Operator Website Package, WooCommerce Website Package, WordPress Foundations Package, Custom Website Solution

## Purpose

Set up or clean up analytics, tracking, and reporting foundations beyond what is included in the base package.

## Use when

- GA4 or GTM is missing
- conversion tracking matters
- the client needs better reporting confidence

## Includes

- GA4 review or setup
- GTM review or setup where relevant
- Search Console baseline review
- event / conversion planning within agreed scope

## Excludes

- enterprise analytics architecture
- advanced BI / dashboard engineering
- offline attribution systems

## Onboarding questions

- Is GA4 already in place?
- Is GTM already in place?
- What conversions matter most?
