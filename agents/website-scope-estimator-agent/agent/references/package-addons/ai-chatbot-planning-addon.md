# AI Chatbot Planning Add-on

**Applies to:** Publisher Website Package, Tour Operator Website Package, WooCommerce Website Package, WordPress Foundations Package, Custom Website Solution

## Purpose

Add chatbot discovery and planning to a website project before any build-phase chatbot implementation.

## Use when

- the website project is likely to lead into a chatbot phase
- chatbot scope is not yet defined

## Includes

- chatbot use-case planning
- source-content and exclusion review
- escalation and launch-gate planning
- implementation-tier recommendation

## Excludes

- chatbot implementation
- CRM / API integration

## Onboarding questions

- Do you want a chatbot in this project or as a later phase?
- What should the chatbot actually do?
- What content should it be allowed to use?
