# SEO Foundation Add-on

**Applies to:** Publisher Website Package, Tour Operator Website Package, WooCommerce Website Package, WordPress Foundations Package, Custom Website Solution

## Purpose

Strengthen the site’s baseline SEO setup beyond what is included in the core website package.

## Use when

- search visibility is a key business goal
- metadata, indexing, sitemap, redirects, or technical search hygiene require additional attention

## Includes

- SEO audit pass
- metadata and heading review
- sitemap and indexing checks
- redirect and canonical review
- priority-page optimisation recommendations

## Excludes

- full content strategy
- large-scale copywriting
- advanced schema implementation unless separately added

## Onboarding questions

- Is SEO a primary success metric for this website?
- Do you already use Yoast or another SEO plugin?
- Are there known ranking or indexing issues?
