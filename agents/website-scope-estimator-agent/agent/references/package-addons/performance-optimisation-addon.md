# Performance Optimisation Add-on

**Applies to:** Publisher Website Package, Tour Operator Website Package, WooCommerce Website Package, WordPress Foundations Package, Custom Website Solution

## Purpose

Address performance, speed, and Core Web Vitals work beyond what is included in the base package.

## Use when

- performance is a commercial priority
- the audit reveals performance issues beyond standard build scope

## Includes

- performance audit
- Core Web Vitals review
- prioritised optimisation recommendations
- agreed implementation work within add-on scope

## Excludes

- full infrastructure engineering
- ongoing performance monitoring unless separately added
- major app-level refactoring

## Onboarding questions

- Is speed a major concern today?
- Are there any known slow templates or flows?
- Is hosting part of the optimisation discussion?
