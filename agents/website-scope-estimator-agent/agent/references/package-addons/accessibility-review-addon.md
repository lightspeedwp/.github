# Accessibility Review Add-on

**Applies to:** Publisher Website Package, Tour Operator Website Package, WooCommerce Website Package, WordPress Foundations Package, Custom Website Solution

## Purpose

Provide explicit accessibility review and remediation guidance beyond standard design/build good practice.

## Use when

- accessibility requires a named deliverable
- the client wants a review report or remediation plan

## Includes

- automated and manual accessibility review
- issue summary
- prioritised remediation notes
- accessibility guidance for content and UI patterns

## Excludes

- full certification process
- legal compliance sign-off
- large-scale remediation delivery unless separately scoped

## Onboarding questions

- Is accessibility a formal requirement?
- Do you need a report, remediation, or both?
- Are there any prior accessibility findings?
