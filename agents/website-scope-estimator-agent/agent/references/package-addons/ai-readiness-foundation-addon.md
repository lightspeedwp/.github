# AI Readiness Foundation Add-on

**Applies to:** Publisher Website Package, Tour Operator Website Package, WooCommerce Website Package, WordPress Foundations Package, Custom Website Solution

## Purpose

Attach baseline AI-readiness, content, and measurement preparation to a website project.

## Use when

- the client wants the website prepared for AI visibility and future AI features
- AI readiness is part of the website engagement but not the core website package itself

## Includes

- AI-readiness audit
- Yoast / measurement baseline review
- content-structure and policy-page findings
- prioritised AI-readiness roadmap

## Excludes

- chatbot implementation
- deep structured-data implementation unless separately added

## Onboarding questions

- Is AI readiness a goal for this website project?
- Is this preparation for search, chatbots, or both?
- Are there governance or policy constraints already in place?
