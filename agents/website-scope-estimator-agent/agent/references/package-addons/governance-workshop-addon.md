# Governance Workshop Add-on

**Applies to:** Publisher Website Package, Tour Operator Website Package, WooCommerce Website Package, WordPress Foundations Package, Custom Website Solution

## Purpose

Add a governance and policy workshop where AI-related risk, source approval, or operational boundaries need to be defined.

## Use when

- AI content or chatbot features create policy, risk, or approval complexity

## Includes

- workshop preparation
- governance workshop delivery
- source-content and approval discussion
- draft governance outputs

## Excludes

- legal sign-off
- full policy implementation across the organisation

## Onboarding questions

- Are there sensitive or regulated topics involved?
- Do you already have AI policies or approval rules?
- Who owns governance decisions internally?
