# AI Search and Structured Data Add-on

**Applies to:** Publisher Website Package, Tour Operator Website Package, WooCommerce Website Package, WordPress Foundations Package, Custom Website Solution

## Purpose

Attach deeper schema, crawl-policy, and machine-readability work to a website project.

## Use when

- the client wants stronger AI/search discoverability beyond baseline SEO

## Includes

- schema audit
- crawl-policy review
- llms.txt recommendation where appropriate
- structured-data validation notes

## Excludes

- specialist sector schema beyond agreed scope
- large-scale custom API engineering

## Onboarding questions

- Which content types matter most for search or AI visibility?
- Is this for traditional SEO, AI search, or both?
