This bundle contains agent-readable website add-on definitions.

## Purpose

Use these files when:

- the base website package has already been identified
- the estimator agent needs to attach optional add-ons
- the proposal agent needs to explain what is extra vs what is core package scope

## Core rule

All add-ons are subject to the same audit-first principle as the base website packages.

## File structure

- `addon-index.md`
- `seo-foundation-addon.md`
- `analytics-foundation-addon.md`
- `accessibility-review-addon.md`
- `performance-optimisation-addon.md`
- `content-migration-addon.md`
- `copywriting-support-addon.md`
- `multilingual-expansion-addon.md`
- `ai-readiness-foundation-addon.md`
- `ai-search-and-structured-data-addon.md`
- `ai-chatbot-planning-addon.md`
- `governance-workshop-addon.md`
- `care-plan-retainer-addon.md`

## Agent reading order

1. Read `addon-index.md`
2. Select only the add-ons relevant to the routed website package
3. Confirm applicability and missing values with the client before quoting
