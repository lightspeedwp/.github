## Add-on selection rules

### Use SEO Foundation Add-on when

- the base package does not already include enough SEO setup
- the project needs stronger metadata, indexing, or search-hygiene support

### Use Analytics Foundation Add-on when

- GA4, GTM, or Search Console setup is missing or unreliable
- reporting and conversion tracking are needed beyond the base package

### Use Accessibility Review Add-on when

- accessibility needs explicit review and reporting
- the client needs accessibility remediation guidance beyond standard design/build quality

### Use Performance Optimisation Add-on when

- speed, stability, or Core Web Vitals are material priorities
- the audit shows performance issues beyond the base package scope

### Use Content Migration Add-on when

- content migration volume or complexity is beyond the base package allowance

### Use Copywriting Support Add-on when

- the client needs writing, rewriting, or content-structure support beyond implementation

### Use Multilingual Expansion Add-on when

- multilingual or regional content setup is required
- the base package did not already route to a custom solution for architecture reasons

### Use AI Readiness Foundation Add-on when

- the website build also needs baseline AI-readiness and content/measurement preparation

### Use AI Search and Structured Data Add-on when

- the website build also needs deeper schema, crawl policy, and machine-readability work

### Use AI Chatbot Planning Add-on when

- the client wants a chatbot phase but planning has not yet been defined

### Use Governance Workshop Add-on when

- AI-related risk, source-content approval, or policy definition must be clarified

### Use Care Plan / Retainer Add-on when

- the client wants ongoing post-launch maintenance, optimisation, or support
