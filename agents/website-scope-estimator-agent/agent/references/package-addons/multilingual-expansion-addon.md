**Applies to:** Publisher Website Package, Tour Operator Website Package, WooCommerce Website Package, WordPress Foundations Package, Custom Website Solution

## Purpose

Add multilingual or regional content support beyond a single-language base package.

## Use when

- multiple languages or regions must be supported
- translation workflows, locale structure, or hreflang handling matter

## Includes

- multilingual audit
- language / locale structure recommendations
- agreed implementation planning within scope
- hreflang and search-structure guidance

## Excludes

- enterprise localisation operations
- unlimited translation management
- deep multilingual architecture beyond add-on scope

## Onboarding questions

- Which languages or regions are needed?
- Will content be translated manually or by a partner?
- Are all languages launching at once?
