# Example Contexts Index

Use this index as the main entry point for repeatable preview testing across the installed example projects.

## Available example contexts

1. `lightspeedwp-agency-example.md`
   - LightSpeedWP.Agency
   - Use for agency-site, multi-source, live/prototype/dev, and estimator baseline tests

2. `touroperator-solutions-example.md`
   - TourOperator.solutions
   - Use for product-site, travel-sector, and live/demo/dev comparison tests

3. `lsx-design-system-example.md`
   - LSX Design System
   - Use for design-system-led, product-led, and documentation-heavy tests

## How to use this index

For repeatable previews:

1. Pick one example context file.
2. Use its listed source references as the grounded test inputs.
3. Run one or more prompts from `preview-test-prompts.md`.
4. Validate the output with `preview-qa-checklist.md`.

## Companion files

- Prompt library: `preview-test-prompts.md`
- QA checklist: `preview-qa-checklist.md`

## Suggested coverage

Use the three contexts together to test:

- evidence-first scoping
- project-specific intake behavior
- package routing quality
- add-on discipline
- estimate drafting quality
- readiness-review consistency
- Memory discipline between reusable defaults, active project state, history, and todos

## Recommended testing flow

1. Start with the example context that best matches the scenario.
2. Run one evidence-first prompt from the prompt library.
3. Run one routing or drafting prompt from the prompt library.
4. Check the result against the QA checklist.
5. Repeat on a second context to compare consistency across projects.
