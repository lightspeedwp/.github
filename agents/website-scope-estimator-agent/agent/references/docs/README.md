# Docs Folder Guide

Use this folder for durable operating documents that explain how the agent should use supporting documentation.

## Purpose

- clarify how documentation files should be read
- point to control files before subfiles
- keep reusable agent-facing documentation organized

## Reading rule

Always read this file first when working inside `/docs`.

## Current files

- `output-template-library.md` — reference for which installed templates to use for each output type

## Agent rule

Use `/docs/output-template-library.md` when deciding which installed template structure should be used for an estimate, proposal, package one-pager, or evidence-library style output.
