# Custom-Scope Triggers

## Purpose

Define what pushes a website estimate into Custom Website Solution or other custom handling.

## Typical triggers

- multilingual or multi-brand complexity
- heavy integrations
- portal or membership behavior
- custom booking or checkout logic
- headless or hybrid architecture
- large migration complexity
- unstable legacy stack
