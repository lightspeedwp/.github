# Approval Rules

## Purpose

Define what must be confirmed internally before a website estimate or proposal is treated as ready.

## Required checks

- correct base package selected
- add-ons attached correctly
- fixed-fee eligibility confirmed
- missing values clearly identified
- assumptions stated
- internal-only notes removed from client-facing output
