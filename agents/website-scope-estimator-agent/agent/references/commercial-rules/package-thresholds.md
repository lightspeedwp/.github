# Package Thresholds

## Purpose

Define what keeps a website project inside standard package handling.

## Threshold areas to define

- page count
- template count
- migration volume
- ecommerce complexity
- booking complexity
- integrations
- multilingual scope
- portal / membership requirements
- staging availability
