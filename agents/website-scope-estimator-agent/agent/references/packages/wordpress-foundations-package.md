**Commercial model:** Fixed fee  
**Prerequisite:** Audit first

## Purpose

Deliver or refresh a standard WordPress brochure or service website on a strong, modern foundation.

## Use when

- the site is a standard brochure or service website
- no major ecommerce, portal, or specialist workflow complexity is required

## Includes

- audit and discovery
- standard information architecture review
- core page templates
- mobile-responsive build or refresh
- CMS setup
- standard contact forms
- basic SEO and analytics baseline
- launch support

## Excludes

- ecommerce
- multilingual
- membership or portal features
- custom application logic
- advanced integrations

## Fixed-fee eligibility

Remains fixed-fee when:

- page count and template count remain within standard range
- no major technical irregularities are found

## Onboarding questions

- Is this a new build or a refresh?
- Approximately how many core pages are needed?
- Is there existing content to migrate?
- Are there any important integrations or forms?
- Is there a design system or Figma reference?

## Values the agent should gather

- `client_page_count_estimate`
- `client_design_system_reference`
- `client_content_migration_need`
- `client_integrations_summary`
