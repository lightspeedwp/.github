# Website Packages Bundle

This bundle contains agent-readable standard website package definitions for estimator use.

## Package set

1. Publisher Website Package
2. Tour Operator Website Package
3. WooCommerce Website Package
4. WordPress Foundations Package
5. Custom Website Solution

## Core operating rule

All packages begin with an audit of the live website and available references before final package recommendation or pricing is confirmed.

## File structure

- `assessment-values.md`
- `package-index.md`
- `publisher-website-package.md`
- `tour-operator-website-package.md`
- `woocommerce-website-package.md`
- `wordpress-foundations-package.md`
- `custom-website-solution.md`

## Agent reading order

1. Read `assessment-values.md`
2. Read `package-index.md`
3. Read only the routed package files
