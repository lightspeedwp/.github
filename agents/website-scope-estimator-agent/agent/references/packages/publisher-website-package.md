# Publisher Website Package

**Commercial model:** Fixed fee  
**Prerequisite:** Audit first

## Purpose

Deliver or refresh a WordPress website designed for content publishing, editorial structure, discoverability, and scalable content operations.

## Use when

- the site is content-led
- editorial publishing and content architecture are the main priorities
- categories, tags, archives, search, authorship, and reading journeys matter

## Includes

- audit and discovery
- editorial content architecture review
- category / archive / author structure planning
- core publisher templates
- search and navigation planning within standard scope
- CMS setup and publishing workflow recommendations
- basic SEO and analytics baseline

## Excludes

- ecommerce
- advanced subscription / paywall systems
- custom portal behaviour
- major app-like features

## Fixed-fee eligibility

Remains fixed-fee when:

- editorial complexity remains within standard publishing architecture
- no major membership or paywall engineering is required

## Onboarding questions

- Is the site primarily editorial, news, insights, or publishing-led?
- Do authors, categories, tags, or archives need special treatment?
- Is search important to the reader experience?
- Is there a large content migration?

## Values the agent should gather

- `client_has_blog`
- `client_has_search`
- `client_page_count_estimate`
- `client_content_migration_need`
- `client_design_system_reference`
