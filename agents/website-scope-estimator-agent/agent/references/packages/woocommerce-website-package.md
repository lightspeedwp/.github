**Commercial model:** Fixed fee  
**Prerequisite:** Audit first

## Purpose

Deliver or refresh a WooCommerce website for standard ecommerce selling with clear product structure, standard checkout behaviour, and scalable merchandising foundations.

## Use when

- WooCommerce is central to the website
- the project needs standard ecommerce functionality rather than a custom platform

## Includes

- audit and discovery
- WooCommerce setup or review
- product and category structure planning
- standard ecommerce templates
- cart and checkout setup within agreed scope
- payment gateway setup within agreed scope
- ecommerce analytics baseline

## Excludes

- ERP integration
- marketplace logic
- custom checkout app behaviour
- complex subscription / membership / booking logic beyond standard scope

## Fixed-fee eligibility

Remains fixed-fee when:

- product and category counts remain within standard thresholds
- checkout flow is reasonably standard
- no major plugin conflicts are found

## Onboarding questions

- Roughly how many products are live?
- Roughly how many categories are in use?
- Are variable products used heavily?
- Are subscriptions, bookings, or memberships involved?
- Which plugins are critical to checkout?

## Values the agent should gather

- `client_has_woocommerce`
- `client_product_count_estimate`
- `client_category_count_estimate`
- `client_integrations_summary`
- `client_content_migration_need`
