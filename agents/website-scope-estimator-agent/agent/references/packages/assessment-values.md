Use this file to drive website-estimator intake before package routing.

## Source collection batch

Ask for or inspect:

- live website URL
- staging URL
- GitHub repo
- Google Docs / Drive references
- Figma files or design system references
- prior proposal, SOW, IA, or audit docs
- analytics or Search Console references
- content inventory or migration notes

## Shared values

| Value | Description | Try to source from | Ask if missing |
|---|---|---|---|
| `client_brand_name` | Brand or company name | Website / docs | Confirm |
| `client_website_url` | Live site | Client input | URL |
| `client_staging_url` | Staging site | Client input | URL |
| `client_platform` | CMS / stack | Live site / repo | Confirm |
| `client_has_woocommerce` | WooCommerce present | Live site / repo | Confirm |
| `client_website_type` | Publisher / tour / service / ecommerce / custom | Website / brief | Confirm |
| `client_page_count_estimate` | Rough number of core pages | Nav / sitemap | Approximate page count |
| `client_product_count_estimate` | Rough product volume | Site / sitemap | Approximate product count |
| `client_category_count_estimate` | Rough category volume | Site / nav | Approximate category count |
| `client_has_blog` | Blog / resource content exists | Live site | Confirm |
| `client_has_search` | Search exists | Live site | Confirm |
| `client_has_multilingual` | Multilingual status | Live site / docs | Confirm |
| `client_has_membership_or_portal` | Membership / login / portal behaviour | Live site / docs | Confirm |
| `client_integrations_summary` | CRM, booking, ERP, helpdesk, API dependencies | Docs / website | List integrations |
| `client_design_system_reference` | Figma or design system available | Figma / docs | Confirm |
| `client_content_migration_need` | Existing content to migrate | Brief / docs | Estimate migration need |
| `project_primary_goal` | Main website outcome | Brief / client input | Goal |
| `project_target_timeline` | Timeline | Prior comms / client input | Deadline |

## Shared website questions

- Is this a refresh of an existing site or a new build?
- Do you need audit only, audit plus implementation, or phased delivery?
- Is there a staging site?
- Are there design references, components, or tokens we should inherit?
- Does the site require ecommerce, booking, editorial publishing, or custom application behaviour?

## Output rule

Do not finalise package recommendation until:

1. website type is confirmed
2. audit findings are confirmed
3. migration, integrations, and staging status are known
