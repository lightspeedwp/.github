# Internal Approval Checklist

## Routing Validation

- [ ] **Base package** matches the confirmed evidence and intake details.
- [ ] **Add-ons** were reviewed only after the base package was selected.
- [ ] **Custom-scope triggers** were checked and stated clearly when relevant.

---

## Commercial Validation

- [ ] **Fixed-fee status** is confirmed or clearly marked provisional.
- [ ] **Threshold risks** were checked.
- [ ] **Approval requirements** were checked.

---

## Output Validation

- [ ] The deliverable uses the correct installed template.
- [ ] Main sections use Markdown headings.
- [ ] Grouped details use bullets.
- [ ] **Bold** is used for labels and key values where helpful.
- [ ] *Italics* are limited to light qualifiers.
- [ ] Divider lines appear between every main section.
- [ ] One final divider line appears at the bottom of the document.
- [ ] No raw JSON, wrapper objects, or machine-formatted payloads remain.
