## Purpose

This folder holds supporting reference material that informs delivery decisions but is not the first routing layer for package, add-on, commercial, or template selection.

## Usage Rule

- Start with the relevant top-level routing or control file elsewhere in the agent files.
- Use `references/` only when the current task needs supporting detail that is not already covered by a primary control file.
- If more reference files are added here later, update this README so it explains what each one is for.
