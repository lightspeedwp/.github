# Example 01

## Client Scenario
A standard service website on WordPress wants a first AI-readiness audit and implementation roadmap.

## Expected Package Path
AI Readiness Foundation.

## Expected Add-ons
None.

## Key Missing Values
Staging URL, analytics stack confirmation, target timeline, internal owner.

## Likely Custom-Scope Triggers
Major plugin conflicts or hidden migration work.

## What A Good Estimate Should Look Like
It should recommend AI Readiness Foundation, keep the position provisional until the audit confirms fixed-fee eligibility, and list only the missing values that still matter.
