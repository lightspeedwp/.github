## Client Scenario

A client wants a website chatbot, but the use case, boundaries, source content, and escalation rules are still exploratory.

## Expected Package Path

AI Chatbot Planning Workshop.

## Expected Add-ons

None.

## Key Missing Values

Chatbot purpose, approved source content, escalation owner, data-capture rules.

## Likely Custom-Scope Triggers

Highly sensitive advice flows, multi-division governance, or pressure to quote implementation before planning is complete.

## What A Good Estimate Should Look Like

It should recommend planning only, avoid jumping straight to implementation, and state clearly what must be defined before Starter or Tailored can be quoted.
