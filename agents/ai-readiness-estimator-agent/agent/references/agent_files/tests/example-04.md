# Example 04

## Client Scenario

A service business wants a chatbot with structured qualification questions, routed lead capture, and richer business-specific journeys.

## Expected Package Path

AI Chatbot with AI Engine — Tailored.

## Expected Add-ons

None.

## Key Missing Values

Qualification flow goal, capture fields, final lead destination, approved journeys, restricted topics.

## Likely Custom-Scope Triggers

CRM integration, booking integration, bespoke application logic, or regulated advice flows.

## What A Good Estimate Should Look Like

It should explain why Tailored fits better than Starter, confirm whether the flow stays within standard tailored capability, and avoid hiding integration risk.
