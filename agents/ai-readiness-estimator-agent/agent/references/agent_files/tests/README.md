# Tests Control File

Use this file before opening files in `tests/`.

## Purpose

This folder contains validation material for checking package routing, estimate quality, output structure, and commercial safeguards.

## File Routing

### `test-plan.md`
Use first to understand what each test should validate.

### `example-01.md` to `example-05.md`
Use as worked validation scenarios for checking whether the estimator follows the required routing and output rules.

## Usage Rule

Use these files for self-checking, regression testing, or reviewing whether a proposed estimate follows the package, add-on, and commercial rules. Do not treat test examples as live client facts.
