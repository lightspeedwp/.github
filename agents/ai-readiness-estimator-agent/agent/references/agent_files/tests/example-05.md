# Example 05

## Client Scenario
A tour operator wants stronger AI visibility, but tourism entity modelling and schema complexity need auditing before implementation can be quoted.

## Expected Package Path
AI Search and Structured Data or AI Readiness Foundation, depending on whether baseline readiness already exists.

## Expected Add-ons
Tour Operator JSON-LD Audit Add-on.

## Key Missing Values
Booking platform, entity model, content structure, implementation expectation after the audit.

## Likely Custom-Scope Triggers
Complex booking integration, inconsistent product modelling, or tourism schema needs that exceed standard implementation scope.

## What A Good Estimate Should Look Like
It should choose the correct base package first, keep the JSON-LD add-on audit-first, and avoid presenting final implementation pricing before the tourism schema audit is complete.
