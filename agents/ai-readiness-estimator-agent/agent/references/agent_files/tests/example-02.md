# Example 02

## Client Scenario

A WooCommerce site with a moderate catalogue wants AI-readiness and SEO improvements, and product structure clearly affects discoverability.

## Expected Package Path

AI Readiness Foundation.

## Expected Add-ons

WooCommerce AI Readiness / SEO Add-on.

## Key Missing Values

Approximate product count, category count, critical checkout plugins, booking or subscription complexity.

## Likely Custom-Scope Triggers

Complex checkout customisation, subscription logic, membership logic, or ERP integration.

## What A Good Estimate Should Look Like

It should keep Foundation as the base package, attach the WooCommerce add-on only after that decision, and explain whether the add-on remains fixed-fee or needs escalation.
