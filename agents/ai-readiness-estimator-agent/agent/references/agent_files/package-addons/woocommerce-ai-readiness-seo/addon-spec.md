## Add-On Name

WooCommerce AI Readiness / SEO Add-on

## Purpose

Handle the additional complexity introduced by WooCommerce catalogue structure, product content, category logic, and commerce-specific discoverability needs.

## Applies To

- AI Readiness Foundation
- AI Search and Structured Data

## Use When

- the client site runs WooCommerce
- product and category architecture materially affects AI readiness, schema, or chatbot usefulness
- the base package remains correct but ecommerce-specific complexity must be layered on

## Includes

- WooCommerce-specific audit
- product and category structure review
- product-content readiness review
- core WooCommerce SEO and discoverability checks
- taxonomy and content-model recommendations
- agreed fixed-scope implementation notes or recommendations

## Excludes

- full catalogue rewrite
- checkout redevelopment
- ERP or marketplace integration
- complex merchandising strategy

## Onboarding Questions

- Roughly how many products are live?
- Roughly how many categories are in use?
- Are variable products used heavily?
- Are subscriptions, bookings, or memberships involved?
- Which plugins are critical to checkout?

## Values The Agent Should Gather

- WooCommerce status
- product count estimate
- category count estimate
- critical plugin summary
- integrations summary
- visible checkout and account-area complexity

## Confirmation Questions

Ask the client to confirm:

- product volume
- category volume
- variable-product complexity
- critical checkout plugins
- whether subscriptions, bookings, or memberships are involved

## Special Scoping Rule

Use this add-on only after the primary base package is chosen.

Keep it fixed-fee only when WooCommerce remains within the agreed fixed-scope profile, no major checkout or plugin conflicts are discovered, and advanced booking, subscription, or membership logic is not in scope.
