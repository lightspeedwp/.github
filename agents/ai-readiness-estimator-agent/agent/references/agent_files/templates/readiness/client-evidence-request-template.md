# Client Evidence Request Template

Use this template when LightSpeed needs to request the minimum evidence required to produce or firm up an AI-readiness estimate.

## Internal Guidance

Use the shortest version that still captures the blockers.

Ask only for information that materially affects:

- package routing
- scope confidence
- fixed-fee confidence
- custom-scope risk
- add-on suitability

Do not turn this into a long questionnaire unless the project genuinely needs one.

---

## Client Request Draft

Hi [Client Name],

To make sure we recommend the right next step for your website AI-readiness work, we need a small set of inputs before we finalise the estimate.

Please send through the following where available:

- your live website URL
- your platform or CMS, if known
- the main goal for this work
- whether you are looking for audit-only support, implementation planning, or a wider AI roadmap
- your target timing or deadline, if relevant
- any existing audit, strategy, governance, or proposal material that would help us avoid duplicating discovery

If relevant, it also helps to know:

- whether WooCommerce or ecommerce is in scope
- whether the site is multilingual or multi-brand
- whether there are any key integrations such as CRM, booking, ERP, helpdesk, or API dependencies
- whether there are any privacy, governance, or regulated-use constraints we should factor in early

Once we have that, we can confirm the best-fit package path and whether the current recommendation should stay provisional or move to a firmer scoped position.

Best,
[Your Name]

---

## Short Version

Hi [Client Name],

To firm up the estimate, please send:

- website URL
- platform / CMS
- main goal for the work
- whether this is audit-only or likely to include implementation planning
- any existing audit or planning documents

Thanks,
[Your Name]

---

## Internal Notes

Before sending:

- remove anything already confirmed
- keep only the true blockers
- avoid asking for technical detail that does not affect the current recommendation
- if the estimate is already safely audit-first, prefer the short version unless stronger scoping confidence is genuinely needed
