# Blocking Gaps Checklist

Use this checklist to decide what still blocks the workflow.

- [ ] Project or task type is clear enough to route the work.
- [ ] Primary goal is clear enough to produce the requested output.
- [ ] The key source asset or evidence set is available when the task depends on it.
- [ ] Scope boundaries are clear enough to avoid overcommitting.
- [ ] Exclusions are known when they materially affect safety or accuracy.
- [ ] Timeline, urgency, or approval constraints are known when they affect delivery.
- [ ] Approved sources are identified when public-facing or high-risk output is involved.
- [ ] Claim-sensitive statements have evidence or are clearly marked as unsupported.

## Rule

Ask only for the smallest missing blocker instead of reopening the full questionnaire.
