Use this checklist when the task may produce client-facing, published, operational, or otherwise approval-sensitive output.

## Approval gates

- [ ] The intended output type is clear.
- [ ] Approved sources are identified.
- [ ] Candidate or unapproved sources are clearly separated.
- [ ] Claim-sensitive wording has been reviewed or routed to a claim register.
- [ ] Exclusions and must-not-do rules are captured.
- [ ] Reviewer or approval owner is known, or the gap is explicitly flagged.
- [ ] Any legal, privacy, compliance, or safety review need is identified.
- [ ] The output is not presented as final if a required approval gate is still missing.

## Use notes

- Do not force a full approval workflow when one small blocking approval clarification is enough.
- If approval status is unclear, ask the narrowest useful question.
