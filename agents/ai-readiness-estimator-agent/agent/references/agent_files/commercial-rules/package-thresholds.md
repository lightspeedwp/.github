## Purpose

Define the minimum routing and evidence thresholds required before the estimator can recommend each package with confidence.

## Shared Threshold For Any Package

Before treating the package recommendation as commercially dependable, confirm:

- website URL
- platform
- project goal
- delivery type
- target timeline when timing affects scope confidence
- internal owner when approvals or handoff matter
- any sensitive or regulated use case

## Package-Specific Thresholds

### AI Readiness Foundation

Need enough evidence to confirm this is baseline readiness work, not schema-only, chatbot-only, or retainer work.

### AI Search and Structured Data

Need evidence that baseline readiness already exists or is strong enough that schema, crawl logic, and machine readability are the next priority.

### AI Chatbot Planning Workshop

Need evidence that chatbot intent exists but the use case, boundaries, sources, or escalation logic are still not defined enough for implementation quoting.

### AI Chatbot with AI Engine — Starter

Need an approved or clearly defined chatbot brief, approved source content, contact route, and confirmation that the use case stays within simple bounded behaviour.

### AI Chatbot with AI Engine — Tailored

Need a defined chatbot brief plus qualification goals, capture fields, lead destination, and confirmation that the work exceeds Starter but remains within standard tailored capability.

### Yoast AI Content Training

Need evidence that the client team manages content internally and that enablement is the main need.

### Ongoing AI Governance and Optimisation Retainer

Need evidence that implementation or launch work already exists and the next need is recurring review, tuning, and governance support.

## Add-On Thresholds

- WooCommerce AI Readiness / SEO Add-on requires confirmed WooCommerce usage plus meaningful product, category, plugin, or checkout complexity.
- Tour Operator JSON-LD Audit Add-on requires a travel or tour business plus tourism-specific entity-model complexity that must be audited before implementation quoting.

## Threshold Rule

If the threshold for a package is not met, route to the more appropriate package, ask only for the missing values, or hold the recommendation as provisional.
