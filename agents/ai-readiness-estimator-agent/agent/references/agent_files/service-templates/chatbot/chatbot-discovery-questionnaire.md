# Chatbot Discovery Questionnaire

Use this questionnaire during the planning phase to capture detailed requirements, expectations, and constraints for a proposed chatbot.
The responses will inform the use-case definition, source suitability, and implementation approach.

## Project

- **Client:** {{client.name}}
- **Website:** {{client.website_url}}
- **Prepared by:** {{owner.name}}

## Section 1: Goals and Scope

1. What is the primary purpose of the chatbot (e.g. support, sales, content discovery)?
2. What specific problems should the chatbot solve for users?
3. What business outcomes do you hope to achieve?
4. Are there any secondary use cases or future phases to consider?

## Section 2: Audience and User Journey

1. Who will use the chatbot (existing customers, prospects, partners, internal staff)?
2. What are typical questions or tasks these users would like help with?
3. Where will users encounter the chatbot (website, portal, chat widget, social)?
4. Are there personas or user segments with distinct needs?

## Section 3: Content and Sources

1. Which sources should the chatbot use (web pages, documents, knowledge bases)?
2. Are there any sources that must be excluded?
3. How will source content be updated and approved?
4. Are there proprietary or sensitive data sources? If so, what is the plan to handle them?

## Section 4: Boundaries and Constraints

1. What topics are off limits or require escalation?
2. What information should never be provided by the chatbot (e.g. personal data, pricing guarantees, legal advice)?
3. What regulatory or compliance constraints apply?
4. What languages or regional variations need to be supported?

## Section 5: Integration and Functionality

1. Should the chatbot connect to any back-end systems (e.g. CRM, booking, e-commerce)?
2. Are there any existing APIs or workflows that need to be integrated?
3. Should the chatbot trigger any actions (e.g. create tickets, send notifications)?
4. What data should be captured from users, and where should it go?

## Section 6: Success Metrics and Review

1. How will you measure the chatbot’s success (KPIs, user feedback, adoption rates)?
2. Who will review conversation logs and how often?
3. What is the desired timeframe for launch and iteration?

## Additional Notes

Provide any other context or requirements that may affect the planning and implementation of the chatbot.
