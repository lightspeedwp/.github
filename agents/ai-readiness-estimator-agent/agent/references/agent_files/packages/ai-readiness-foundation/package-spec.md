## Package Name

AI Readiness Foundation

## Purpose

Establish a clear baseline for the website's AI readiness, search-readiness, content clarity, and measurement setup before any wider implementation, rebuild, schema, or AI-search optimisation work is scoped.

## Use When

- the client needs a baseline AI readiness assessment before wider implementation work is scoped
- the site needs a clear view of current search-readiness, content clarity, and measurement setup
- LightSpeed needs a recommended base package before quoting further implementation-heavy work
- this is the first package in the AI package path

## Includes

- initial live-site audit and AI readiness review
- review of current SEO foundations, including metadata, headings, indexing signals, sitemap, canonicals, and redirects
- review of internal linking and priority content structure
- review of Yoast SEO configuration
- review of GA4, Google Search Console, and Site Kit baseline setup where available
- identification of content-hygiene and discoverability quick wins
- high-level review of trust, policy, and public content clarity where relevant
- AI readiness findings summary
- prioritised roadmap for follow-on improvements

## Excludes

- full technical implementation of recommendations
- full sitewide copywriting or page rewrites
- chatbot strategy, planning, or implementation
- large-scale development, migrations, or custom integrations
- advanced schema modelling across all content types
- full performance engineering or speed optimisation
- formal legal, privacy, or compliance advice

## Deliverables

- AI Readiness Foundation findings summary
- prioritised recommendations and next-step roadmap
- clear list of dependencies, risks, and follow-on workstreams

## Onboarding Questions

- What is the main outcome you want from AI readiness work?
- Is this foundation only, or the first step toward broader search, content, or AI work?
- Do you already use Yoast SEO, Site Kit, GA4, and Google Search Console?
- Is there any relevant reference material or prior audit work we should review?
- Are there any known technical, content, policy, or tracking concerns we should be aware of before the audit?

## Values The Agent Should Gather From The Live Site Or References

- website URL
- platform
- project goal
- delivery type
- live-site SEO baseline signals
- internal linking and content-structure observations
- Yoast SEO status
- GA4 status
- Google Search Console status
- Site Kit status
- trust, policy, and public-content clarity observations where relevant
- internal owner / named client owner
- relevant reference material availability

## What The Agent Should Ask The Client To Confirm

- GA4, Google Search Console, and Site Kit status where relevant
- the named client owner for content, approvals, and follow-up decisions
- whether Yoast SEO Premium-specific configuration or workflows are expected
- any missing reference material or context needed for a reliable foundation review
- whether they want to include the optional Yoast SEO Premium Training Session alongside the foundation package

## Fixed-Fee Eligibility Rules

Remains fixed-fee when:

- the work stays within the standard AI Readiness Foundation review and findings scope
- the website can be assessed through the live site and normal reference material without major technical blockers
- no rebuild, migration, advanced schema, or implementation-heavy work is being included in this phase
- follow-on implementation or specialist work is quoted separately after the foundation findings are complete

## Dependencies / Client Requirements

- access to the live website and relevant reference material
- confirmation of GA4, Search Console, and Site Kit status where relevant
- named client owner for content, approvals, and follow-up decisions
- purchase of a valid Yoast SEO Premium licence by the client if Premium-specific configuration or workflows are expected: <https://yoast.com/product/yoast-seo-premium-wordpress/

## Estimated Effort Band

- M

## Custom-Scope Triggers

- rebuild or migration work being requested within the foundation phase
- advanced schema modelling across broader content types
- implementation-heavy technical work beyond the standard findings package
- large-scale development, custom integrations, or unusual platform complexity
- major content restructuring or rewrite requirements
- severe tracking, indexing, or technical instability that prevents a standard review path

## Likely Related Add-Ons

- Yoast SEO Premium Training Session when the client team wants editorial enablement after the foundation review
- WooCommerce AI Readiness / SEO Add-on when WooCommerce materially affects readiness or discoverability
- Tour Operator JSON-LD Audit Add-on when travel-schema complexity must be audited before quoting

## Notes

- This should be positioned as the recommended base package.
- Any rebuild, migration, advanced schema, or implementation-heavy work should be quoted separately after the foundation findings are complete.

## Next-Step / Routing Notes

- Position this as the recommended base package before any wider implementation work is scoped.
- Start with the audit of the live site and available references.
- Use `/packages/assessment-values.md` to collect shared values in batches.
- Use `/packages/package-index.md` to confirm that this is the primary base package.
- Consider add-ons only after the base package path is confirmed.
- Keep the optional Yoast SEO Premium Training Session alongside, not instead of, the foundation package.
