## Package Name

AI Chatbot Planning Workshop

## Purpose

Define whether the client should deploy a chatbot, what it should do, what content it can use, what it must avoid, and what implementation tier is appropriate.

## Use When

- the client wants a chatbot but scope is still unclear
- source content, boundaries, and escalation rules need definition first
- a chatbot brief is needed before implementation is quoted

## Includes

- review of chatbot questionnaire or discovery inputs
- use-case and audience definition
- source-content and exclusion review
- escalation and fallback planning
- lead-capture planning
- launch-gate definition
- success-metric definition
- recommendation of implementation tier

## Excludes

- chatbot build
- plugin configuration
- CRM or API integration
- live prompt tuning after launch

## Onboarding Questions

- What is the main job the chatbot should do?
- Who will use the chatbot?
- What approved source content should it use?
- What topics must it avoid or escalate?
- Should it capture leads or user data?
- Who owns approvals and transcript review?

## Values The Agent Should Gather From The Live Site Or References

- website URL
- FAQ, help, policy, and source-content presence
- site-search presence
- WooCommerce status if relevant
- sensitive or regulated use cases
- existing chatbot or AI strategy notes
- project goal, delivery type, timeline, and internal owner

## What The Agent Should Ask The Client To Confirm

- chatbot purpose
- target audience
- source-content owner
- escalation route
- data-capture rules
- whether the result should route to Starter or Tailored implementation

## Fixed-Fee Eligibility Rules

Remains fixed-fee when:

- the workshop remains within standard discovery format
- no multi-division or unusually complex governance programme is required
- the work stays focused on chatbot definition rather than implementation

## Custom-Scope Triggers

- unusually complex governance or approval structures
- multiple divisions or materially different chatbot audiences
- highly sensitive or regulated advice flows
- requests that move from planning into implementation or integration work

## Likely Related Add-Ons

- none by default; decide base chatbot path first, then route to Starter or Tailored implementation

## Next-Step / Routing Notes

- Use this before any chatbot implementation package when scope is not yet clear.
- Gather values in batches and confirm only the missing items.
- After the workshop, route to `AI Chatbot with AI Engine — Starter` or `AI Chatbot with AI Engine — Tailored`.
