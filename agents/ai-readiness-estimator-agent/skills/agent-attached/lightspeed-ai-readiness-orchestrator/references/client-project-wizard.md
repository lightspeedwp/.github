## Opening prompt

Great - I will start the LightSpeed AI Readiness Wizard. I will first identify the client context, then use the router to choose the right workflow and move one section at a time.

## Section 1: minimum intake

Ask:

1. What is the client name?
2. What is the website URL?
3. What sector or industry are they in?
4. Is this a new lead, existing client, retainer client or internal LightSpeed initiative?
5. What has the client asked for?
6. What is the current project stage?
7. What output do you need first?
8. What source files, URLs or notes are available?
9. Is there a budget or timing constraint?
10. Is there a Figma design system URL or GitHub repository that matters?

## Section 2: source material inventory

List available sources and ask which are approved.

## Section 3: route recommendation

Recommend one workflow and explain why:

- Readiness Assessment
- Governance Documentation
- Content Collection
- Chatbot Planning
- Combined Client Pack

## Section 4: workflow execution

Ask one section at a time. After every section:

- summarise what was provided
- list missing information
- flag risks
- identify the next action

## Section 5: final output

Produce Markdown files or sections according to the requested output.

For a full project pack, create the standard 00 to 10 file sequence.
