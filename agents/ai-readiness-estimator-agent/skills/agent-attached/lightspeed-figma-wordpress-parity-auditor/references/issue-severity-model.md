# Issue Severity Model

| Severity | Meaning | Launch treatment |
|---|---|---|
| P0 Launch Blocker | Blocks launch, key conversion, accessibility, navigation, forms or brand integrity | Must fix before launch |
| P1 High | Important user-facing or editor-facing defect | Fix before launch if possible |
| P2 Medium | Noticeable mismatch or maintainability issue | Can launch if accepted and scheduled |
| P3 Low | Polish or documentation | Backlog |

## Common P0 examples

- inaccessible navigation
- invisible focus state
- form cannot be submitted
- broken mobile layout on key page
- dark mode text unreadable
- missing critical CTA
- theme token mismatch causing broad visual failure
