# Component to Block Mapping

## Mapping options

Map Figma components to:

- core WordPress block
- core block variation
- custom block
- block pattern
- template part
- global style
- plugin-provided block
- not implemented

## Check each component for

- visual parity
- content flexibility
- responsive behaviour
- editor usability
- accessibility states
- dark mode support
- design-token usage
- maintainability

## Recommended fields

- Figma component
- WordPress implementation
- Block/pattern file
- Template usage
- Status
- Severity
- Notes
- Fix owner
