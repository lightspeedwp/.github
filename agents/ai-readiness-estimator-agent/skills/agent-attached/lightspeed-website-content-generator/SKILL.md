# LightSpeed Website Content Generator

## Purpose

Generate website-ready content from approved LightSpeed planning artefacts, especially outputs produced by the Content Collection Planner, AI Readiness Assessor, AI Governance Documentor and Chatbot Planner workflows.

Use this skill after content collection has identified required artefacts, source status, claim status, approval state and chatbot suitability.

## Core rule

Do not invent claims, statistics, case-study outcomes, pricing, guarantees, legal wording, compliance statements or AI/ROI results.

If evidence is missing, either:

- rewrite cautiously as a capability or pilot statement, or
- flag the item as `Evidence Required` in the internal notes.

## Inputs to accept

Accept any combination of:

- page briefs
- content collection checklists
- source-of-truth registers
- claim registers
- approved stats lists
- FAQ source libraries
- existing website copy
- governance notes
- service or solution outlines
- case-study notes
- chatbot planning briefs
- launch audit notes

If the user has not provided enough source material, generate a safe outline and list missing inputs instead of pretending the content is final.

## Output types

Generate:

- homepage drafts
- service page drafts
- solution page drafts
- lifecycle/process page drafts
- company FAQ pages
- page-level FAQs
- CTA blocks
- meta titles and descriptions
- schema-ready FAQ answers
- case-study drafts
- policy page drafts
- chatbot-safe answer snippets
- complete content packs in Markdown

## Workflow

1. Identify the requested output type.
2. Identify available source material and approval status.
3. Check claim, evidence and chatbot-safety rules.
4. Draft public-facing content in UK English.
5. Use LightSpeed's practical, professional, systems-led tone.
6. Separate public-facing content from internal review notes.
7. Include SEO, schema and internal-linking suggestions where relevant.
8. Mark the review status and chatbot-safe status.
9. Flag missing evidence, risky claims and legal/privacy review needs.
10. Suggest the next content or governance step.

## Required output sections

For page, service, solution, FAQ and case-study drafts, include:

- Public-facing content
- Suggested CTA
- Suggested internal links
- SEO title and meta description
- Suggested schema
- Claims used
- Claims avoided
- Evidence required
- Chatbot-safe status
- Review status
- Internal LightSpeed notes

For content packs, create numbered Markdown files and a README-style index.
