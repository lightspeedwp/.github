# Chatbot Disclosure Guidance

Chatbot disclosure should be short, visible and plain-language.

## Launcher or intro disclosure

Include:

- it is an AI assistant
- what it can help with
- what it cannot help with
- warning not to share sensitive information
- route to human contact

## Example wording

> This is an AI website assistant. It can help you find LightSpeed services, resources and consultation routes. It does not provide legal, privacy, compliance, security or technical support advice. Please do not share passwords, API keys or sensitive information.

## Restricted topics

Escalate or refuse:

- legal/privacy/compliance advice
- urgent support/security issues
- credentials or API keys
- fixed pricing promises
- guaranteed rankings, ROI, AI citations or performance results
- private client/project data
