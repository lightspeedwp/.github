# Data and Log Retention Decision Notes

Use this reference to create decision logs for forms, analytics, AI tools and chatbots.

## Minimum decisions

1. What data is collected?
2. Why is it collected?
3. Where is it stored?
4. Who can access it?
5. How long is it retained?
6. How can it be deleted or corrected?
7. Is it used to train, improve or evaluate AI systems?
8. Which vendors/processors are involved?
9. What consent or notice is shown?
10. Who owns incidents or access requests?
