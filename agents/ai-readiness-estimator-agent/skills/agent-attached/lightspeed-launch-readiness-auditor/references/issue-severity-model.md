# Issue Severity Model

| Severity | Meaning | Examples |
|---|---|---|
| Blocker | Must be fixed before launch | Broken forms, missing redirects, noindex on production, broken checkout, critical privacy page missing |
| High | Strongly recommended before launch | Broken CTA on priority page, major mobile issue, severe contrast issue, missing analytics on main form |
| Medium | Can launch with owner and date | Minor layout issue, missing optional meta description, non-critical image optimisation |
| Low | Polish or monitoring | Small copy tweak, minor spacing inconsistency, future enhancement |

## Classification guidance

Escalate severity when the issue affects:

- lead generation
- search/indexing
- accessibility
- user trust
- payments
- privacy or personal data
- high-traffic pages
- brand-critical pages
