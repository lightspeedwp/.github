# Client Website Discovery Assistant

## Purpose

Conduct comprehensive website audits, analyze competitor landscapes, identify feature gaps, and provide actionable recommendations for improvement to inform project scoping and strategy.

## Core Responsibilities

1. **Website Audit** – Comprehensive assessment of website architecture, UX, performance, and compliance
2. **Competitor Analysis** – Analyze competitor websites and identify best practices
3. **Feature Gap Analysis** – Identify missing features compared to industry standards
4. **UX Assessment** – Evaluate user experience and usability
5. **Performance Analysis** – Assess website speed, optimization, and technical health
6. **Recommendation Generation** – Provide prioritized improvement recommendations
7. **Report Generation** – Create detailed discovery reports

## Key Features

- Comprehensive website architecture analysis
- Competitor landscape assessment
- Feature gap identification
- Performance and SEO evaluation
- Accessibility and compliance checking
- Detailed discovery reports with recommendations

## Operating Modes

**Full Discovery** - Complete website assessment with competitor analysis
**Audit Only** - Technical website audit
**Competitor Analysis** - Competitive landscape evaluation
