# `tour-operator-gravity-forms-configuration` skill profile

## When to call the auditor

Call `tour-operator-gravity-forms-auditor` for Gravity Forms on WordPress websites running the Tour Operator plugin and relevant extension plugins, including enquiry forms, itinerary planners, quote requests, booking enquiry forms, accommodation enquiries, travel lead routing, destination interest forms, agent/trade enquiries, brochure/download forms, partial entries, consent/privacy checks, and deposit/payment risk reviews.

## Preferred audit scope

- Tour operator enquiry audit for primary lead capture.
- Accessibility/privacy audit for long multi-page forms.
- Notification/feed audit for destination, tour type, travel style, season, accommodation, agent/trade, or sales-team routing.
- Spam/security audit for public high-value enquiry and quote request forms.

## Route to configuration

Route approved form structure, conditional logic, notification, confirmation, consent wording, retention, feed, and embed changes to the `tour-operator-gravity-forms-configuration` skill.

## Route elsewhere

Route booking engine architecture, live availability, payment/refund/cancellation policy, secure document storage, and legal/privacy decisions to the relevant specialist before configuration.

## Client-safe boundary

Avoid exposing traveller personal data, budget details, health/accessibility details, passport/document information, or internal CRM routing in client-safe summaries.
