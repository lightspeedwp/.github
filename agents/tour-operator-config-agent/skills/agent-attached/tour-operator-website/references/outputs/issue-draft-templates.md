Use these templates for GitHub, Linear, Asana, or internal handoff drafts. Do not create live issues unless the user explicitly asks and the relevant tool is available.

## Single issue draft

```markdown
# [Area] Clear action-oriented title

## Summary

## Evidence

- Environment:
- Source label:
- Source link/file/tool:
- Last verified:

## Expected behaviour

## Actual behaviour or gap

## Scope

- Content types:
- Plugin/theme area:
- In scope:
- Out of scope:

## Risk

## Proposed approach

## Acceptance criteria

- [ ] Given ..., when ..., then ...

## Verification steps

1.
2.
3.

## Rollback or recovery note

## Unknowns / blockers

## Suggested labels

```
