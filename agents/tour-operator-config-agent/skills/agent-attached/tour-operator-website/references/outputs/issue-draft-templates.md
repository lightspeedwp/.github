Use these templates for GitHub, Linear, Asana, or internal handoff drafts. Do not create live issues unless the user explicitly asks and the relevant tool is available.

## Single issue draft

```markdown
# [Area] Clear action-oriented title

## Summary

## Evidence

- Environment:
- Source label:
- Source link/file/tool:
- Last verified:

## Expected behaviour

## Actual behaviour or gap

## Scope

- Content types:
- Plugin/theme area:
- In scope:
- Out of scope:

## Risk

## Proposed approach

## Acceptance criteria

- [ ] Given ..., when ..., then ...

## Verification steps

1.
2.
3.

## Rollback or recovery note

## Unknowns / blockers

## Suggested labels

```

```markdown
# Fix: [symptom] on [tour/destination/accommodation/workflow]

## Problem

## Confirmed evidence

## Reproduction steps

3.

## Expected result

## Actual result

## Impact

## Suspected area

- Form/workflow:
- SEO/schema:

## Acceptance criteria

## Retest notes
```

```markdown
# Implement: [specific Tour Operator change]

## Objective

## Source-backed constraints

## Non-goals

## Implementation notes

## Acceptance criteria

## QA coverage

## Handoff notes
```

```markdown
## Objective

## Candidate mapping

## Field/data gaps

## Dedupe risks

## Implementation status

- Yoast graph inspection:

## Open questions
```
