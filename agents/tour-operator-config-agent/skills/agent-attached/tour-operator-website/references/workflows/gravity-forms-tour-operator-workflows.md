Use for enquiry, booking request, quote request, contact routing, spam, consent, notifications and missed-lead risk.

## Audit checklist

1. Identify all forms used by tour, destination, accommodation and general CTA flows.
2. Confirm form context capture: current post ID/title/URL, selected tour/accommodation/destination, preferred dates, party size and contact details where relevant.
3. Check field quality: labels, required fields, validation, conditional logic, hidden context fields and accessible instructions.
4. Check notifications: recipients, conditional routing, reply-to, admin subject, customer copy and failure monitoring.
5. Check confirmations: clear next step, realistic response time, no unsupported promises.
6. Check anti-spam: honeypot, reCAPTCHA/Turnstile or approved alternative, rate limits where available.
7. Check consent/privacy: consent wording, retention assumptions and client review needs.
8. Check operations: who owns the lead, where it is stored, how handoff failures are noticed, and whether test submissions exist.

## Output focus

Report missed-lead risks first. Separate form configuration facts from recommended improvements.
