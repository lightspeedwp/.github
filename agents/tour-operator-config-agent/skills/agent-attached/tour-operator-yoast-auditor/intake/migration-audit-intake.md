# Migration Audit Intake

Use this when a travel site rebuild, URL change, site merge or launch migration is in scope.

## Required migration evidence

- Old site URL and new site/staging URL.
- Old/new URL map for important pages, tours, destinations and accommodation.
- Redirect map or redirect rules.
- Sitemap index and sitemap files for old and new structures where available.
- Canonical output on sample new URLs.
- Meta robots output on sample new URLs.
- Metadata carry-over rules or samples.
- Travel taxonomy/archive changes.
- Enquiry path changes.
- Launch date or launch window if relevant.

## Migration-specific checks

- Important old URLs should have clear redirect destinations.
- Important new URLs should be indexable unless intentionally excluded.
- Canonicals should point to the intended final URL.
- Sitemaps should use the final domain.
- Destination, accommodation and travel-style archive behaviour should be deliberate.
- Enquiry and thank-you page indexation should match the intended search policy.
