# Audit Intake

Use this when the audit scope is unclear or evidence is missing.

Ask only for blocking information. Prefer the smallest useful set.

## Minimum intake

1. Site URL and whether it is staging or live.
2. Audit scope: configuration review, content metadata, tour and destination archives, accommodation relationships, schema output, migration readiness, launch QA or full-site review.
3. Output type: fast snapshot, client report, internal report, developer handoff, migration report, schema QA or evidence gap report.
4. Important pages, tours, destinations, accommodation or taxonomies.
5. Site type: tour operator, safari operator, travel agency, destination guide, accommodation-led travel site, multilingual travel site, migration/rebuild.
6. Available evidence: screenshots, crawl export, source HTML, rendered page output, schema output, sitemap URLs, robots.txt, llms.txt, redirect map or admin screenshots.

## Fast intake question

> Please share the site URL, the audit focus, and any important tour, destination, accommodation or taxonomy URLs you want checked.
