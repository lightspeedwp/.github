Use this profile for tour operator, safari, travel agency, destination-led, and accommodation-linked travel websites.

## Common content types

- Tours.
- Destinations.
- Accommodation.
- Travel styles.
- Itineraries.
- Specials.
- Reviews or testimonials.
- Enquiry and lead-generation pages.
- Blog or guide content.

## Audit emphasis

- Important tour and destination URLs are indexable when intended.
- Destination, accommodation and travel-style archives have clear metadata, canonical output and sitemap behaviour.
- Tours link clearly to related destinations and accommodation where available.
- Enquiry journeys avoid accidental search-index exposure for thank-you pages.
- Schema output does not misrepresent travel content.
- Metadata uses human-readable wording that matches search intent.
- Rebuilds protect important legacy travel URLs through planned redirects.

## Common risks

- Thin destination archives.
- Duplicated tour metadata across similar itineraries.
- Unclear canonical output for related travel pages.
- Hidden or weak internal links between tours and destinations.
- Staging URLs leaking into metadata or sitemaps.
- Thank-you pages accidentally indexable.
- Schema conflicts caused by theme or plugin output overlap.
