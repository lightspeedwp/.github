# Migration and Rebuild Audit Profile

Use this profile when a travel site is moving domains, changing URLs, rebuilding templates, consolidating content or preparing for launch.

## Main checks

- Old/new URL mapping covers important pages, tours, destinations and accommodation.
- Redirect rules exist for important old URLs.
- New URLs have final-domain canonicals.
- XML sitemaps contain intended public URLs only.
- Robots.txt and meta robots do not block important public content.
- Metadata carry-over is intentional.
- Destination and travel-style archives are included or excluded deliberately.
- Enquiry and thank-you pages follow the intended indexation policy.

## Handoff emphasis

Separate SEO migration risks from content strategy issues. Developer handoff items should name affected URLs, expected output and QA steps.
