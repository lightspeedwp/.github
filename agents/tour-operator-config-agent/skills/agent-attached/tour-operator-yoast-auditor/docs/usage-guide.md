# Usage Guide

Use this skill for evidence-led Yoast audits on travel and tour operator websites.

## Good use cases

- Reviewing Yoast metadata and schema output for tours, destinations and accommodation.
- Checking whether travel-style and destination archives have safe indexation and canonical output.
- Auditing how enquiry pages and thank-you pages are represented in search output.
- Reviewing launch readiness after a travel website rebuild.
- Turning Yoast findings into client-ready reports or developer handoffs.

## Route away

Route to `tour-operator-yoast-configuration` for first-time setup, reusable defaults, Search Appearance templates, sitemap setup, schema setup, breadcrumb configuration or implementation-ready configuration playbooks.

## Recommended intake

Ask for:

- Site URL and staging/live status.
- Audit focus and output format.
- Important pages, tours, destinations, accommodation and taxonomies.
- Known launch, migration or content relationship concerns.
- Available evidence: crawl export, screenshots, source HTML, rendered output, schema output, sitemap URLs and admin screenshots.

## Output formats

Default output is Google Doc-ready Markdown. Use client report, internal report, page table, tour relationship report, schema QA, launch QA, migration report, evidence gap report or developer handoff as appropriate.
