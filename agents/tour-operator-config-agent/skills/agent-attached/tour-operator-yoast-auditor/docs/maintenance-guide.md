# Maintenance Guide

## Updating official-source notes

Review official Yoast, Yoast developer, WordPress, Google Search and Schema.org sources before changing capability notes. Update `references/source-register.md` with date accessed, status, confidence and feature scope.

## Updating templates

When changing a template, preserve these fields: scope, evidence status, limitations, findings, priority, confidence, recommendation, owner or next route, retest/validation step and client-safe wording.

## Updating tour relationship guidance

Keep relationship checks focused on observable SEO output and content clarity:

- tours to destinations
- tours to accommodation
- tours to itinerary sections
- tours to travel styles
- specials to related travel content
- review content to relevant pages
- enquiry journey paths

Do not turn the audit skill into a setup playbook. Route setup work to `tour-operator-yoast-configuration`.

## Versioning

Record meaningful changes in `docs/changelog.md`, especially changes to routing, templates, evidence requirements, safety rules and source handling.
