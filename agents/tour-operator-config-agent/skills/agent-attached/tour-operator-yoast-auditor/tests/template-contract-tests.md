# Template Contract Tests

## Required fields

Every report template must include:

- Scope reviewed.
- Evidence status or evidence source.
- Findings table with priority, confidence, risk, recommendation, owner/route and retest.
- Evidence gaps or limitations.
- Client-safe note.

## Client-safe note rule

Every client-facing audit, launch, migration, relationship or schema template must include a `## Client-safe note` that avoids ranking guarantees.

## Score rule

A score may only be used when reviewed evidence is broad enough. Otherwise output `## Score status` and state what evidence is needed before scoring.
