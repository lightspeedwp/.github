Use this file to decide what evidence supports each finding.

## Evidence by issue type

| Issue type | Strong evidence | Weak evidence |
|---|---|---|
| Metadata missing or weak | Rendered/source title and meta description | User memory only |
| Canonical issue | Source HTML canonical and intended URL | Screenshot without source |
| Indexation issue | Meta robots, robots.txt, headers and sitemap evidence | Search result snippet only |
| Sitemap issue | Sitemap index and relevant sitemap files | Verbal claim only |
| Schema issue | Raw schema graph output | Visual page screenshot only |
| Redirect issue | HTTP response chain or redirect map | Assumed old URL behaviour |
| Travel relationship issue | Observed links, related fields, URLs and metadata | Unverified content notes |
| Enquiry path issue | Enquiry URL, thank-you URL, meta robots and sitemap status | Form screenshot only |

## Confidence labels

- High: direct current evidence supports the finding.
- Medium: evidence strongly implies the finding but does not prove every detail.
- Low: plausible issue with limited evidence.
- Blocked: minimum evidence is missing.
