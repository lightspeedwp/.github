# Schema Audit Reference

Use this file when structured data or Yoast schema graph output is in scope.

## Inspect

- Schema graph output on representative pages.
- Organisation and website schema presence where relevant.
- WebPage, Article or other page-type output from Yoast.
- Breadcrumb schema consistency with visible breadcrumbs.
- Conflicts with theme or plugin schema output.
- Missing inputs that block accurate schema output.
- Travel-specific claims that may need evidence or editorial review.

## Rules

- Do not invent schema types from the page topic alone.
- Do not state that a rich result is guaranteed.
- Separate Yoast configuration gaps from code-level schema conflicts.
- Use official Schema.org, Google Search and Yoast documentation for detailed capability claims.

## Output

Include affected URL, observed schema, issue, confidence, risk, owner, recommendation and retest step.
