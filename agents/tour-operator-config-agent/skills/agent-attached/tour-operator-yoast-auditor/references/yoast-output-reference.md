# Yoast Output Reference

Use this file when checking standard Yoast output.

## Common output to inspect

- SEO title.
- Meta description.
- Canonical URL.
- Meta robots.
- Open Graph title, description and image.
- Twitter/X card output where relevant.
- Breadcrumb output and breadcrumb schema.
- Schema graph output.
- XML sitemap index and relevant sitemap files.
- Robots.txt and llms.txt where available.

## Travel-site sample coverage

For a representative audit, include:

- Home page.
- One important tour page.
- One important destination page.
- One destination archive.
- One accommodation page or archive where relevant.
- One travel-style archive where relevant.
- One enquiry page.
- One article or guide page if the site uses content marketing.
