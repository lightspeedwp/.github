# Tour Operator Intake

Use this intake when the request involves destination, tour, accommodation, travel-style, guide, itinerary, FAQ or enquiry-led content.

## Blocking questions only

Ask only if the answer changes the recommendation.

- What content types exist: destinations, tours, accommodation, travel styles, guides, enquiry pages or translated pages?
- Which page groups are most important for leads?
- Are any tours seasonal, retired or replaced?
- Is there a migration or URL restructure?
- Is there source copy approved for metadata and FAQ content?
- Do you have rendered output, sitemap URLs, settings exports or crawl evidence?

## Safe assumptions

If details are missing, assume planning mode and avoid recommending live indexation, canonical, schema or redirect changes without approval.
