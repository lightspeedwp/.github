# Remediation Backlog Model

Use this model for action lists after audits.

## Fields

- issue
- affected area
- evidence
- confidence
- severity
- priority
- recommended action
- owner route
- approval needed
- QA required
- smallest next action

## Priority guidance

Prioritise indexation, canonical, redirect, sitemap and schema risks before metadata polish. Prioritise high-value destination, tour, accommodation and enquiry pages before low-value archives.
