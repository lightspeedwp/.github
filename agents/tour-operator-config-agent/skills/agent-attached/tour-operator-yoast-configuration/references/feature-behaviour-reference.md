# Feature Behaviour Reference

Use this reference for common Yoast behaviour checks.

## Behaviour boundaries

- Settings are not proof of rendered output.
- Schema validity is not proof of rich-result display.
- Redirect plans are not proof of live redirects.
- Sitemap inclusion should align with indexation decisions.
- Canonical and robots checks must be sampled after relevant changes.

## Common mistakes

- leaving low-value archives indexable by accident
- excluding strategic destination archives without approval
- relying on default metadata across many tours
- using unsupported claims in meta descriptions
- missing QA after redirect imports
- not checking translated canonicals and alternates
