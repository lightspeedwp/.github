# Bulk Metadata Governance

Use this reference for high-volume title, description or social metadata changes.

## Required controls

- source of each row
- approval state
- affected page group
- import route
- backup or rollback plan
- sample QA set
- post-change crawl or rendered-output sample

## Tour operator sampling

Include at least one destination, tour, accommodation, guide and enquiry page where present.

## Rule

Never treat a spreadsheet as proof of approval or live output.
