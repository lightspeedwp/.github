# Schema Reference

Use this reference for schema review and schema decision support.

## Evidence hierarchy

- current rendered JSON-LD
- Yoast schema settings
- visible page content
- approved source copy
- Schema.org vocabulary
- Google Search Central eligibility notes

## Common valid areas

- Organization
- WebSite
- WebPage
- Article
- FAQPage
- BreadcrumbList
- Place-style entity modelling where the vocabulary and content support it

## Rules

- Do not add schema for claims that are not visible or approved.
- Do not treat schema validity as proof of rich-result display.
- Do not overstate FAQ or HowTo outcomes.
- Check schema output after theme, plugin, template and custom-code changes.
- For custom schema, create a developer handoff with source fields, fallback rules, test URLs and rollback notes.
