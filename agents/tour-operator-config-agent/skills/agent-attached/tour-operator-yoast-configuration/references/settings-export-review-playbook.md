# Settings Export Review Playbook

Use this when the user provides Yoast settings, screenshots or copied admin values.

## Review steps

1. Identify the site type and page groups.
2. Separate observed settings from inferred live behaviour.
3. Flag settings that change indexation, sitemap, schema, breadcrumbs or metadata templates.
4. Recommend rendered-output sampling before approval.
5. Produce a settings-export review when requested.

## Evidence boundary

A settings export does not prove live title, meta, robots, canonical, sitemap or schema output.
