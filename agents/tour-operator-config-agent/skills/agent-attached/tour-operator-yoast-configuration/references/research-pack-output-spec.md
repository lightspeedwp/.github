# Research Pack Output Spec

Use this spec when building or refreshing reference data.

## Source register fields

- title
- source URL
- accessed date
- source owner
- feature area
- key facts
- configuration relevance
- developer relevance
- limitations
- source type
- confidence
- status

## Output rules

- Use official Yoast, WordPress, Google Search Central and Schema.org sources first.
- Mark unscanned rows as research targets.
- Keep packaging claims separate from behaviour claims.
- Capture limitations and date sensitivity.
