# Evidence State Model

Use these labels in findings and research packs.

- **current verified source**: checked in the current workflow.
- **scanned evidence**: opened and summarised, but may need date review.
- **research target**: queued, not scanned.
- **user-provided evidence**: supplied by the user and not independently verified.
- **inference**: reasoned from evidence but not directly proven.
- **stale**: known or likely outdated.
- **contradictory**: conflicts with another source.
