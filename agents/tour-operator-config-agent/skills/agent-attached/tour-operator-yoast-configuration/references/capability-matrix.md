# Capability Matrix

Use this reference when checking which Yoast capability may support a requested workflow.

| Area | Typical use | Verification need |
|---|---|---|
| Search appearance | title and description templates | verify current UI path if client-facing |
| XML sitemaps | include or exclude content groups | sample sitemap URLs |
| Breadcrumbs | visible and structured breadcrumb output | check theme support and rendered output |
| Schema | graph output and custom pieces | validate rendered JSON-LD |
| Redirect manager | premium redirect planning | verify entitlement and live status |
| AI-assisted metadata | candidate titles and descriptions | verify packaging and approval state |
| `llms.txt` | AI-facing source hints | avoid Google ranking claims |

Do not make entitlement claims without current verification.
