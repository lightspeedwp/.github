# AI-assisted SEO Workflow

Use this reference when metadata, FAQ copy or summary content was generated or refined with AI.

## Rules

- Treat AI text as candidate copy, not approved source evidence.
- Check every claim against approved page content.
- Mark missing proof clearly.
- Keep human approval separate from implementation.
- QA rendered output after admin entry or import.

## Recommended approval states

- approved
- needs edit
- needs source evidence
- rejected
- not reviewed
