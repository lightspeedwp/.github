# Developer API Reference

Use this reference when a developer handoff is needed for Yoast output customisation.

## Guidance

- Prefer documented Yoast APIs, filters, presenters and schema graph extension points.
- Use pseudo-code unless the source was verified in the current task.
- Do not advise direct database edits to Yoast indexables as routine practice.
- Define source fields, fallback rules, target templates and test URLs.
- Require rendered-output QA after deployment.

## Handoff sections

- goal
- affected templates
- current evidence
- proposed technical route
- pseudo-code or implementation notes
- risks
- test plan
- rollback notes
