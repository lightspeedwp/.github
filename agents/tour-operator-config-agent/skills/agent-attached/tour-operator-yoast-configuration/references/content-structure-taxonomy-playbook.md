Use this playbook for archive, taxonomy and content-structure decisions.

## Decision inputs

Collect these inputs before recommending indexation or sitemap settings:

- taxonomy name and purpose
- number of public terms
- sample archive URLs
- visible intro copy
- listed content quality
- internal links
- overlap with destination, tour, accommodation or guide pages
- current title, meta, canonical, robots and sitemap state
- stakeholder goal for the archive

## Recommended decision options

- **Keep indexable** when the archive answers real search intent and has useful, unique content.
- **Improve before indexation** when the archive has potential but thin content.
- **Noindex** when the archive is useful internally but weak for search.
- **Consolidate** when multiple terms target the same intent.
- **Redirect** when a term has been replaced and has a clear successor.

## Tour operator examples

- Destination archives usually deserve review before noindex because they often support search journeys.
- Travel-style archives can be valuable when they explain the experience and link to relevant tours.
- Internal tags should usually not be indexable unless they support a clear user journey.
- Accommodation archives should be judged by whether they help planning and link clearly into destination content.

## Output rule

Always present taxonomy recommendations as decisions with evidence, risk, owner route and QA checks.
