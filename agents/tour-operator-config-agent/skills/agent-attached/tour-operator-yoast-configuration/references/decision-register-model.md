# Decision Register Model

Use this for decisions that should be traceable.

## Fields

- decision
- context and evidence
- options considered
- recommendation
- rationale
- risk level
- approval owner
- approval status
- implementation route
- QA checks
- rollback or monitoring notes

## Decisions that need records

- indexation changes
- canonical changes
- sitemap changes
- schema changes
- redirect plan approval
- multilingual alternate changes
- bulk metadata approval
- developer customisation
