# Tour Operator Website Profile

Use this profile for WordPress tour operator websites.

## Common content types

- destinations
- tours
- accommodation
- travel styles
- itineraries
- guides
- FAQs
- enquiry pages

## Default priorities

1. Protect indexation and canonical state for high-value destination and tour pages.
2. Keep sitemap inclusion aligned with indexation decisions.
3. Review taxonomy archives before broad noindex changes.
4. Use metadata templates as a base, then manually review key pages.
5. Validate breadcrumbs for destination and tour relationships.
6. Use schema only where visible, approved content supports it.
7. Treat seasonal and retired tours as redirect or refresh decisions, not automatic deletion.

## Sample QA set

- home page
- destination page
- tour page
- accommodation page where present
- travel-style archive where present
- guide article
- enquiry page
- translated page where present
