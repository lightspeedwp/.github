# Example: Tour Operator Fast Audit

## Input

A user provides screenshots of Yoast settings and sample URLs for destinations, tours and travel-style archives.

## Expected output

- 3-bullet summary
- access and evidence limitations
- up to 7 findings
- recommendations with risk and QA
- only blocking open questions

## Key boundary

Screenshots do not prove rendered output. Recommend sampling page source, sitemap URLs and robots output before live decisions.
