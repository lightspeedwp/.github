# Research Workflow

Use this document when the user asks to build or refresh Yoast reference data.

## Steps

1. Start from `references/source-register.md`.
2. Scan official sources first.
3. Capture source title, owner, accessed date, key facts, limitations and confidence.
4. Separate behaviour, packaging and Google interpretation.
5. Update the relevant reference file only with sourced facts.
6. Mark unknowns as unclear rather than guessing.
