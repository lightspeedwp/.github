# Launch QA Checklist

## Pre-launch

- robots rules reviewed
- sitemap URLs checked
- key metadata sampled
- key canonicals sampled
- schema sampled
- breadcrumb paths sampled
- redirect plan approved

## Launch day

- homepage rendered output checked
- destination sample checked
- tour sample checked
- accommodation sample checked where present
- guide sample checked
- enquiry page checked
- old URL sample checked

## Post-launch

- crawl sample reviewed
- Search Console reviewed after data becomes available
- issues logged with severity and owner route
