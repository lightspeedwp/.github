Use for training, onboarding, lightweight learning checks, or internal assessments.

## Recommended stance

- Require Quiz Add-On detection before using Quiz fields or quiz settings.
- Do not use instant feedback for high-stakes exams.
- Treat scoring and threshold changes as approval-sensitive because historical results can be recalculated when viewed.
- Avoid conditional logic that hides quiz questions unless scoring consequences are accepted.

## Suggested fields

1. Participant name or learner identifier if the result must be tied to a person.
2. Quiz questions using single-choice or multiple-choice fields.
3. Optional feedback question after the quiz.
4. Consent/acknowledgement if results affect access or certification.

## Validation

- Test pass, fail, boundary, and hidden-question cases.
- Confirm score merge tags and confirmation content.
- Review quiz result dashboard and entry data.
