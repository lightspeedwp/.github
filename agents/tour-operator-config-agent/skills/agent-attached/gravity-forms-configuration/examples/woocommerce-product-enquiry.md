# Example: WooCommerce product enquiry

Use when a product needs pre-sales questions without replacing WooCommerce checkout.

- Fields: Product name/URL/ID context, Name, Email, Phone optional, Quantity/variation interest, Message, Consent.
- Confirmation: thank the customer and explain response timeframe.
- Notification: route to sales/product owner; include product context and Reply-To submitter.
- Guardrail: do not create orders, take payments, or alter checkout unless explicitly scoped and approved.
- Test: submit from at least one product page and verify context is captured correctly.
