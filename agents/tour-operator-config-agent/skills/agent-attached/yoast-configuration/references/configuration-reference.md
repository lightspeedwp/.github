This file contains skill-ready configuration reference entries. Treat entries as decision scaffolds until the linked source register rows are refreshed with scanned evidence.

## Rules

- Do not expose exact admin UI paths without live verification.
- Keep indexation, canonical and sitemap decisions aligned.
- For WooCommerce, load `references/woocommerce-seo-reference.md` as well.
- For schema customisation, load `references/schema-reference.md` and `references/developer-api-reference.md`.
