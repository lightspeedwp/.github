## Package upload

1. Upload `skill.zip` to the LightSpeed ChatGPT workspace skill library.
2. Confirm the skill appears as **Tour Operator Gravity Forms Configuration**.
3. Attach it to:
   - WordPress Configuration Agent
   - Tour Operator Website Configuration Agent
4. Keep the skill standalone-enabled for direct Gravity Forms support prompts.

## Smoke test after install

Run these prompts in a safe workspace:

1. "Audit this Gravity Forms setup using read-only mode and produce a preflight report."
2. "Plan a tour itinerary request form but do not apply changes."
3. "Create a tour operator enquiry configuration plan with multi-page fields."
4. "Review an existing notification and explain what must be checked before changing it."

## Upgrade notes

When updating, replace the whole skill package with the new `skill.zip`; do not patch individual files in production unless the workspace supports controlled skill versioning.
