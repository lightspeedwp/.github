# Example: WordPress contact form

Use for a general website contact page. Keep it short and accessible.

- Fields: Name, Email, Phone optional, Message, Consent.
- Confirmation: clear text confirmation with next response expectation.
- Notification: admin notification to site owner/team, From Email on site domain, Reply-To submitter.
- Spam: honeypot or layered protection; Turnstile only if add-on/keys confirmed.
- Embed: Gravity Forms block on Contact page where available.
- Test: submit realistic test data, verify confirmation, admin email, entry, and mobile/keyboard basics.
