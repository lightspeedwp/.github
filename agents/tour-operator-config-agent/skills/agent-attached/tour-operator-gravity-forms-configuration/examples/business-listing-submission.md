# Example: Business Listing Submission

## Goal

Collect business listing submissions for editorial or directory-team review without letting submitters create public directory content automatically.

## Recommended stance

- Treat listings as UGC with moderation.
- Use controlled categories rather than free-text taxonomy creation.
- Keep generated posts/listings as Draft or Pending Review.
- Avoid collecting unnecessary identity documents or payment details in the listing form.

## Suggested fields

- Business name.
- Contact name.
- Contact email.
- Website URL.
- Phone.
- Category.
- Area served.
- Short description.
- Logo/image upload, optional.
- Listing consent and accuracy acknowledgement.

## Feed notes

Advanced Post Creation can be used only if the listing post type already exists. Custom fields, taxonomy terms, and featured images must be mapped explicitly. If the listing post type or fields do not exist, route away to WordPress configuration or implementation planning.

## Handoff

Directory owner reviews content, confirms category/area, checks image/logo rights, and publishes manually after approval.
