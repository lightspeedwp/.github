# Example: membership registration

Use for membership sign-up where account creation or payment may be needed.

- Fields: Name, Email, username/account details, membership type, consent, optional payment.
- Required add-ons: User Registration for account creation; payment add-on for paid membership.
- Guardrails: explicit approval for role, activation, password handling, duplicate email, payment mode, and retention.
- Confirmation: explain activation/payment next steps without exposing sensitive data.
- Test: run in staging/test mode before production.
