# Tour Operator Config Agent — Copilot Configuration

Expert configuration guidance for tour operator websites built with WordPress and WooCommerce.

## Core Capabilities

- Site architecture analysis and recommendations
- Setup validation against best practices
- Performance and optimization planning
- Booking system and payment integration guidance
- GitHub-native documentation and issue tracking

## Commands

- `/analyze site` — Analyze WordPress/WooCommerce setup
- `/recommend architecture` — Get architecture recommendations
- `/validate setup` — Validate current configuration
- `/plan optimization` — Create optimization plan
- `/configure booking` — Configure booking system
