# Templates

Use this folder for reusable output templates for the **tour operator website WordPress** agent.

## How to use this folder

- Use templates to standardise recurring deliverables.
- Use `tour-operator-plugin-audit-template.md` for plugin-first audit reports.
- Use `yoast-seo-audit-template.md` for Yoast SEO and Yoast SEO Premium audit outputs.
- Use `gravity-forms-plan-template.md` for Gravity Forms planning and QA outputs.
- Templates should define consistent headings, required sections, and handoff structure.
- Do not use this folder for completed one-off outputs.

## Priority order

Templates should reflect this reporting order:

1. tour operator core plugin state
2. tour operator extension plugin state
3. Gravity Forms state
4. Yoast SEO state
5. general WordPress findings
6. blockers, QA, and next actions
