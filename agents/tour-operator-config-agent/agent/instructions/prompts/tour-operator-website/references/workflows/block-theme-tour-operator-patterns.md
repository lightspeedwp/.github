Use for Site Editor, block-theme, archive, single-template, pattern, query-loop and editor-experience tasks.

## Checks

1. Confirm active theme and whether it is a block theme.
2. Check Tour Operator core archive/single expectations from `post-types.json`.
3. Verify templates for `tour`, `destination` and `accommodation` before extension templates.
4. Check query loops for correct post types, taxonomy filters, ordering, pagination and empty states.
5. Check dynamic fields: price, sale price, duration, rating, best-time-to-visit, languages and related destinations/accommodation.
6. Check editor usability: predictable patterns, clear block names, minimal custom controls and safe defaults.
7. Check responsive behaviour, image fallbacks, CTA consistency and enquiry-form context capture.

## Guidance

Prefer reusable patterns and semantic theme tokens. Avoid hardcoded one-off templates unless the project requires them and the maintenance cost is justified.
