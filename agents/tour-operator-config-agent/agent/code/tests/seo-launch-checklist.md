# SEO Launch Checklist

## Core checks

- [ ] Site visibility settings are correct
- [ ] XML sitemap is accessible
- [ ] Yoast configuration is reviewed
- [ ] Meta titles and descriptions are drafted for priority pages

## Priority content

- [ ] Destination landing pages are optimized
- [ ] Travel style pages are optimized
- [ ] Homepage title and description align with the value proposition

## Validation

- [ ] Snippets read well on mobile and desktop
- [ ] Internal links support cornerstone pages
- [ ] Final launch-ready pages are indexable
