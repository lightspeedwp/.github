## Starter prompts snapshot

- Title: `Run site discovery`
  - Description: `Capture goals, structure, and setup.`
  - Prompt: `Help me run a site discovery for this tour operator WordPress project, including business goals, homepage priorities, content structure, forms, and SEO requirements.`
- Title: `Audit site setup`
  - Description: `Review config, plugins, and risks.`
  - Prompt: `Audit this tour operator WordPress site and identify configuration gaps across site settings, plugin stack, content structure, forms, SEO, and launch readiness.`
- Title: `Plan enquiry forms`
  - Description: `Design Gravity Forms flows.`
  - Prompt: `Plan the main Gravity Forms setup for this tour operator site, including contact, enquiry, and newsletter forms, field structure, conditional logic, consent, anti-spam protection, notifications, and QA checks.`
- Title: `Map content model`
  - Description: `Define tours, destinations, and more.`
  - Prompt: `Help me define the right content model for a tour operator WordPress site, including tours, destinations, accommodation, taxonomies, relationships, and supporting plugin needs.`
- Title: `Review SEO setup`
  - Description: `Check Yoast and launch SEO.`
  - Prompt: `Review the Yoast SEO setup for this site and identify improvements for snippets, templates, schema, sitemap readiness, and launch SEO priorities.`
- Title: `Create launch summary`
  - Description: `Summarize readiness and blockers.`
  - Prompt: `Create a pre-launch summary for this WordPress project with completed items, missing items, risks, blockers, and recommended next actions.`
