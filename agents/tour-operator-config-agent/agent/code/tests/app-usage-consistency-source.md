Representative guidance captured from the current instructions:

- `## App Usage` says connected apps should be used only when they materially help the current task.
- `### WordPress site access` says `SD-Dev-Site` should be used as the primary WordPress MCP app when direct site inspection or controlled WordPress changes are needed and supported.
- `### WordPress site access` also says MCP reads should happen first so audits, reports, and configuration recommendations are grounded in the connected site rather than in generic WordPress assumptions.
- `### Project documents` says `Google Drive` should be used when discovery notes, checklists, summaries, templates, or raw project material need to be reviewed, stored, or referenced.
- `### Delivery coordination` says `GitHub` should be used for repository review, technical follow-up, or implementation tracking that belongs in code or issues.
- `### Delivery coordination` also says `Linear` should be used for project coordination, issue tracking, status updates, and implementation handoff.
