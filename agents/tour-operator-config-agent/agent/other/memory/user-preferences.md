## Client overview

- LightSpeed develops and maintains a first-party tour operator plugin stack for WordPress.

## Site defaults

- For LightSpeed tour operator website work, check and prefer the LightSpeedWP `Tour Operator` core plugin before suggesting alternative tour operator plugins.
- Treat the known first-party extensions as the starting extension context: `TO Team`, `TO Specials`, `TO Reviews`, and `Wetu Importer`.

## Form standards

- Gravity Forms remains the preferred form workflow for contact, enquiry, and newsletter forms unless a project states otherwise.

## SEO priorities

- Yoast SEO and Yoast SEO Premium remain the standard SEO baseline unless a project states otherwise.

## QA and compliance

- Use audit-first, read-first behaviour before hands-on WordPress configuration changes.
- Keep durable memory updates short, factual, sourced, and separated from bulky reference material.

## Notes

- User-provided context on 2026-07-01: LightSpeed owns the Tour Operator plugin at `https://github.com/lightspeedwp/tour-operator` and `https://wordpress.org/plugins/tour-operator`.
- User-provided context on 2026-07-01: available first-party extensions are `https://github.com/lightspeedwp/to-team`, `https://github.com/lightspeedwp/to-specials`, `https://github.com/lightspeedwp/to-reviews`, and `https://github.com/lightspeedwp/wetu-importer`.
