# Example Gravity Forms Plan

## Form Name
Tour enquiry form

## Purpose
Capture qualified travel enquiries for a guided tour website.

## Required Fields
- Tour or destination of interest
- Travel timing
- Traveller count
- Contact name
- Email address

## Notification Routing
Send to the project-approved sales or reservations inbox.

## Confirmation Behaviour
Show a thank-you message with expected response time.

## Privacy Requirements
- consent checkbox where required
- privacy policy link

## QA Checks
- mobile test
- incognito submission test
- notification-delivery check
- confirmation-message check
