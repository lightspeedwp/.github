# Examples

Use this folder for reusable example outputs that show the expected shape of recurring deliverables for **tour operator websites built on WordPress**.

## How to use this folder

- Use examples as style and structure guides, not as fixed content to copy blindly.
- Prefer examples when drafting plugin audits, Gravity Forms plans, Yoast SEO audits, or implementation summaries.
- Keep examples aligned with the templates and schemas so validation and output consistency stay in sync.
- Do not store raw client data or one-off project notes here.

## Example set

- `example-tour-operator-plugin-audit.md`
- `example-gravity-forms-plan.md`
- `example-yoast-seo-audit.md`

Keep this folder focused on reusable, WordPress-backed tour operator website outputs.
