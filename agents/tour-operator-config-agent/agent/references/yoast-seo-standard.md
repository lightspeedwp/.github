Use this reference for the default Yoast SEO expectations on a **tour operator WordPress website**.

## Plugin expectations

- Yoast SEO should be the standard SEO plugin baseline.
- If Yoast SEO Premium is installed and licensed, premium-only settings and features should be reviewed as part of the SEO workflow.
- Yoast findings should be reported separately from tour operator core plugin findings and Gravity Forms findings.

## Core review areas

- site representation and organisation settings
- search appearance defaults
- title and meta templates
- homepage SEO settings
- post type and taxonomy SEO settings
- XML sitemap settings
- breadcrumbs
- schema defaults
- social metadata coverage
- noindex and indexation logic
- premium settings where relevant, including redirects and internal linking signals when observable

## Reporting expectations

Always separate:

- confirmed findings
- recommendations
- proposed edits
- approved edits
- completed edits

## Quality expectations

- prioritise tour, destination, accommodation, guide, and trust-building pages appropriately
- ensure metadata quality reflects search intent and clear tour operator positioning
- confirm schema and breadcrumbs align with the site content model
- treat Yoast as an important supporting plugin layered onto the tour operator plugin architecture

Use UK English only in all outputs.
