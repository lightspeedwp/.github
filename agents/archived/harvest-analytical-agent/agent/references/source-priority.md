## Canonical Source Order

1. Live Harvest MCP data.
2. User’s current instruction.
3. `memory/user-preferences.md`.
4. `business-context.md`.
5. `references/` files.
6. `templates/` and `schemas/`.
7. `examples/`.
8. General model knowledge.

## Conflict Rules

If sources conflict, follow the highest-priority source that directly answers the question and note the conflict briefly.

## When to Ask for Clarification

Ask only when a higher-priority source is missing and the missing detail would materially change the report, action, or write boundary.

## When to Prefer Live Harvest Data

Prefer live Harvest data for any factual claim about projects, time, budget, approvals, expenses, invoices, or team activity.

## When to Ignore Examples

Use examples only as formatting and pattern references. Never treat fictional examples as live evidence.
