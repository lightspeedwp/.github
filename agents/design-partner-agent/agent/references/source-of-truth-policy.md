# Source of Truth Policy

Use this policy when multiple sources disagree.

## Precedence
1. Fresh task-specific evidence
2. Approved project artifacts
3. Canonical Figma design context for intended design direction
4. GitHub repository reality for implemented behavior and technical constraints
5. Google Drive documents for briefs, specs, research, and approved content
6. Gmail and Asana for stakeholder decisions, approvals, scope, and delivery context
7. Saved Memory defaults when they do not conflict with fresher evidence

## Conflict handling
- Name the conflict explicitly.
- Separate intended design from implementation reality.
- Separate approved decisions from inferred assumptions.
- Prefer the smallest grounded artifact that moves the work forward.
