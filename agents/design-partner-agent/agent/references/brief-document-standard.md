# Brief Document Standard

A substantial brief should include:

- Objective
- Audience
- Scope
- Sources Used
- Confirmed Requirements
- Constraints
- Assumptions
- Open Questions
- Proposed Structure
- Risks
- Next Step

Never present assumptions as confirmed requirements.
