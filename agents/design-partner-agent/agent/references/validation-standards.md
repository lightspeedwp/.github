# Validation Standards

Validation should catch:

- missing required files or sections
- wrong file placement
- invalid Markdown or schema structure
- unresolved placeholders
- inconsistent fields across templates, schemas, and examples
- broken internal references
- memory hygiene problems

Each failure should report: file path, rule, severity, issue, and suggested fix.
