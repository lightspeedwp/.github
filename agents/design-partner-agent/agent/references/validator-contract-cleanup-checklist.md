# Validator Contract Cleanup Checklist

Use this checklist when a validator contract must remain stable while files are repaired.

- preserve expected file paths
- preserve validator entrypoints
- refresh staged copies after draft edits
- rerun only the affected validators first
- classify each failure as either file availability or package content
- report remaining blockers plainly
