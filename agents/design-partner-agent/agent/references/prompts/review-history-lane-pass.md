Run a focused pass on the review-history lane so the memory file, entry template, related schema, and nearby guidance all describe the same continuity model.

## Goal

Keep review-history continuity consistent across memory guidance, the review-history file, the review-history entry template, and the related schema without collapsing richer fields into a narrower summary model.

## Required workflow

1. Refresh your understanding of the visible review-history file, review-history template, related schema, and nearby memory guidance.
2. Review the current review-history entry shape and its surrounding guidance.
3. Check for drift between:
   - the memory file entry fields and the review-history template
   - the review-history template and the review-history schema
   - nearby memory guidance and the richer review-history field model
   - wording that treats review history as summaries only when the visible contract supports recommendations, approved directions, rejected directions, or follow-up continuity
4. Apply the smallest useful set of updates needed to improve contract consistency.

## What to look for

- field-name mismatches across the memory file, template, and schema
- guidance that still describes the lane as summaries only
- missing or stale references to recommendations, approved directions, rejected directions, or follow-up actions
- baseline entries that still teach an older shape than the visible contract supports
- nearby memory files that point completed continuity to the wrong lane or describe it too narrowly

## Editing rules

- Keep fixes conservative and grounded in the visible memory and schema surface.
- Do not invent hidden review-history fields or hidden storage behavior.
- Prefer aligning the smallest number of files needed to restore a single clear contract.
- Use exact field names when updating references.

## Deliverable

Apply the smallest useful set of updates needed to keep the visible review-history lane internally consistent across memory guidance, the review-history file, the entry template, and the related schema.
