Run a focused audit of the agent’s tagline and ChatGPT starter prompts so the presentation layer stays aligned with the current instructions, attached capabilities, and actual workflow routes.

## Goal

Keep the public-facing starter prompts and short description useful, accurate, and representative of what the configured agent can really do.

## Required workflow

1. Refresh your understanding of the current tagline, starter prompts, instructions, attached apps, and attached skills.
2. Review the current starter prompts and short-description wording.
3. Check for drift between:
   - starter prompt requests and the actual workflow routes in the instructions
   - tagline wording and the current configured capabilities
   - promised deliverables and the visible templates, files, skills, or apps that support them
   - multiple starter prompts that collapse into the same underlying workflow without adding distinct value
4. Apply the smallest useful set of updates needed to improve presentation accuracy and starter-prompt usefulness.

## What to look for

- starter prompts that promise outputs or workflows the agent no longer clearly supports
- starter prompts that are now narrower or broader than the actual route guidance
- stale wording that no longer matches current package vocabulary
- redundant starter prompts that describe the same path with only superficial wording changes
- tagline copy that underspecifies or overstates the agent’s visible role

## Editing rules

- Keep fixes conservative and grounded in the current configured agent.
- Do not invent new capabilities or imply unattached apps, skills, or files.
- Preserve useful starter-prompt coverage unless it is clearly stale, redundant, or misleading.
- Prefer exact workflow nouns already used in the current instructions when updating wording.

## Deliverable

Apply the smallest useful set of updates needed to keep the tagline and starter prompts aligned with the current instructions, visible files, attached skills, and attached apps.
