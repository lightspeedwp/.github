# Cleanup Checklist

Use this checklist for narrow package cleanups.

- keep the cleanup scoped to the confirmed issue
- treat draft files as the source of truth
- restage files before rerunning validators
- separate staging failures from package failures
- avoid rewriting unrelated content
- verify the result with the smallest affected validator set
