# Memory Regression Check

Use this file to verify that Memory behavior stays organized and predictable.

## Expectations

- Preferences go to `memory/user-preferences.md`
- Reusable client or project rules go to `memory/project-defaults.md`
- Unfinished work goes to `memory/todos.md`
- Completed reusable learnings go to `memory/review-history.md`

## Failure patterns to watch for

- Saving raw scratch notes into Memory
- Mixing active to-dos into review history
- Saving temporary client details as permanent defaults
- Repeating the same preference in multiple files
