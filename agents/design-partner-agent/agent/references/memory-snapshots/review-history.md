# Review History

Use this file to store **compressed continuity entries for completed work** so future runs can build on prior findings without redoing the same reasoning.

## What belongs here
- completed briefs
- completed critiques
- completed audits
- completed implementation handoffs
- key findings worth preserving
- recommendations worth remembering
- approved directions worth repeating
- rejected directions worth avoiding
- recurring issues that keep showing up across runs
- follow-up continuity that should shape future work
