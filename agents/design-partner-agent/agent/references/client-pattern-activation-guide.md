# Client Pattern Activation Guide

Use this guide when moving from reusable client patterns into active project work.

## Activation steps

1. Start from the closest reusable client pattern in `memory/project-defaults.md`.
2. Copy only the relevant stable context into the active project record.
3. Add project-specific constraints, goals, URLs, repos, Figma files, and approvals.
4. Keep uncertain details out until they are confirmed.
5. Save finished learnings to review history after meaningful work is completed.

## Do not

- overwrite reusable client patterns with one-off project details
- save unconfirmed context as default reuse material
- use active follow-up tasks as long-term defaults
