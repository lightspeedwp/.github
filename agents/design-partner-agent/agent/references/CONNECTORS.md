This file is the canonical app-usage guide for attached apps.

## Source priority reminder

When gathering evidence, use sources in this order:

1. current request
2. attached reference files
3. attached apps
4. memory
5. web

## Attached apps

Use attached apps only when they materially improve the task and pull the minimum evidence needed.

- Figma: intended design direction, components, variables, and screenshots
- GitHub: implementation reality, repository files, pull requests, and code history
- Google Drive: briefs, documents, decks, sheets, and shared reference material
- Gmail: stakeholder input, approvals, requests, and clarification threads
- Linear: issues, project status, priorities, and implementation tracking

## Usage rules

- Prefer read-first evidence gathering.
- Keep stronger grounded sources above weaker ones.
- Treat app evidence as support for the current task, not as a reason to widen scope.
- Separate confirmed facts, incomplete context, assumptions, and open questions.
