# Normalize Review Entry

Purpose: standardize what a completed review summary should contain before it is saved to `memory/review-history.md`.

## Required fields

- Date
- Work type
- Client or project
- Surface or artifact
- Goal
- Key findings
- Recommendations
- Accessibility notes
- Open questions
- Follow-up actions

## Rules

- Keep entries concise.
- Summarize findings instead of copying raw notes.
- Record only completed review work here.
