Use this file to keep lightweight guidance for manual or scripted support tasks around the agent's review workflow.

## Suggested script categories

- `extract-...` for pulling content from source material
- `normalize-...` for cleaning or standardizing inputs
- `validate-...` for checking output completeness or structure
- `compare-...` for comparing source versions, mockups, or outputs

## Recommended conventions

- Use kebab-case filenames.
- Keep each script focused on one repeatable job.
- Prefer outputs that are easy to inspect in Markdown or JSON.
- Document expected inputs and outputs at the top of each script.

## Good future script candidates

- `extract-figma-notes.*`
- `normalize-research-notes.*`
- `validate-handoff-output.*`
- `compare-copy-variants.*`
