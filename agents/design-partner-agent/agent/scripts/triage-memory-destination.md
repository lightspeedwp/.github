# Triage Memory Destination

Use this helper when deciding where new information belongs.

## Decision guide

- If it is about how the user wants outputs delivered, save it in `memory/user-preferences.md`.
- If it is a stable client or project rule, save it in `memory/project-defaults.md`.
- If it is still open or unfinished, save it in `memory/todos.md`.
- If it is completed and worth remembering, save it in `memory/review-history.md`.

## Do not save

- Raw scratch notes
- Temporary ideas
- Unconfirmed assumptions
- Large research dumps
