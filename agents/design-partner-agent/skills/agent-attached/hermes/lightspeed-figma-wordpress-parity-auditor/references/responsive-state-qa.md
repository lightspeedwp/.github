# Responsive State QA

## Breakpoints to check

Use the project's breakpoint system. If unknown, check at least:

- small mobile
- large mobile
- tablet
- laptop
- desktop/wide

## Check

- navigation behaviour
- hero layout
- cards and grids
- forms
- CTA sections
- images and media
- pattern stacking
- spacing and rhythm
- readable line lengths
- touch target sizes
- footer layout

## Output

Record page, viewport, issue, severity, expected behaviour and fix owner.
