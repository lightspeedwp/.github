# Release Notes Rules

Release notes should include:

- release name/version/date if known
- project/context summary
- shipped features
- technical changes
- content/design changes
- QA completed
- known issues
- rollback notes where relevant
- next monitoring actions

Avoid claiming a feature shipped unless it is evidenced by implementation or QA notes.
