# Known Issues Rules

Classify known issues as:

- Launch blocker
- Must fix soon
- Accepted risk
- Post-launch improvement
- Needs reproduction
- Not reproducible
- Deferred scope

Each issue should include:

- description
- affected area
- severity
- owner role
- target date
- user impact
- workaround if available
