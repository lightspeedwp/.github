Portable plugin pack for QA planning, gate enforcement, and regression risk controls.

- `skills/lightspeed-quality-gate/SKILL.md`
- `skills/lightspeed-regression-risk-assessment/SKILL.md`
- `skills/lightspeed-test-matrix-planner/SKILL.md`
