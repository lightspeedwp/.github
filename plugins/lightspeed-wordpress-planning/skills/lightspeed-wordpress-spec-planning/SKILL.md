# lightspeed-wordpress-spec-planning

## Triggers

- Plan a new WordPress feature.
- Break a PRD into implementation phases.
- Convert governance requirements into task-ready checklists.

## Output expectations

- Requirements summary
- Acceptance criteria
- Design outline
- Phased delivery tasks, ordered by implementation sequence
- Validation checklist
