# Reusable Prompts Library

This directory contains organisation-wide reusable prompts for automation, workflows, and agent coordination across LightSpeed projects. Each prompt is self-contained, documented, and designed for copy-paste use in chat sessions.

## Quick Reference

1. **Update Active Projects** — Document session work in project files, create tasks, regenerate specs
2. **PR Finalization** — 10-step workflow: review, labels, templates, merge to develop
3. **Context Continuation** — Generate self-contained continuation prompt for new chat window
4. **Dependabot Merge** — Manual merge workflow with dependency ordering guidance
5. **Recommend Next Task** — Audit projects, prioritize work, generate recommendations
6. **Milestone Allocation** — Allocate issues across version milestones, balance workload
7. **Branch Cleanup** — Clean merged/stale branches, validate naming
8. **Create/Update README** — Generate READMEs with Mermaid diagrams following standards
9. **Move Files** — Audit `.github/` and migrate files to root folders

## How to Use

Copy-paste any prompt file into a new Claude Code chat, customize for your context, and execute the workflow.
