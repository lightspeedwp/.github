## Security & Licensing

This document outlines the security, data hygiene, and licensing requirements for all AI template assets in LightSpeedWP projects. All contributors must follow these rules to ensure safe, compliant, and redistributable templates.

## Data Hygiene

- **No secrets or sensitive data:** Never include passwords, API keys, customer names, private URLs, or confidential information in any template or example.
- **Anonymise data:** Mask or anonymise any real data in examples and test cases.
- **Review before release:** Double-check all content for accidental leaks or sensitive information before merging or releasing.
- **Reference:** See [Contributing Templates](./CONTRIBUTING-TEMPLATES.md) for the review checklist.

## Model Safety

- **No harmful instructions:** Avoid prompts or instructions that could enable illegal, unethical, or privacy-invasive behaviour.
- **Limits section:** Every template must include a **Limits** section outlining what the template must not be used for, and refusal guidance for edge cases.
- **Bias and fairness:** Strive to avoid bias in examples and instructions. Use inclusive, respectful language.
- **Reference:** See [Coding & Content Style](./CODING-STYLE.md) for language and content standards.

## Licensing

- **Default licence:** All templates are licensed under GPL 3.0 (or the org standard) unless otherwise stated.
- **Third-party content:** If you include third-party code or assets, you must include the source and a licence note. Only add assets you have rights to redistribute in the release ZIP.
- **Attribution:** Give credit to original authors where required by licence.
- **Reference:** See [Release Process](./RELEASE-PROCESS.md) for packaging and distribution rules.
