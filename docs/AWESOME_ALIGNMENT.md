# Awesome Copilot Alignment

## Purpose

Track structural alignment with the reference repository while preserving LightSpeedWP conventions and governance.

## Mapping Summary

- `.schemas` -> portable schema contracts and registry
- `.vscode` -> workspace integration defaults
- `plugins` -> installable platform packs
- `skills` -> portable skill catalogues and contracts
- `workflows` -> portable runbooks
- `hooks` -> guardrail and scanning hook specs
