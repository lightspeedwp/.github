## Template Files

All starter code, including tests and source files, are named with `.mustache` to indicate placeholders.  
E.g., `index.js.mustache`, `date.test.js.mustache`, `block-e2e.spec.js.mustache`.

### To use:

1. Run `replace-placeholders.js` on all `.mustache` files.
2. Rename files to remove `.mustache` (e.g., `index.js`).
3. Validate with `/tests/placeholder.test.js` that no placeholders remain.
