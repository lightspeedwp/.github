# Getting Started with {{projectName}} Block Plugin

## Installation

1. Clone repo:  
   ```sh
   git clone https://github.com/<your-org>/<your-plugin-repo>.git
   cd <your-plugin-repo>
   ```
2. Install dependencies:  
   ```sh
   npm install
   composer install
   ```

3. Activate the plugin in WordPress.

## Usage

- Add the custom block via the block editor.
- Configure block settings as needed.

See [`DEVELOPMENT.md`](./DEVELOPMENT.md) for more.
