# Bin Folder: Build & Automation Scripts for {{slug}} plugin

This folder contains all build, test, and automation scripts used in development:

- `build.sh`: Build assets.
- `test.sh`: Run all tests (JS, PHP).
- `install-wp-tests.sh`: Set up WP PHPUnit environment.
- `update-version.js`: Update version numbers.
- `replace-placeholders.js`: Replace mustache placeholders in source files.

Scripts use mustache placeholders for easy scaffolding.  
See [`PLACEHOLDER-WORKFLOW.single-block-plugin.md`](../docs/single-block-plugin/PLACEHOLDER-WORKFLOW.single-block-plugin.md).
