# .all-contributorsrc – All Contributors configuration

This file is used by [all-contributors](https://allcontributors.org/) to automatically generate and update the contributors section in this repository.

- **Project:** LightSpeedWP Community Health Files
- **Owner:** [LightSpeedWP](https://github.com/lightspeedwp)
- **License:** GPL-3.0-or-later

## What is this for?

- Tracks all contributors to LightSpeedWP's `.github` community health repo.
- Used to generate badges and contributor tables in `README.md` and documentation.
- Keeps an up-to-date, machine-readable list of all contributors and their types of contribution.

## Usage

- To add yourself or someone else as a contributor, use the [all-contributors CLI](https://allcontributors.org/docs/en/cli/overview):

  ```bash
  npx all-contributors add <github-username> <contribution-type>
  npx all-contributors generate
  ```

- Supported contribution types: code, doc, infra, maintenance, test, design, business, ideas, projectManagement, fundingFinding, review, security, tool, platform, translation, tutorial, blog, content, talk, question, userTesting, mentoring.

- See details: [all-contributors.org](https://allcontributors.org/docs/en/emoji-key)

## Contributor Guide

- Please keep this file and `.all-contributorsrc` in sync.
- All new or departing contributors should be reflected in both config and docs.
- Update the contributors section in `README.md` after running the CLI.
