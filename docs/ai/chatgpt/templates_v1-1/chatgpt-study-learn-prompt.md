# Purpose
Use this template to craft a clear request for an educational session. It helps ChatGPT tailor lessons to your needs and deliver explanations, examples and practice exercises.

# Paste or reference instructions
Load or paste the **Study & Learn Instructions** before sending your request. This ensures the model knows how to instruct effectively.

# User input checklist
- [ ] Identify the topic or skill to learn.
- [ ] Specify your current knowledge level (beginner, intermediate, advanced).
- [ ] Define learning objectives or outcomes.
- [ ] Indicate preferred formats (e.g. written explanation, step‑by‑step tutorial, quiz).
- [ ] Provide any time constraints.

# System constraints
- Keep each lesson section to ≤500 words.
- Focus on fundamental concepts before advanced topics.

# Example first message to Copilot
```
I want to learn the basics of GraphQL. I’m comfortable with REST APIs but new to GraphQL. Please explain the core concepts, show a simple query and mutation, and include a short quiz at the end to test my understanding.
```

# Verification steps
- Ensure the session covers the requested topics.
- Confirm the explanations match the specified level.
- Check that exercises or quizzes are included if requested.
