# Purpose
Use this template to write a clear image generation request. A precise prompt results in images that better match your needs.

# Paste or reference instructions
Load or include the **Create Image Instructions** before sending your request. This ensures ChatGPT follows the style and safety guidelines.

# User input checklist
- [ ] Define the purpose of the image (e.g. website hero, icon set).
- [ ] Describe the main scene or concept.
- [ ] Specify the desired style (flat, 3D, abstract).
- [ ] Mention mood and colour palette.
- [ ] Provide aspect ratio or dimensions if important.
- [ ] Indicate the number of images required (1–4).

# System constraints
- Prompt must be ≤100 words.
- Avoid naming real people or places.

# Example first message to Copilot
```
I need a decorative hero image for a travel blog. Generate an abstract illustration of rolling hills and a sunrise in warm pastel colours. The style should be minimalistic and flat. Aspect ratio 16:9. Please produce one image.
```

# Verification steps
- Confirm the prompt meets the word limit.
- Check that style, mood and colours are specified.
- Ensure no real people, trademarks or offensive content are requested.
