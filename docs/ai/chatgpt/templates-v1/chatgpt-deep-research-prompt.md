# Purpose

Use this template to craft a clear and complete prompt when you need ChatGPT to perform deep research. A well‑structured prompt improves the relevance and depth of the resulting report.

# Paste or reference instructions

At the beginning of your session, ensure the **Deep Research Instructions** file has been loaded or reference its URL. If working in a Copilot Space, paste the instructions into the “Instructions” field.

# User input checklist

- [ ] Specify the research question or problem statement.
- [ ] Mention key aspects or subtopics to explore.
- [ ] Define the desired depth (overview or exhaustive).
- [ ] Provide any geographic or temporal constraints (e.g. “focus on 2023–2025”).
- [ ] State whether internal data sources should be searched via connectors.

# System constraints

- The report should be delivered in markdown.
- Use UK English and metric units.
- Include numbered citations and a references section.
- Word limit: 2,500 words unless otherwise noted.

# Example first message to Copilot

```
Please perform a deep research analysis on the adoption of headless WordPress architectures from 2022–2025. Focus on benefits, challenges, and ecosystem maturity. Include at least three authoritative sources, cite them inline, and structure the report with Introduction, Findings, Discussion, and Conclusion.
```

# Verification steps

- Ensure the response includes all requested sections.
- Check that citations are present and correspond to the sources listed in the references.
- Verify that the report answers the research question and stays within the word limit.
