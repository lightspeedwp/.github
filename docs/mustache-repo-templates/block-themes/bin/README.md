# bin/ Scripts

This folder contains automation scripts for {{theme_name}} block theme development.

- `build.sh`: Runs the build process, compiles assets from `src/` to `build/`.
- `test.sh`: Runs tests (JS and PHP, if present).
- `replace-placeholders.js`: Replaces mustache placeholders (e.g., `{{theme_name}}`) in files using values from a mapping JSON.

See [PLACEHOLDER-WORKFLOW.md](../PLACEHOLDER-WORKFLOW.md) for usage instructions.
