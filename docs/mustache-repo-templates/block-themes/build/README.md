# build/

This directory is the output location for compiled assets (CSS/JS) generated by the build process (e.g., `npm run build`, `bin/build.sh`).  
**Do not commit files in this folder**—it is managed by the build pipeline and is ignored by `.gitignore`.

Assets are compiled from `src/js/` and `src/scss/` (or `assets/`) and output here for production use.
