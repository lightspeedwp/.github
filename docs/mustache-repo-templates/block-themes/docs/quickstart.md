# Quickstart Guide

Get started with the {{theme_name}} block theme:

1. Clone the repo and install dependencies:

    ```sh
    git clone {{repo_url}}
    cd {{theme_slug}}
    npm install
    ```

2. Replace mustache placeholders in all files:
    See [placeholder-workflow.md](placeholder-workflow.md).

3. Build and activate the theme:

    ```sh
    npm run build
    # or use bin/build.sh
    ```

    Activate via WordPress admin.

4. Customize templates, patterns, styles, and assets.
