# Project Structure & Guidelines

This theme follows the official WordPress block theme directory structure:

- Required: `style.css`, `templates/index.html`
- Recommended: `functions.php`, `theme.json`, `screenshot.png`, `README.md`
- Directories: `templates/`, `parts/`, `patterns/`, `styles/`, `assets/`, `inc/`, `.github/`, `build/`, `bin/`, `docs/`

See [WordPress Block Theme – Structure & Development Guidelines.md](structure-guidelines.md) for details.
