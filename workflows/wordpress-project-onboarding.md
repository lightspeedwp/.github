# WordPress Project Onboarding Workflow

## Steps

1. Run repository structure and standards checks.
2. Confirm instruction and agent baseline files.
3. Draft PRD and implementation sequence.
4. Configure plugin pack manifests.
5. Execute lint/test validation gates.
