# Memory Platform

This directory stores portable memory contracts and data packs for all agent and skill assets.

## Structure

- `registry/` global registry and inventory lock
- `profiles/agents/` per-agent memory profiles
- `profiles/skills/` per-skill memory profiles
- `examples/agents/` memory snapshot examples for agents
- `examples/skills/` memory snapshot examples for skills
- `examples/packs/` bundled example packs
