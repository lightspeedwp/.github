## WordPress Agent-Skills Context

### What is WordPress Agent-Skills?

The WordPress Foundation released [WordPress agent-skills](https://github.com/WordPress/agent-skills) as a community project to enable AI-driven automation in WordPress governance.

**Key Points to Know**:
- **Scope**: Reusable skills for WordPress governance automation
- **License**: GPL 3.0 (same as WordPress core)
- **Maturity**: Early, community-driven
- **Relevance**: Directly overlaps with LightSpeed's plugin pack use cases

### LightSpeed + WordPress Agent-Skills Alignment

| Aspect | LightSpeed Plugin Pack | WordPress Agent-Skills | Opportunity |
|--------|---|---|---|
| **Scope** | GitHub governance automation | WordPress ecosystem automation | Complementary—different domains |
| **License** | Currently being validated | GPL 3.0 | Alignment required; likely compatible |
| **Approach** | Hooks + workflows + agents | Skills + agents | Similar patterns, can learn from each other |
| **Community** | Open-source, invite collaboration | WordPress Foundation | Potential partnership |

### Integration Strategy (Year 1)

1. **Audit**: Study WordPress agent-skills repo, understand architecture
2. **Mapping**: Identify which LightSpeed patterns align with WordPress patterns
3. **Adaptation**: Design how plugin pack can integrate with WordPress automation
4. **Licensing**: Ensure GPL 3.0 compliance; contribute back
5. **Collaboration**: Propose partnership with WordPress Foundation

## FAQ: WordPress Agent-Skills

### Q: Isn't WordPress agent-skills new/immature?

**A**: Yes, but that's an opportunity. We're positioning LightSpeed as an early adopter and thought leader. We can shape the direction.

### Q: How is this different from what LightSpeed is already doing?

**A**: LightSpeed focuses on GitHub governance. WordPress agent-skills focuses on WordPress ecosystem automation. They're complementary. Integration means we can serve WordPress organisations that want governance + automation together.

### Q: What if WordPress agent-skills changes direction?

**A**: We've built LightSpeed to be modular. If the integration doesn't work, we can pivot. But our bet is that WordPress and GitHub governance automation will converge.

### Q: Does GPL 3.0 licensing complicate things?

**A**: No. We're already committed to open-source and GPL compatibility. GPL 3.0 is a good fit. It ensures our contributions stay open and benefits the broader community.
