# Agent Slide Decks Index

This directory contains 26 comprehensive slide deck prompts covering the complete LightSpeed .github automation ecosystem. These materials support the WCEU 2026 25-minute talk on ".github repo automation" and serve as reference materials for training and implementation.

## Usage

Each markdown file in this directory contains a detailed prompt structure designed for:

- **NotebookLM generation**: Input for Google NotebookLM to create audio-video presentations
- **Google Slides conversion**: Prompts can be used with Figma/Google Slides to generate visual decks
- **Implementation guidance**: Each prompt includes practical examples and code snippets

## Organization

Files are organized alphabetically by topic. All files use the same structure:

1. **Introduction** — Purpose and context
2. **Key Concepts** — Terminology and core ideas
3. **Visual Suggestions** — Diagrams, screenshots, and design notes
4. **Code Examples** — Working examples and snippets
5. **Implementation Guidance** — How to adopt or replicate
6. **Resources** — Links to relevant documentation
